18:T4cd4,<h1 id="Thread-API">Thread API</h1>
<p>可以通过 <code>Agent Server</code> 暴露的 <code>Thread API</code> 管理线程（图的持久化状态）</p>
<p>API文档地址：http://localhost:2024/docs#tag/threads</p>
<p>API调用：推荐 <code>langgraph_sdk</code></p>
<p>本节先补充上节课遗漏的"子图"接口，再讲解 Thread 接口。</p>
<h2 id="安装-LangGraph-SDK">安装 LangGraph SDK</h2>
<p>上一节课已经安装过 <code>langgraph-sdk</code>，这里重复执行也无副作用，仅保证课件可独立运行：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="err">!</span><span class="n">uv</span> <span class="n">add</span> <span class="n">langgraph</span><span class="o">-</span><span class="n">sdk</span><span class="o">==</span><span class="mf">0.4.2</span>
</pre></div>
</div>
<h2 id="创建客户端">创建客户端</h2>
<p>连接本地 Agent Server（默认端口 2024），获得 <code>client.threads</code> 子客户端：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="kn">from</span><span class="w"> </span><span class="nn">langgraph_sdk</span><span class="w"> </span><span class="kn">import</span> <span class="n">get_client</span>

<span class="c1"># 连接本地 Agent Server</span>
<span class="n">client</span> <span class="o">=</span> <span class="n">get_client</span><span class="p">(</span><span class="n">url</span><span class="o">=</span><span class="s2">"http://localhost:2024"</span><span class="p">)</span>
<span class="n">client</span>
</pre></div>
</div>
<h2 id="补充获取子图">补充：获取子图</h2>
<blockquote>
<p>GET /assistants/{assistant_id}/subgraphs</p>
<p>GET /assistants/{assistant_id}/subgraphs/{namespace}</p>
</blockquote>
<p>子图接口返回的是图中<strong>结构化定义</strong>的子图节点。当前注册的 <code>agent</code> 图没有结构化子图（其子 Agent 是通过工具动态调用编译的子图，不算结构化子图），因此返回空对象。</p>
<p>先获取一个已有 Assistant 的 ID：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 获取一个已有的 agent Assistant</span>
<span class="n">assistants</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">search</span><span class="p">(</span><span class="n">graph_id</span><span class="o">=</span><span class="s2">"agent"</span><span class="p">,</span> <span class="n">limit</span><span class="o">=</span><span class="mi">1</span><span class="p">)</span>
<span class="n">assistant_id</span> <span class="o">=</span> <span class="n">assistants</span><span class="p">[</span><span class="mi">0</span><span class="p">][</span><span class="s2">"assistant_id"</span><span class="p">]</span>
<span class="n">assistant_id</span>
</pre></div>
</div>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 当前图没有结构化子图，返回空对象</span>
<span class="n">subgraphs</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">get_subgraphs</span><span class="p">(</span><span class="n">assistant_id</span><span class="p">)</span>
<span class="n">subgraphs</span>
</pre></div>
</div>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 按命名空间查询子图，同样为空</span>
<span class="n">subgraphs</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">get_subgraphs</span><span class="p">(</span><span class="n">assistant_id</span><span class="p">,</span> <span class="n">namespace</span><span class="o">=</span><span class="s2">"child:graph"</span><span class="p">)</span>
<span class="n">subgraphs</span>
</pre></div>
</div>
<h2 id="创建线程">创建线程</h2>
<blockquote>
<p>POST /threads</p>
</blockquote>
<p>创建线程时可附带元数据，并通过 <code>graph_id</code> 关联图：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 创建线程</span>
<span class="c1"># metadata：附加元数据，可用于后续搜索过滤</span>
<span class="n">thread</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">create</span><span class="p">(</span>
    <span class="n">metadata</span><span class="o">=</span><span class="p">{</span>
        <span class="s2">"title"</span><span class="p">:</span> <span class="s2">"新会话"</span><span class="p">,</span>
        <span class="s2">"user_id"</span><span class="p">:</span> <span class="s2">"007"</span><span class="p">,</span>
        <span class="s2">"graph_id"</span><span class="p">:</span> <span class="s2">"agent"</span><span class="p">,</span>
    <span class="p">},</span>
<span class="p">)</span>
<span class="n">thread</span>
</pre></div>
</div>
<p>极少用的字段说明（需要时查询）：</p>
<ul>
<li>ttl（Time-To-Live）: 可以控制线程存活周期，比如1个月后自动清理线程数据</li>
<li>supersteps：在初始化线程时，可以直接传递每一个检查点的状态</li>
</ul>
<p>保存 Thread ID 供后续接口使用：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">thread_id</span> <span class="o">=</span> <span class="n">thread</span><span class="p">[</span><span class="s2">"thread_id"</span><span class="p">]</span>
<span class="n">thread_id</span>
</pre></div>
</div>
<h2 id="获取线程">获取线程</h2>
<blockquote>
<p>GET /threads/{thread_id}</p>
</blockquote>
<p>通过 ID 获取线程的详细信息：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">thread</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">get</span><span class="p">(</span><span class="n">thread_id</span><span class="p">)</span>
<span class="n">thread</span>
</pre></div>
</div>
<p>返回字段说明：</p>
<ul>
<li>state_updated_at：线程状态最近更新时间（每次运行产生新检查点时变化）</li>
<li>status：线程状态，如 idle（空闲）/ busy（执行中）/ interrupted（中断）/ error（出错）</li>
<li>config：最新运行使用的配置，来自 assistant 的 config</li>
<li>values：线程当前的图状态值（如消息列表），未运行过时为 None</li>
</ul>
<h2 id="更新线程">更新线程</h2>
<blockquote>
<p>PATCH /threads/{thread_id}</p>
</blockquote>
<p>更新线程的元数据（<code>metadata</code>）等字段，新的元数据会与已有元数据合并：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">thread_v2</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">update</span><span class="p">(</span>
    <span class="n">thread_id</span><span class="p">,</span>
    <span class="n">metadata</span><span class="o">=</span><span class="p">{</span><span class="s2">"title"</span><span class="p">:</span> <span class="s2">"langgraph_sdk的使用方法"</span><span class="p">},</span>
<span class="p">)</span>
<span class="n">thread_v2</span>
</pre></div>
</div>
<p>返回字段与「获取线程」一致，区别在于其 <code>metadata</code> 已与传入的新元数据合并（旧的 <code>title</code>、<code>graph_id</code> 等会保留）。</p>
<h2 id="搜索线程">搜索线程</h2>
<blockquote>
<p>POST /threads/search</p>
</blockquote>
<p>按 <code>metadata</code>、<code>values</code>、<code>status</code> 等过滤，支持分页与排序。该接口同样用于列出全部线程：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 按 metadata 过滤</span>
<span class="n">result</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">search</span><span class="p">(</span>
    <span class="n">metadata</span><span class="o">=</span><span class="p">{</span><span class="s2">"user_id"</span><span class="p">:</span> <span class="s2">"007"</span><span class="p">},</span>
    <span class="n">limit</span><span class="o">=</span><span class="mi">10</span><span class="p">,</span>
<span class="p">)</span>
<span class="n">result</span>
</pre></div>
</div>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 使用 select 指定返回字段，并按创建时间倒序</span>
<span class="n">result</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">search</span><span class="p">(</span>
    <span class="n">limit</span><span class="o">=</span><span class="mi">5</span><span class="p">,</span>
    <span class="n">offset</span><span class="o">=</span><span class="mi">0</span><span class="p">,</span>
    <span class="n">sort_by</span><span class="o">=</span><span class="s2">"created_at"</span><span class="p">,</span>
    <span class="n">sort_order</span><span class="o">=</span><span class="s2">"desc"</span><span class="p">,</span>
    <span class="n">select</span><span class="o">=</span><span class="p">[</span><span class="s2">"thread_id"</span><span class="p">,</span> <span class="s2">"status"</span><span class="p">,</span> <span class="s2">"created_at"</span><span class="p">],</span>
<span class="p">)</span>
<span class="n">result</span>
</pre></div>
</div>
<p>返回的是线程对象列表，每个元素的字段与「获取线程」返回的结构一致；若指定了 <code>select</code>，则只返回选中的字段。</p>
<h2 id="统计线程数量">统计线程数量</h2>
<blockquote>
<p>POST /threads/count</p>
</blockquote>
<p>按条件统计线程数量：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">count</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">count</span><span class="p">()</span>
<span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"线程数量: </span><span class="si">{</span><span class="n">count</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
</pre></div>
</div>
<h2 id="复制线程">复制线程</h2>
<blockquote>
<p>POST /threads/{thread_id}/copy</p>
</blockquote>
<p>复制线程会<strong>连同状态和检查点一起复制</strong>，得到一个新的线程。</p>
<p>下面从服务器上已有的、有运行记录的线程复制一份，得到的线程自带状态数据，正好用于接下来的"状态与历史"演示：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">source_id</span> <span class="o">=</span> <span class="s2">"019fef6f-fc1f-72b2-a824-98a9c8fc4cda"</span>
<span class="c1"># 复制线程（连同状态与检查点一起复制）</span>
<span class="n">copy_thread</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">copy</span><span class="p">(</span><span class="n">source_id</span><span class="p">)</span>
<span class="n">copy_thread_id</span> <span class="o">=</span> <span class="n">copy_thread</span><span class="p">[</span><span class="s2">"thread_id"</span><span class="p">]</span> <span class="c1"># type: ignore</span>
<span class="n">copy_thread_id</span>
</pre></div>
</div>
<p>返回一个新的线程对象，字段与「获取线程」一致，<code>thread_id</code> 为新生成（旧线程不受影响）。</p>
<h2 id="获取线程状态">获取线程状态</h2>
<blockquote>
<p>GET /threads/{thread_id}/state</p>
</blockquote>
<p>获取线程的最新状态（即最新检查点的状态）。这里用上面复制出的线程演示（它自带状态数据）：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">state</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">get_state</span><span class="p">(</span><span class="n">copy_thread_id</span><span class="p">)</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">json</span>
<span class="nb">print</span><span class="p">(</span><span class="n">json</span><span class="o">.</span><span class="n">dumps</span><span class="p">(</span><span class="n">state</span><span class="p">,</span> <span class="n">indent</span><span class="o">=</span><span class="mi">2</span><span class="p">,</span> <span class="n">ensure_ascii</span><span class="o">=</span><span class="kc">False</span><span class="p">))</span>
</pre></div>
</div>
<p>返回字段说明：</p>
<ul>
<li>values：图的最新状态（如消息列表 messages）</li>
<li>next：下一步要执行的节点列表；空列表表示图已执行完毕</li>
<li>tasks：正在排队/执行中的任务</li>
<li>metadata：本次运行的元数据（system_prompt、graph_id、assistant_id 等）</li>
<li>checkpoint：最新检查点信息（checkpoint_id、thread_id、checkpoint_ns）</li>
<li>checkpoint_id：最新检查点 ID，每个超步产生一个</li>
<li>parent_checkpoint / parent_checkpoint_id：上一个检查点</li>
<li>interrupts：当前的中断（human-in-the-loop 触发 interrupt 时才会有）</li>
<li>created_at：检查点创建时间</li>
</ul>
<h2 id="获取线程历史">获取线程历史</h2>
<blockquote>
<p>GET /threads/{thread_id}/history</p>
</blockquote>
<p>获取线程的全部历史状态（每个超步产生一个检查点，对应一个状态）：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">history</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">get_history</span><span class="p">(</span><span class="n">copy_thread_id</span><span class="p">,</span> <span class="n">limit</span><span class="o">=</span><span class="mi">10</span><span class="p">)</span>
<span class="n">checkpoints</span> <span class="o">=</span> <span class="p">[</span><span class="n">state</span><span class="p">[</span><span class="s2">"checkpoint"</span><span class="p">]</span> <span class="k">for</span> <span class="n">state</span> <span class="ow">in</span> <span class="n">history</span><span class="p">]</span>
<span class="nb">print</span><span class="p">(</span><span class="n">json</span><span class="o">.</span><span class="n">dumps</span><span class="p">(</span><span class="n">history</span><span class="p">,</span> <span class="n">indent</span><span class="o">=</span><span class="mi">2</span><span class="p">,</span> <span class="n">ensure_ascii</span><span class="o">=</span><span class="kc">False</span><span class="p">))</span>
</pre></div>
</div>
<p>返回的是状态历史列表，每个元素对应一次超步执行后产生的一个检查点，字段与「获取线程状态」返回的结构一致，其中 <code>metadata.step</code> 为超步序号，<code>checkpoint</code> 里是 <code>checkpoint_id</code> 等检查点信息。</p>
<h2 id="获取指定检查点状态">获取指定检查点状态</h2>
<blockquote>
<p>GET /threads/{thread_id}/state/{checkpoint_id}</p>
</blockquote>
<p>通过 <code>checkpoint_id</code> 获取某个历史检查点的状态。先取历史中的一个检查点 ID：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 获取指定检查点的状态</span>
<span class="n">state</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">get_state</span><span class="p">(</span><span class="n">copy_thread_id</span><span class="p">,</span> <span class="n">checkpoint_id</span><span class="o">=</span><span class="s2">"1f1954b1-a620-642e-8000-8ca661c7fcb5"</span><span class="p">)</span>
<span class="n">state</span>
</pre></div>
</div>
<p>返回字段与「获取线程状态」一致，只是对应的是指定检查点那一刻的状态（可用于回溯/时间旅行）。</p>
<h2 id="清理线程">清理线程</h2>
<blockquote>
<p>POST /threads/prune</p>
</blockquote>
<p>按 ID 清理线程。<code>strategy="delete"</code> 会删除整个线程，<code>strategy="keep_latest"</code> 则只清理旧检查点但保留线程及最新状态。</p>
<p>先创建一个临时线程用于清理演示：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 清理临时线程（delete 策略会删除整个线程）</span>
<span class="n">result</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">threads</span><span class="o">.</span><span class="n">prune</span><span class="p">(</span>
    <span class="n">thread_ids</span><span class="o">=</span><span class="p">[</span><span class="n">copy_thread_id</span><span class="p">],</span>
    <span class="n">strategy</span><span class="o">=</span><span class="s2">"keep_latest"</span><span class="p">,</span>
<span class="p">)</span>
<span class="n">result</span>
</pre></div>
</div>
<p>返回字段说明：</p>
<ul>
<li>pruned_count：实际清理的线程数量</li>
</ul>
