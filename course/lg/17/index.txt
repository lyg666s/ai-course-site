16:T33cf,<h1 id="Assistant-API">Assistant API</h1>
<p>可以通过<code>Agent Server</code>暴露的<code>Assistant API</code>管理AI助手</p>
<p>API文档地址：http://localhost:2024/docs#tag/assistants</p>
<p>API调用：推荐 <code>langgraph_sdk</code></p>
<h2 id="安装-LangGraph-SDK">安装 LangGraph SDK</h2>
<p>本课件使用 <code>langgraph-sdk</code> 访问 Assistant API，先通过 UV 安装：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="err">!</span><span class="n">uv</span> <span class="n">add</span> <span class="n">langgraph</span><span class="o">-</span><span class="n">sdk</span><span class="o">==</span><span class="mf">0.4.2</span>
</pre></div>
</div>
<h2 id="创建客户端">创建客户端</h2>
<p>连接本地 Agent Server（默认端口 2024），获得 <code>client.assistants</code> 子客户端：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="kn">from</span><span class="w"> </span><span class="nn">langgraph_sdk</span><span class="w"> </span><span class="kn">import</span> <span class="n">get_client</span>

<span class="c1"># 连接本地 Agent Server</span>
<span class="n">client</span> <span class="o">=</span> <span class="n">get_client</span><span class="p">(</span><span class="n">url</span><span class="o">=</span><span class="s2">"http://localhost:2024"</span><span class="p">)</span>
<span class="n">client</span>
</pre></div>
</div>
<h2 id="创建-Assistant">创建 Assistant</h2>
<blockquote>
<p>POST /assistants</p>
</blockquote>
<p>创建时会为该 Assistant 生成初始版本（version=1）。</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 为 agent 图创建 Assistant</span>
<span class="c1"># - context：静态上下文，会注入到图的 Runtime 中</span>
<span class="c1"># - metadata：附加元数据，可用于后续搜索过滤</span>
<span class="n">assistant</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">create</span><span class="p">(</span>
    <span class="n">graph_id</span><span class="o">=</span><span class="s2">"agent"</span><span class="p">,</span>
    <span class="n">name</span><span class="o">=</span><span class="s2">"假模型"</span><span class="p">,</span> <span class="c1"># 取一个直观的名称，用户友好，无功能含义</span>
    <span class="n">description</span><span class="o">=</span><span class="s2">"最多允许运行10个超步"</span><span class="p">,</span> <span class="c1"># 描述，无功能含义</span>
    <span class="n">context</span><span class="o">=</span><span class="p">{</span><span class="s2">"model"</span><span class="p">:</span> <span class="s2">"fake"</span><span class="p">},</span>
    <span class="n">config</span><span class="o">=</span><span class="p">{</span>
        <span class="s2">"recursion_limit"</span><span class="p">:</span> <span class="mi">10</span>
    <span class="p">}</span>
<span class="p">)</span>
<span class="n">assistant</span>
</pre></div>
</div>
<p>保存 Assistant ID 供后续接口使用：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">assistant_id</span> <span class="o">=</span> <span class="n">assistant</span><span class="p">[</span><span class="s2">"assistant_id"</span><span class="p">]</span>
<span class="n">assistant_id</span>
</pre></div>
</div>
<h2 id="获取-Assistant">获取 Assistant</h2>
<blockquote>
<p>GET /assistants/{assistant_id}</p>
</blockquote>
<p>通过 ID 获取 Assistant 的详细信息：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">assistant</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">get</span><span class="p">(</span><span class="n">assistant_id</span><span class="p">)</span>
<span class="n">assistant</span>
</pre></div>
</div>
<h2 id="更新-Assistant">更新 Assistant</h2>
<blockquote>
<p>PATCH /assistants/{assistant_id}</p>
</blockquote>
<p>更新 Assistant 的名称、描述、配置等。更新后会生成一个新版本，并将其设为最新版本。</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">assistant_v2</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">update</span><span class="p">(</span>
    <span class="n">assistant_id</span><span class="p">,</span>
    <span class="n">description</span><span class="o">=</span><span class="s2">"最多允许20个超步"</span><span class="p">,</span>
    <span class="n">config</span><span class="o">=</span><span class="p">{</span>
        <span class="s2">"recursion_limit"</span><span class="p">:</span><span class="mi">20</span>
    <span class="p">}</span>
<span class="p">)</span>
<span class="n">assistant_v2</span>
</pre></div>
</div>
<h2 id="获取-Assistant-版本列表">获取 Assistant 版本列表</h2>
<blockquote>
<p>POST /assistants/{assistant_id}/versions</p>
</blockquote>
<p>列出 Assistant 的全部历史版本：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">versions</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">get_versions</span><span class="p">(</span><span class="n">assistant_id</span><span class="p">)</span>
<span class="n">versions</span>
</pre></div>
</div>
<h2 id="设置最新版本">设置最新版本</h2>
<blockquote>
<p>POST /assistants/{assistant_id}/latest</p>
</blockquote>
<p>将某个历史版本设为最新版本，用于版本回滚：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 回滚到版本 1</span>
<span class="n">assistant</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">set_latest</span><span class="p">(</span><span class="n">assistant_id</span><span class="p">,</span> <span class="n">version</span><span class="o">=</span><span class="mi">1</span><span class="p">)</span>
<span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"当前最新版本: </span><span class="si">{</span><span class="n">assistant</span><span class="p">[</span><span class="s1">'version'</span><span class="p">]</span><span class="si">}</span><span class="s2">, 名称: </span><span class="si">{</span><span class="n">assistant</span><span class="p">[</span><span class="s1">'name'</span><span class="p">]</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
</pre></div>
</div>
<h2 id="搜索-Assistant">搜索 Assistant</h2>
<blockquote>
<p>POST /assistants/search</p>
</blockquote>
<p>按名称、graph_id、metadata 过滤，支持分页与排序。该接口同样用于列出全部 Assistant。</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 按名称模糊搜索（不区分大小写的子串匹配）</span>
<span class="n">result</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">search</span><span class="p">(</span>
    <span class="n">graph_id</span><span class="o">=</span><span class="s2">"agent"</span><span class="p">,</span>
    <span class="n">limit</span><span class="o">=</span><span class="mi">10</span><span class="p">,</span>
<span class="p">)</span>
<span class="n">result</span>
</pre></div>
</div>
<p>使用 <code>select</code> 可指定返回字段：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="n">result</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">assistants</span><span class="o">.</span><span class="n">search</span><span class="p">(</span>
    <span class="n">limit</span><span class="o">=</span><span class="mi">2</span><span class="p">,</span>
    <span class="n">offset</span><span class="o">=</span><span class="mi">0</span><span class="p">,</span>
    <span class="n">sort_by</span><span class="o">=</span><span class="s2">"created_at"</span><span class="p">,</span>
    <span class="n">sort_order</span><span class="o">=</span><span class="s2">"desc"</span><span class="p">,</span>
    <span class="n">select</span><span class="o">=</span><span class="p">[</span><span class="s2">"assistant_id"</span><span class="p">,</span> <span class="s2">"name"</span><span class="p">,</span> <span class="s2">"created_at"</span><span class="p">]</span>
<span class="p">)</span>
<span class="n">result</span>
</pre></div>
</div>
