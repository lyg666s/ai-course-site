16:T7b85,<h1 id="时间旅行">时间旅行</h1>
<p>时间旅行：允许你从某一个检查点开始重新运行直到图结束。</p>
<p>支持两种模型的时间旅行：</p>
<ul>
<li>Replay: 从某个检查点的状态开始重新运行</li>
<li>Fork：和 Replay 一样，只是运行时可以修改检查点状态</li>
</ul>
<p><img loading="lazy" src="./assets/时间旅行.svg?1"></p>

<h3 id="最佳实践">最佳实践</h3>
<ul>
<li>刷新 AI 输出：找到AI结果之前的检查点，直接 replay 即可</li>
<li>修改内容：找到内容产出节点上一个检查点，指定<code>as_node</code>为内容产出节点，修改内容，然后从该检查点 replay</li>
</ul>
<h2 id="Agent-Server">Agent Server</h2>
<p>Agent Server 上运行的图同样基于检查点，因此时间旅行（Replay / Fork）可以直接通过 SDK 操作。</p>
<p>与 LangGraph API 的区别只在于：历史、状态与检查点都存在服务器上，通过 <code>client.threads</code> 查询与修改，再通过 <code>client.runs</code> 从指定检查点恢复运行。</p>
<p>API文档地址：http://localhost:2024/docs</p>
