18:T495b,<h1 id="Cron-API">Cron API</h1>
<p>可以通过 <code>Agent Server</code> 暴露的 <code>Cron API</code> 按指定的时间计划<strong>定时运行</strong>图（类似操作系统的 <code>cron</code> 定时任务）</p>
<p>API文档地址：http://localhost:2024/docs#tag/crons</p>
<p>API调用：推荐 <code>langgraph_sdk</code></p>
<p>Cron 分两类：
- <strong>无状态 Cron（Stateless Crons）</strong>：每次执行都新建一个线程，运行结束后删除
- <strong>有状态 Cron（Thread Crons）</strong>：绑定一个<strong>固定的线程</strong>，每次执行都复用该线程，可以积累上下文</p>
<h2 id="安装-LangGraph-SDK">安装 LangGraph SDK</h2>
<p>上一节课已经安装过 <code>langgraph-sdk</code>，这里重复执行也无副作用，仅保证课件可独立运行：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="err">!</span><span class="n">uv</span> <span class="n">add</span> <span class="n">langgraph</span><span class="o">-</span><span class="n">sdk</span><span class="o">==</span><span class="mf">0.4.2</span>
</pre></div>
</div>

<h2 id="创建-Cron">创建 Cron</h2>
<h3 id="创建无状态-Cron">创建无状态 Cron</h3>
<blockquote>
<p>POST /runs/crons</p>
</blockquote>
<p>无状态 Cron 每次执行时都会<strong>自动创建一个新的线程</strong>。用 <code>on_run_completed</code> 控制线程去留：
- <code>delete</code>（默认）：运行完成后删除线程，无任何残留
- <code>keep</code>：保留线程，会不断积累线程数据，需要自己清理</p>
<blockquote>
<p>为了不在课堂上真的频繁触发任务，这里先创建 <code>enabled=False</code> 的禁用 Cron，稍后再演示启用：</p>
</blockquote>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 创建无状态 Cron（每次执行都会新建线程）</span>
<span class="n">cron</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">crons</span><span class="o">.</span><span class="n">create</span><span class="p">(</span>
    <span class="n">assistant_id</span><span class="o">=</span><span class="n">assistant_id</span><span class="p">,</span>
    <span class="n">schedule</span><span class="o">=</span><span class="s2">"*/2 * * * *"</span><span class="p">,</span>  <span class="c1"># 每 2 分钟执行一次</span>
    <span class="nb">input</span><span class="o">=</span><span class="p">{</span><span class="s2">"messages"</span><span class="p">:</span> <span class="p">[{</span><span class="s2">"role"</span><span class="p">:</span> <span class="s2">"user"</span><span class="p">,</span> <span class="s2">"content"</span><span class="p">:</span> <span class="s2">"定时任务：汇报一下当前时间"</span><span class="p">}]},</span>
    <span class="n">metadata</span><span class="o">=</span><span class="p">{</span><span class="s2">"lesson"</span><span class="p">:</span> <span class="s2">"第21节课：无状态Cron测试"</span><span class="p">},</span>
    <span class="n">enabled</span><span class="o">=</span><span class="kc">False</span><span class="p">,</span>  <span class="c1"># 先禁用，避免课堂演示时频繁触发</span>
<span class="p">)</span>
<span class="n">cron</span>
</pre></div>
</div>

<p>常用示例：
- <code>0 9 * * *</code>：每天早上 9 点
- <code>*/5 * * * *</code>：每 5 分钟
- <code>0 0 * * 1</code>：每周一零点</p>
<p>不传 <code>timezone</code> 时按 <strong>UTC</strong> 时区解释。</p>
<h3 id="创建线程-Cron有状态">创建线程 Cron（有状态）</h3>
<blockquote>
<p>POST /threads/{thread_id}/runs/crons</p>
</blockquote>
<p>与无状态 Cron 的区别：通过 <code>create_for_thread</code> 绑定一个固定的线程。每次执行都往<strong>同一个线程</strong>里追加消息，可以积累多轮对话的上下文：</p>
<div class="nb-cell"><div class="codehilite lang-nb"><pre><span></span><span class="c1"># 创建绑定线程的 Cron（每次执行都复用同一个线程）</span>
<span class="n">thread_cron</span> <span class="o">=</span> <span class="k">await</span> <span class="n">client</span><span class="o">.</span><span class="n">crons</span><span class="o">.</span><span class="n">create_for_thread</span><span class="p">(</span>
    <span class="n">thread_id</span><span class="o">=</span><span class="n">thread_id</span><span class="p">,</span>
    <span class="n">assistant_id</span><span class="o">=</span><span class="n">assistant_id</span><span class="p">,</span>
    <span class="n">schedule</span><span class="o">=</span><span class="s2">"0 9 * * *"</span><span class="p">,</span>  <span class="c1"># 每天早上 9 点</span>
    <span class="nb">input</span><span class="o">=</span><span class="p">{</span><span class="s2">"messages"</span><span class="p">:</span> <span class="p">[{</span><span class="s2">"role"</span><span class="p">:</span> <span class="s2">"user"</span><span class="p">,</span> <span class="s2">"content"</span><span class="p">:</span> <span class="s2">"每日晨报"</span><span class="p">}]},</span>
    <span class="n">metadata</span><span class="o">=</span><span class="p">{</span><span class="s2">"lesson"</span><span class="p">:</span> <span class="s2">"第21节课：线程Cron测试"</span><span class="p">},</span>
    <span class="n">enabled</span><span class="o">=</span><span class="kc">False</span><span class="p">,</span>  <span class="c1"># 先禁用</span>
<span class="p">)</span>
<span class="n">thread_cron_id</span> <span class="o">=</span> <span class="n">thread_cron</span><span class="p">[</span><span class="s2">"cron_id"</span><span class="p">]</span> <span class="c1"># type: ignore</span>
<span class="n">thread_cron</span>
</pre></div>
</div>
<h3 id="cron-对象字段说明">cron 对象字段说明</h3>
<ul>
<li><code>cron_id</code>：Cron 任务 ID</li>
<li><code>thread_id</code>：绑定的线程（无状态 Cron 会为每次执行新建，通常为空）</li>
<li><code>assistant_id</code>：执行时使用的助手</li>
<li><code>schedule</code>：cron 表达式</li>
<li><code>payload</code>：每次执行时要创建运行的参数（input、config 等）</li>
<li><code>next_run_date</code>：下一次执行时间</li>
<li><code>end_time</code>：Cron 的结束时间（为空则无限期运行）</li>
<li><code>enabled</code>：是否启用</li>
<li><code>metadata</code>：创建时传入的元数据，可用于搜索过滤</li>
</ul>
