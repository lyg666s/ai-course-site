<h2 id="课程目标">课程目标</h2>
<ul>
<li>理解 BOM（Bill of Materials）在微服务多模块项目中的作用</li>
<li>掌握 Spring Cloud Alibaba 版本对应关系与选择原则</li>
<li>掌握在父 POM 中导入 Spring Boot、Spring Cloud、Spring Cloud Alibaba 三大 BOM</li>

<h2 id="回顾与导入">回顾与导入</h2>
<p>在前面的课程中，我们完成了多模块工程骨架搭建，但父 POM 尚未导入任何 BOM。此时子模块声明外部依赖时需要写版本号，存在以下问题：</p>
<table>
<thead>
<tr>
<th>问题</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>版本冲突</strong></td>
<td>不同模块使用不同版本，导致运行时 NoSuchMethodError</td>
</tr>
<tr>
<td><strong>升级困难</strong></td>
<td>升级某个组件需要修改所有模块</td>
</tr>
<tr>
<td><strong>遗漏依赖</strong></td>
<td>新模块容易忘记声明某些依赖的版本</td>
</tr>
<tr>
<td><strong>兼容性风险</strong></td>
<td>手动选择版本可能不兼容</td>
</tr>
</tbody>
</table>
<p>本节课将引入 Spring Cloud Alibaba 技术栈，通过 BOM 统一管理所有依赖版本。</p>
<h2 id="为什么需要-BOM">为什么需要 BOM</h2>
<p><strong>BOM（Bill of Materials）</strong> 是 Maven 提供的依赖管理机制。通过 <code>&lt;dependencyManagement&gt;</code> 导入 BOM，可以统一管理所有相关组件的版本，子模块无需指定版本号。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    A[父POM] --&gt;|导入| B[Spring Boot BOM]
    A --&gt;|导入| C[Spring Cloud BOM]
    A --&gt;|导入| D[Spring Cloud Alibaba BOM]

    E[book-product] --&gt;|继承| A
    F[book-user] --&gt;|继承| A
    G[book-order] --&gt;|继承| A

    E --&gt;|声明依赖,不写版本| H[Nacos]
    F --&gt;|声明依赖,不写版本| H
    G --&gt;|声明依赖,不写版本| H

    style A fill:#e3f2fd
    style B fill:#e8f5e9
    style C fill:#e8f5e9
    style D fill:#e8f5e9
</code></pre></div>

<table>
<thead>
<tr>
<th>好处</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>版本一致</strong></td>
<td>所有子模块使用同一版本，避免冲突</td>
</tr>
<tr>
<td><strong>简化配置</strong></td>
<td>子模块无需写版本号</td>
</tr>
<tr>
<td><strong>升级方便</strong></td>
<td>只需修改父 POM 的版本变量</td>
</tr>
<tr>
<td><strong>兼容保证</strong></td>
<td>BOM 内部已解决组件之间的兼容性</td>
</tr>
</tbody>
</table>

<h2 id="注意事项">注意事项</h2>
<ol>
<li><strong>BOM 导入位置</strong>：三个 BOM 必须在 <code>&lt;dependencyManagement&gt;</code> 中通过 <code>&lt;scope&gt;import&lt;/scope&gt;</code> 导入，否则版本管理不生效。</li>
<li><strong>BOM 顺序</strong>：Spring Cloud Alibaba BOM 应放在最后，因为它会覆盖前面 BOM 中同名依赖的版本。</li>
<li><strong>内部模块版本</strong>：<code>book-common</code> 等内部模块必须写 <code>${project.version}</code>，不能省略。</li>
<li><strong>不要混用版本</strong>：不要手动指定 Spring Cloud Alibaba 组件的版本号，一切由 BOM 裁决。</li>
<li><strong>JDK 版本</strong>：Spring Cloud Alibaba 2025.0.0.0 要求 JDK 17+。</li>
<li><strong>版本升级</strong>：升级 Spring Boot 版本时，必须同步升级 Spring Cloud 和 Spring Cloud Alibaba 版本，三者版本必须匹配。</li>
<li><strong>验证方法</strong>：使用 <code>mvn dependency:tree</code> 查看实际生效的版本，确认 BOM 是否生效。</li>
</ol>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
