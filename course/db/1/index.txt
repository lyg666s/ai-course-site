<h2 id="安装-Docker">安装 Docker</h2>
<h3 id="安装-Docker-Desktop">安装 Docker Desktop</h3>
<p>访问 <a href="https://www.docker.com/products/docker-desktop">https://www.docker.com/products/docker-desktop</a> 下载 Docker Desktop</p>
<p>⚠️注意：windows电脑均下载AMD版本的，不要下载ARM版本的，课堂上说的有误！</p>
<h3 id="配置镜像加速器">配置镜像加速器</h3>
<p>由于网络原因，国内用户拉取 Docker 镜像可能很慢，需要配置镜像加速器。</p>
<p><strong>打开 Docker Desktop → Settings → Docker Engine</strong>，在配置文件中添加 <code>registry-mirrors</code>：</p>
<div class="codehilite lang-json"><pre><span></span><code><span class="p">{</span>
<span class="w">  </span><span class="nt">"registry-mirrors"</span><span class="p">:</span><span class="w"> </span><span class="p">[</span>
<span class="w">    </span><span class="s2">"https://docker.m.daocloud.io"</span><span class="p">,</span>
<span class="w">    </span><span class="s2">"https://docker.1ms.run"</span><span class="p">,</span>
<span class="w">    </span><span class="s2">"https://docker.aityp.com"</span>
<span class="w">  </span><span class="p">]</span>
<span class="p">}</span>
</code></pre></div>

<p>点击 <strong>Apply &amp; Restart</strong> 使配置生效。</p>
<h3 id="验证-Docker-安装">验证 Docker 安装</h3>
<p>打开终端（Terminal），执行：</p>
<div class="codehilite lang-bash"><pre><span></span><code>docker<span class="w"> </span>--version
</code></pre></div>

<p>预期输出（版本号可能不同）：</p>
<div class="codehilite"><pre><span></span><code>Docker version 29.2.0, build 0b9d198
</code></pre></div>

<p>验证 Docker 正常运行：</p>
<div class="codehilite lang-bash"><pre><span></span><code>docker<span class="w"> </span>info
</code></pre></div>

<p>能看到 Server 相关信息表示安装成功。</p>
<hr />
<h2 id="安装-PostgreSQL">安装 PostgreSQL</h2>
<h3 id="拉取-PostgreSQL-镜像">拉取 PostgreSQL 镜像</h3>
<div class="codehilite lang-bash"><pre><span></span><code>docker<span class="w"> </span>pull<span class="w"> </span>postgres:16
</code></pre></div>

<blockquote>
<p>我们选择 PostgreSQL 16，这是目前最新的稳定版本。</p>
</blockquote>
<h3 id="创建并运行-PostgreSQL-容器">创建并运行 PostgreSQL 容器</h3>
<div class="codehilite lang-bash"><pre><span></span><code>docker<span class="w"> </span>run<span class="w"> </span>-d<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>--name<span class="w"> </span>pg16<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-e<span class="w"> </span><span class="nv">POSTGRES_USER</span><span class="o">=</span>admin<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-e<span class="w"> </span><span class="nv">POSTGRES_PASSWORD</span><span class="o">=</span><span class="m">123123</span><span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-p<span class="w"> </span><span class="m">5432</span>:5432<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-v<span class="w"> </span><span class="s2">"你的本地路径:/var/lib/postgresql/data"</span><span class="w"> </span><span class="se">\</span>
<span class="w">  </span>postgres:16
</code></pre></div>

<p>参数说明：</p>
<table>
<thead>
<tr>
<th>参数</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>-d</code></td>
<td>后台运行容器</td>
</tr>
<tr>
<td><code>--name pg16</code></td>
<td>容器命名为 pg16</td>
</tr>
<tr>
<td><code>-e POSTGRES_USER=admin</code></td>
<td>设置超级用户名为 admin</td>
</tr>
<tr>
<td><code>-e POSTGRES_PASSWORD=admin123</code></td>
<td>设置密码为 admin123</td>
</tr>
<tr>
<td><code>-p 5432:5432</code></td>
<td>将宿主机 5432 端口映射到容器 5432 端口</td>
</tr>
<tr>
<td><code>-v ...:/var/lib/postgresql/data</code></td>
<td>数据持久化卷，容器删除后数据不丢失</td>
</tr>
</tbody>
</table>
<h3 id="验证-PostgreSQL-容器">验证 PostgreSQL 容器</h3>
<p>进入容器连接 PostgreSQL</p>
<div class="codehilite lang-bash"><pre><span></span><code>docker<span class="w"> </span><span class="nb">exec</span><span class="w"> </span>-it<span class="w"> </span>pg16<span class="w"> </span>psql<span class="w"> </span>-U<span class="w"> </span>admin<span class="w"> </span>-d<span class="w"> </span>admin
</code></pre></div>

<p>参数说明：</p>
<table>
<thead>
<tr>
<th>参数</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>docker exec -it pg16</code></td>
<td>在 pg16 容器中执行交互式命令</td>
</tr>
<tr>
<td><code>psql -U admin -d demo_db</code></td>
<td>使用用户 admin 连接 demo_db 数据库</td>
</tr>
</tbody>
</table>
<p>连接成功后，在 <code>demo_db=#</code> 提示符下执行以下命令验证：</p>
<div class="codehilite lang-sql"><pre><span></span><code><span class="c1">-- 查看当前连接信息</span>
<span class="err">\</span><span class="n">conninfo</span>

<span class="c1">-- 列出所有数据库</span>
<span class="err">\</span><span class="n">l</span>

<span class="c1">-- 查看当前用户</span>
<span class="k">SELECT</span><span class="w"> </span><span class="k">current_user</span><span class="p">;</span>

<span class="c1">-- 退出psql</span>
<span class="err">\</span><span class="n">q</span>
</code></pre></div>

<h2 id="安装管理工具-pgAdmin">安装管理工具 pgAdmin</h2>
<p>官网地址：https://www.pgadmin.org/</p>
<p>同样使用 Docker 安装：</p>
<div class="codehilite lang-bash"><pre><span></span><code>docker<span class="w"> </span>run<span class="w"> </span>-d<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>--name<span class="w"> </span>pgadmin4<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-e<span class="w"> </span><span class="nv">PGADMIN_DEFAULT_EMAIL</span><span class="o">=</span>admin@qq.com<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-e<span class="w"> </span><span class="nv">PGADMIN_DEFAULT_PASSWORD</span><span class="o">=</span><span class="m">123123</span><span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-p<span class="w"> </span><span class="m">5050</span>:80<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>dpage/pgadmin4
</code></pre></div>

<p>参数说明：</p>
<table>
<thead>
<tr>
<th>参数</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>-e PGADMIN_DEFAULT_EMAIL</code></td>
<td>登录邮箱</td>
</tr>
<tr>
<td><code>-e PGADMIN_DEFAULT_PASSWORD</code></td>
<td>登录密码</td>
</tr>
<tr>
<td><code>-p 5050:80</code></td>
<td>宿主机 5050 端口映射到容器 80 端口</td>
</tr>
<tr>
<td><code>--link pg16:pg16</code></td>
<td>连接到 pg16 容器，网络互通</td>
</tr>
</tbody>
</table>
<p>接下来可以打开浏览器访问 http://localhost:5050</p>
