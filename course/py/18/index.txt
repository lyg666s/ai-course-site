<p>带 <code>__enter__</code> 和 <code>__exit__</code> 方法的对象叫做<strong>上下文管理器（Context Manager）</strong>。</p>
<ul>
<li><strong>上下文管理器</strong>是支持 <code>with</code> 语句的对象</li>
<li><strong>必须同时实现</strong>两个方法，否则 <code>with</code> 会报错</li>
</ul>

<h2 id="异常处理">异常处理</h2>
<p><code>__exit__</code> 方法可以处理或记录异常：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">SuppressError</span><span class="p">:</span>
<span class="w">    </span><span class="sd">"""忽略指定类型的异常"""</span>

    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="o">*</span><span class="n">exception_types</span><span class="p">):</span>

    <span class="k">def</span><span class="w"> </span><span class="fm">__enter__</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="k">return</span> <span class="bp">self</span>

    <span class="k">def</span><span class="w"> </span><span class="fm">__exit__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">exc_type</span><span class="p">,</span> <span class="n">exc_val</span><span class="p">,</span> <span class="n">exc_tb</span><span class="p">):</span>

            <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"捕获并忽略异常: </span><span class="si">{</span><span class="n">exc_type</span><span class="o">.</span><span class="vm">__name__</span><span class="si">}</span><span class="s2">: </span><span class="si">{</span><span class="n">exc_val</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
            <span class="k">return</span> <span class="kc">True</span>  <span class="c1"># 返回 True，异常被处理，不再传播</span>
        <span class="k">return</span> <span class="kc">False</span>  <span class="c1"># 不处理其他异常</span>

<h2 id="使用-contextmanager-装饰器">使用 @contextmanager 装饰器</h2>
<p>对于简单的上下文管理器，可以使用 <code>contextlib</code> 模块的 <code>@contextmanager</code> 装饰器，用生成器函数实现：</p>

<span class="nd">@contextmanager</span>
<span class="k">def</span><span class="w"> </span><span class="nf">managed_resource</span><span class="p">(</span><span class="n">name</span><span class="p">):</span>
<span class="w">    </span><span class="sd">"""用生成器实现上下文管理器"""</span>
    <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"获取资源: </span><span class="si">{</span><span class="n">name</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
    <span class="n">resource</span> <span class="o">=</span> <span class="p">{</span><span class="s2">"name"</span><span class="p">:</span> <span class="n">name</span><span class="p">,</span> <span class="s2">"status"</span><span class="p">:</span> <span class="s2">"active"</span><span class="p">}</span>
    <span class="k">try</span><span class="p">:</span>
        <span class="k">yield</span> <span class="n">resource</span>  <span class="c1"># yield 之前的代码等价于 __enter__</span>
    <span class="k">finally</span><span class="p">:</span>
        <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"释放资源: </span><span class="si">{</span><span class="n">name</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>  <span class="c1"># yield 之后的代码等价于 __exit__</span>


<span class="c1"># 使用</span>
<span class="k">with</span> <span class="n">managed_resource</span><span class="p">(</span><span class="s2">"database"</span><span class="p">)</span> <span class="k">as</span> <span class="n">res</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"使用资源: </span><span class="si">{</span><span class="n">res</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
