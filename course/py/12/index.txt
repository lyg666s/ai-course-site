18:T3750,<h2 id="类的创建过程">类的创建过程</h2>
<p>使用 <code>class</code> 关键字定义类时，Python 底层会调用元类来创建类：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">:</span>
    <span class="k">pass</span>


<span class="c1"># 等效于</span>
<span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">(</span><span class="n">metaclass</span><span class="o">=</span><span class="nb">type</span><span class="p">):</span>
    <span class="k">pass</span>


<span class="c1"># 等效于</span>
<span class="n">Dog</span> <span class="o">=</span> <span class="nb">type</span><span class="p">(</span><span class="s2">"Dog"</span><span class="p">,</span> <span class="p">(),</span> <span class="p">{})</span>

<span class="c1"># 等效于</span>
<span class="n">Dog</span> <span class="o">=</span> <span class="nb">type</span><span class="o">.</span><span class="fm">__call__</span><span class="p">(</span><span class="nb">type</span><span class="p">,</span> <span class="s2">"Dog"</span><span class="p">,</span> <span class="p">(),</span> <span class="p">{})</span>
</code></pre></div>

<p>也就是说，<code>class</code> 关键字只是语法糖，底层仍然是通过 <code>type()</code> 创建类。</p>

<h2 id="自定义元类">自定义元类</h2>
<p>通过继承 <code>type</code>，可以自定义元类，控制类的创建过程。</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">MyMeta</span><span class="p">(</span><span class="nb">type</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__new__</span><span class="p">(</span><span class="n">mcs</span><span class="p">,</span> <span class="n">name</span><span class="p">,</span> <span class="n">bases</span><span class="p">,</span> <span class="n">namespace</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"正在创建类: </span><span class="si">{</span><span class="n">name</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
        <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"父类: </span><span class="si">{</span><span class="n">bases</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
        <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"属性: </span><span class="si">{</span><span class="nb">list</span><span class="p">(</span><span class="n">namespace</span><span class="o">.</span><span class="n">keys</span><span class="p">())</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>

        <span class="c1"># 必须调用 type.__new__ 来真正创建类</span>
        <span class="bp">cls</span> <span class="o">=</span> <span class="nb">super</span><span class="p">()</span><span class="o">.</span><span class="fm">__new__</span><span class="p">(</span><span class="n">mcs</span><span class="p">,</span> <span class="n">name</span><span class="p">,</span> <span class="n">bases</span><span class="p">,</span> <span class="n">namespace</span><span class="p">)</span>
        <span class="k">return</span> <span class="bp">cls</span>


<span class="c1"># 使用 metaclass 参数指定元类</span>
<span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">(</span><span class="n">metaclass</span><span class="o">=</span><span class="n">MyMeta</span><span class="p">):</span>
    <span class="n">species</span> <span class="o">=</span> <span class="s2">"Canis familiaris"</span>

    <span class="k">def</span><span class="w"> </span><span class="nf">bark</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"Woof!"</span><span class="p">)</span>


<span class="c1"># 等效于</span>
<span class="c1"># def bark(self):</span>
<span class="c1">#     print("Woof!")</span>


<span class="c1"># Dog = type.__call__(MyMeta, "Dog", (), {"species": "Canis familiaris", "bark": bark})</span>

<span class="c1"># 输出：</span>
<span class="c1"># 正在创建类: Dog</span>
<span class="c1"># 父类: ()</span>
<span class="c1"># 属性: ['__module__', '__qualname__', 'species', 'bark']</span>
</code></pre></div>

<p><strong>参数说明：</strong></p>
<ul>
<li><code>mcs</code>：元类自身（类似类方法中的 <code>cls</code>）</li>
<li><code>name</code>：类名字符串</li>
<li><code>bases</code>：父类元组</li>
<li><code>namespace</code>：类属性的字典</li>

<h2 id="深入元类的查找顺序">深入：元类的查找顺序</h2>
<p>子类会继承父类的元类：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">MyMeta</span><span class="p">(</span><span class="nb">type</span><span class="p">):</span>

<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">MetaA</span><span class="p">(</span><span class="nb">type</span><span class="p">):</span>

<span class="k">class</span><span class="w"> </span><span class="nc">A</span><span class="p">(</span><span class="n">metaclass</span><span class="o">=</span><span class="n">MetaA</span><span class="p">):</span>

<span class="k">class</span><span class="w"> </span><span class="nc">B</span><span class="p">(</span><span class="n">metaclass</span><span class="o">=</span><span class="n">MetaB</span><span class="p">):</span>
