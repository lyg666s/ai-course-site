17:Te87a,<p>Python 是一门<strong>面向对象</strong>的编程语言。类（Class）是创建对象的蓝图，而对象（Object）是类的具体实例。通过类和对象，可以将数据（属性）和行为（方法）封装在一起，使代码更具结构性和可复用性。</p>
<hr />
<h2 id="定义类">定义类</h2>
<p>使用 <code>class</code> 关键字定义类：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">:</span>
    <span class="k">pass</span>

<span class="c1"># 创建实例</span>
<span class="n">my_dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">()</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">type</span><span class="p">(</span><span class="n">my_dog</span><span class="p">))</span>  <span class="c1"># &lt;class '__main__.Dog'&gt;</span>
</code></pre></div>

<h3 id="使用-type-动态定义类">使用 <code>type()</code> 动态定义类</h3>
<p>类本身也是对象，<code>type()</code> 是创建类的内置函数。可以动态地创建类：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># type(类名, (父类元组,), {属性字典})</span>

<span class="c1"># 定义方法</span>
<span class="k">def</span><span class="w"> </span><span class="nf">bark</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="bp">self</span><span class="o">.</span><span class="n">name</span><span class="si">}</span><span class="s2"> says: Woof!"</span><span class="p">)</span>

<span class="c1"># 动态创建 Dog 类</span>
<span class="n">Dog</span> <span class="o">=</span> <span class="nb">type</span><span class="p">(</span><span class="s1">'Dog'</span><span class="p">,</span> <span class="p">(),</span> <span class="p">{</span><span class="s1">'name'</span><span class="p">:</span> <span class="s1">'Buddy'</span><span class="p">,</span> <span class="s1">'bark'</span><span class="p">:</span> <span class="n">bark</span><span class="p">})</span>

<span class="c1"># 创建实例</span>
<span class="n">my_dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">()</span>
<span class="nb">print</span><span class="p">(</span><span class="n">my_dog</span><span class="o">.</span><span class="n">name</span><span class="p">)</span>  <span class="c1"># Buddy</span>
<span class="n">my_dog</span><span class="o">.</span><span class="n">bark</span><span class="p">()</span>       <span class="c1"># Buddy says: Woof!</span>
</code></pre></div>

<p><strong>参数说明：</strong></p>
<ul>
<li>第一个参数：类名（字符串）</li>
<li>第二个参数：继承的父类元组</li>
<li>第三个参数：类属性和方法的字典</li>
</ul>
<p><strong>实际应用场景：</strong> 在 ORM 框架或需要根据配置动态生成类的场景中经常使用。</p>

<h2 id="构造方法-__init__">构造方法 <code>__init__</code></h2>
<p><code>__init__</code> 是类的构造方法，在创建对象时自动调用，用于初始化对象的属性：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="n">this</span><span class="p">,</span> <span class="n">name</span><span class="p">,</span> <span class="n">age</span><span class="p">):</span>
        <span class="n">this</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>
        <span class="n">this</span><span class="o">.</span><span class="n">age</span> <span class="o">=</span> <span class="n">age</span>

<span class="c1"># 创建对象时传入参数</span>
<span class="n">my_dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">,</span> <span class="mi">3</span><span class="p">)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">my_dog</span><span class="o">.</span><span class="n">name</span><span class="p">)</span>  <span class="c1"># Buddy</span>
<span class="nb">print</span><span class="p">(</span><span class="n">my_dog</span><span class="o">.</span><span class="n">age</span><span class="p">)</span>   <span class="c1"># 3</span>
</code></pre></div>

<p><strong>注意：</strong> <code>self</code> 代表对象本身，必须是第一个参数，但调用时不需要传。</p>

<h2 id="实例属性与类属性">实例属性与类属性</h2>
<h3 id="实例属性">实例属性</h3>
<p>每个对象独立的属性，通过 <code>self</code> 定义：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>  <span class="c1"># 实例属性</span>

<span class="n">dog1</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>
<span class="n">dog2</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Max"</span><span class="p">)</span>

<span class="nb">print</span><span class="p">(</span><span class="n">dog1</span><span class="o">.</span><span class="n">name</span><span class="p">)</span>  <span class="c1"># Buddy</span>
<span class="nb">print</span><span class="p">(</span><span class="n">dog2</span><span class="o">.</span><span class="n">name</span><span class="p">)</span>  <span class="c1"># Max</span>
</code></pre></div>

<h3 id="类属性">类属性</h3>
<p>所有对象共享的属性，在类内部直接定义：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">:</span>
    <span class="n">species</span> <span class="o">=</span> <span class="s2">"Canis familiaris"</span>  <span class="c1"># 类属性</span>

    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>

<span class="n">dog1</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>
<span class="n">dog2</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Max"</span><span class="p">)</span>

<span class="nb">print</span><span class="p">(</span><span class="n">dog1</span><span class="o">.</span><span class="n">species</span><span class="p">)</span>  <span class="c1"># Canis familiaris</span>
<span class="nb">print</span><span class="p">(</span><span class="n">dog2</span><span class="o">.</span><span class="n">species</span><span class="p">)</span>  <span class="c1"># Canis familiaris</span>

<span class="c1"># 修改类属性（通过类名）</span>
<span class="n">Dog</span><span class="o">.</span><span class="n">species</span> <span class="o">=</span> <span class="s2">"Canis lupus"</span>
<span class="nb">print</span><span class="p">(</span><span class="n">dog1</span><span class="o">.</span><span class="n">species</span><span class="p">)</span>  <span class="c1"># Canis lupus</span>
</code></pre></div>

<p><strong>访问规则：</strong> 实例属性通过 <code>self</code> 访问，类属性通过 <code>类名</code> 或 <code>self</code> 访问。</p>

<h2 id="实例方法">实例方法</h2>
<p>定义在类中的函数，第一个参数必须是 <code>self</code>：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>

    <span class="k">def</span><span class="w"> </span><span class="nf">bark</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="bp">self</span><span class="o">.</span><span class="n">name</span><span class="si">}</span><span class="s2"> says: Woof!"</span><span class="p">)</span>

<h2 id="类方法与静态方法">类方法与静态方法</h2>
<h3 id="类方法-classmethod">类方法 <code>@classmethod</code></h3>
<p>第一个参数是 <code>cls</code>，代表类本身，可以访问或修改类属性：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">:</span>

    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>
        <span class="n">Dog</span><span class="o">.</span><span class="n">count</span> <span class="o">+=</span> <span class="mi">1</span>

    <span class="nd">@classmethod</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">get_count</span><span class="p">(</span><span class="bp">cls</span><span class="p">):</span>
        <span class="k">return</span> <span class="bp">cls</span><span class="o">.</span><span class="n">count</span>

<span class="n">dog1</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>
<span class="n">dog2</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Max"</span><span class="p">)</span>

<span class="nb">print</span><span class="p">(</span><span class="n">Dog</span><span class="o">.</span><span class="n">get_count</span><span class="p">())</span>  <span class="c1"># 2</span>
</code></pre></div>

<h3 id="静态方法-staticmethod">静态方法 <code>@staticmethod</code></h3>
<p>不接收 <code>self</code> 或 <code>cls</code>，与普通函数类似，只是组织在类中：</p>

    <span class="nd">@staticmethod</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">is_even</span><span class="p">(</span><span class="n">n</span><span class="p">):</span>
        <span class="k">return</span> <span class="n">n</span> <span class="o">%</span> <span class="mi">2</span> <span class="o">==</span> <span class="mi">0</span>

<h2 id="继承">继承</h2>
<p>子类继承父类的属性和方法，并可以扩展或重写：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Animal</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>

    <span class="k">def</span><span class="w"> </span><span class="nf">speak</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"Some sound"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">(</span><span class="n">Animal</span><span class="p">):</span>  <span class="c1"># Dog 继承 Animal</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">speak</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>  <span class="c1"># 重写父类方法</span>
        <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="bp">self</span><span class="o">.</span><span class="n">name</span><span class="si">}</span><span class="s2"> says: Woof!"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">Cat</span><span class="p">(</span><span class="n">Animal</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">speak</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="bp">self</span><span class="o">.</span><span class="n">name</span><span class="si">}</span><span class="s2"> says: Meow!"</span><span class="p">)</span>

<span class="n">dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>
<span class="n">cat</span> <span class="o">=</span> <span class="n">Cat</span><span class="p">(</span><span class="s2">"Kitty"</span><span class="p">)</span>

<span class="n">dog</span><span class="o">.</span><span class="n">speak</span><span class="p">()</span>  <span class="c1"># Buddy says: Woof!</span>
<span class="n">cat</span><span class="o">.</span><span class="n">speak</span><span class="p">()</span>  <span class="c1"># Kitty says: Meow!</span>
</code></pre></div>

<h3 id="调用父类方法">调用父类方法</h3>
<p>使用 <code>super()</code> 调用父类的方法：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Animal</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>

<span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">(</span><span class="n">Animal</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">,</span> <span class="n">breed</span><span class="p">):</span>
        <span class="nb">super</span><span class="p">()</span><span class="o">.</span><span class="fm">__init__</span><span class="p">(</span><span class="n">name</span><span class="p">)</span>  <span class="c1"># 调用父类的 __init__</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">breed</span> <span class="o">=</span> <span class="n">breed</span>      <span class="c1"># 扩展新属性</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"Dog init"</span><span class="p">)</span>

<span class="nb">print</span><span class="p">(</span><span class="n">dog</span><span class="o">.</span><span class="n">name</span><span class="p">)</span>   <span class="c1"># Buddy</span>
<span class="nb">print</span><span class="p">(</span><span class="n">dog</span><span class="o">.</span><span class="n">breed</span><span class="p">)</span>  <span class="c1"># Golden Retriever</span>
</code></pre></div>

<h3 id="多继承">多继承</h3>
<p>Python 支持一个子类同时继承多个父类：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Flyable</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">fly</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"I can fly!"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">Swimmable</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">swim</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"I can swim!"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">Duck</span><span class="p">(</span><span class="n">Flyable</span><span class="p">,</span> <span class="n">Swimmable</span><span class="p">):</span>  <span class="c1"># 同时继承 Flyable 和 Swimmable</span>
    <span class="k">pass</span>

<span class="n">duck</span> <span class="o">=</span> <span class="n">Duck</span><span class="p">()</span>
<span class="n">duck</span><span class="o">.</span><span class="n">fly</span><span class="p">()</span>   <span class="c1"># I can fly!</span>
<span class="n">duck</span><span class="o">.</span><span class="n">swim</span><span class="p">()</span>  <span class="c1"># I can swim!</span>
</code></pre></div>

<h4 id="方法解析顺序MRO">方法解析顺序（MRO）</h4>
<p>当多个父类有同名方法时，Python 按照 <strong>MRO</strong>（Method Resolution Order）顺序查找：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">A</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">hello</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"Hello from A"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">B</span><span class="p">(</span><span class="n">A</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">hello</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"Hello from B"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">C</span><span class="p">(</span><span class="n">A</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="nf">hello</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"Hello from C"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">D</span><span class="p">(</span><span class="n">B</span><span class="p">,</span> <span class="n">C</span><span class="p">):</span>  <span class="c1"># MRO: D -&gt; B -&gt; C -&gt; A</span>
    <span class="k">pass</span>

<span class="n">d</span> <span class="o">=</span> <span class="n">D</span><span class="p">()</span>
<span class="n">d</span><span class="o">.</span><span class="n">hello</span><span class="p">()</span>  <span class="c1"># Hello from B（先找到 B 的方法）</span>

<span class="c1"># 查看 MRO 顺序</span>
<span class="nb">print</span><span class="p">(</span><span class="n">D</span><span class="o">.</span><span class="vm">__mro__</span><span class="p">)</span>
<span class="c1"># (&lt;class 'D'&gt;, &lt;class 'B'&gt;, &lt;class 'C'&gt;, &lt;class 'A'&gt;, &lt;class 'object'&gt;)</span>
</code></pre></div>

<h4 id="super-在多继承中的行为"><code>super()</code> 在多继承中的行为</h4>
<p><code>super()</code> 按照 MRO 顺序调用<strong>下一个</strong>类的方法，不一定是直接父类：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">A</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"A init"</span><span class="p">)</span>

<span class="k">class</span><span class="w"> </span><span class="nc">B</span><span class="p">(</span><span class="n">A</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"B init"</span><span class="p">)</span>
        <span class="nb">super</span><span class="p">()</span><span class="o">.</span><span class="fm">__init__</span><span class="p">()</span>  <span class="c1"># 调用 C 的 __init__，不是 A</span>

<span class="k">class</span><span class="w"> </span><span class="nc">C</span><span class="p">(</span><span class="n">A</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"C init"</span><span class="p">)</span>
        <span class="nb">super</span><span class="p">()</span><span class="o">.</span><span class="fm">__init__</span><span class="p">()</span>  <span class="c1"># 调用 A 的 __init__</span>

<span class="k">class</span><span class="w"> </span><span class="nc">D</span><span class="p">(</span><span class="n">B</span><span class="p">,</span> <span class="n">C</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"D init"</span><span class="p">)</span>
        <span class="nb">super</span><span class="p">()</span><span class="o">.</span><span class="fm">__init__</span><span class="p">()</span>  <span class="c1"># 调用 B 的 __init__</span>

<span class="n">D</span><span class="p">()</span>
<span class="c1"># 输出：</span>
<span class="c1"># D init</span>
<span class="c1"># B init</span>
<span class="c1"># C init</span>
<span class="c1"># A init</span>
</code></pre></div>

<p><strong>注意：</strong> 多继承虽然强大，但过度使用会使代码难以维护。通常优先考虑组合（Composition）代替多继承。</p>

<h2 id="访问控制">访问控制</h2>
<p>Python 没有严格的私有/公有，但以下划线约定访问权限：</p>
<table>
<thead>
<tr>
<th>命名方式</th>
<th>含义</th>
<th>访问建议</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>name</code></td>
<td>公有</td>
<td>可自由访问</td>
</tr>
<tr>
<td><code>_name</code></td>
<td>保护（约定）</td>
<td>建议不直接访问</td>
</tr>
<tr>
<td><code>__name</code></td>
<td>私有（名称改写）</td>
<td>外部难以直接访问</td>
</tr>
</tbody>
</table>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">BankAccount</span><span class="p">:</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">owner</span><span class="p">,</span> <span class="n">balance</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">owner</span> <span class="o">=</span> <span class="n">owner</span>          <span class="c1"># 公有</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">_balance</span> <span class="o">=</span> <span class="n">balance</span>     <span class="c1"># 保护</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">__password</span> <span class="o">=</span> <span class="s2">"123456"</span>  <span class="c1"># 私有（名称改写为 _BankAccount__password）</span>

    <span class="k">def</span><span class="w"> </span><span class="nf">deposit</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">amount</span><span class="p">):</span>
        <span class="k">if</span> <span class="n">amount</span> <span class="o">&gt;</span> <span class="mi">0</span><span class="p">:</span>
            <span class="bp">self</span><span class="o">.</span><span class="n">_balance</span> <span class="o">+=</span> <span class="n">amount</span>

    <span class="k">def</span><span class="w"> </span><span class="nf">get_balance</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="k">return</span> <span class="bp">self</span><span class="o">.</span><span class="n">_balance</span>

<span class="n">account</span> <span class="o">=</span> <span class="n">BankAccount</span><span class="p">(</span><span class="s2">"Alice"</span><span class="p">,</span> <span class="mi">1000</span><span class="p">)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">account</span><span class="o">.</span><span class="n">owner</span><span class="p">)</span>      <span class="c1"># Alice</span>
<span class="nb">print</span><span class="p">(</span><span class="n">account</span><span class="o">.</span><span class="n">_balance</span><span class="p">)</span>   <span class="c1"># 1000（可以访问，但不建议）</span>
<span class="c1"># print(account.__password)  # AttributeError！</span>
<span class="nb">print</span><span class="p">(</span><span class="n">account</span><span class="o">.</span><span class="n">_BankAccount__password</span><span class="p">)</span>  <span class="c1"># 123456（强行访问）</span>
</code></pre></div>

<p><strong>注意：</strong> Python 的访问控制基于约定，不是强制。</p>

<h3 id="isinstance"><code>isinstance()</code></h3>
<p>判断对象是否是指定类（或其子类）的实例：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>

<span class="nb">print</span><span class="p">(</span><span class="nb">isinstance</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="n">Dog</span><span class="p">))</span>      <span class="c1"># True</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">isinstance</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="n">Animal</span><span class="p">))</span>   <span class="c1"># True（Dog 继承 Animal）</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">isinstance</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="nb">str</span><span class="p">))</span>      <span class="c1"># False</span>

<span class="c1"># 支持元组形式，判断是否为多个类型之一</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">isinstance</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="p">(</span><span class="n">Dog</span><span class="p">,</span> <span class="n">Cat</span><span class="p">)))</span>   <span class="c1"># True</span>

</code></pre></div>

<p><strong>与 <code>type()</code> 的区别：</strong> <code>isinstance()</code> 会考虑继承关系，<code>type()</code> 不会。</p>

<h3 id="getattr"><code>getattr()</code></h3>
<p>获取对象的属性值，属性不存在时可返回默认值。<strong>会沿着继承链查找属性（包括实例属性、类属性、父类属性）：</strong></p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">Animal</span><span class="p">:</span>
    <span class="n">species</span> <span class="o">=</span> <span class="s2">"Animal"</span>

    <span class="k">def</span><span class="w"> </span><span class="nf">speak</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
        <span class="k">return</span> <span class="s2">"Some sound"</span>

<span class="k">class</span><span class="w"> </span><span class="nc">Dog</span><span class="p">(</span><span class="n">Animal</span><span class="p">):</span>
    <span class="k">def</span><span class="w"> </span><span class="fm">__init__</span><span class="p">(</span><span class="bp">self</span><span class="p">,</span> <span class="n">name</span><span class="p">):</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">name</span> <span class="o">=</span> <span class="n">name</span>

<span class="n">dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>

<span class="c1"># 查找实例属性</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">getattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"name"</span><span class="p">))</span>           <span class="c1"># Buddy</span>

<span class="c1"># 查找类属性</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">getattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"species"</span><span class="p">))</span>        <span class="c1"># Animal（继承自父类）</span>

<span class="c1"># 查找父类方法</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">getattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"speak"</span><span class="p">)())</span>       <span class="c1"># Some sound</span>

<span class="c1"># 属性不存在时，提供默认值</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">getattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"age"</span><span class="p">,</span> <span class="mi">3</span><span class="p">))</span>         <span class="c1"># 3（默认值）</span>

<span class="c1"># 等价于</span>
<span class="n">dog</span><span class="o">.</span><span class="n">name</span>
<span class="n">dog</span><span class="o">.</span><span class="n">species</span>
<span class="n">dog</span><span class="o">.</span><span class="n">speak</span><span class="p">()</span>
</code></pre></div>

<h3 id="setattr"><code>setattr()</code></h3>
<p>设置对象的属性值，属性不存在时会创建。<strong>如果父类定义了描述符（如 <code>@property.setter</code>）或 <code>__setattr__</code> 方法，会遵循继承链上的这些机制：</strong></p>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>

<span class="nb">setattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"age"</span><span class="p">,</span> <span class="mi">3</span><span class="p">)</span>

<div class="codehilite lang-python"><pre><span></span><code><span class="n">dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">(</span><span class="s2">"Buddy"</span><span class="p">)</span>

<span class="c1"># 继承的方法</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">hasattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"speak"</span><span class="p">))</span>      <span class="c1"># True（继承自 Animal）</span>

<span class="c1"># 不存在的属性</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">hasattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"age"</span><span class="p">))</span>        <span class="c1"># False</span>

<span class="c1"># 常用于安全地访问属性前进行检查</span>
<span class="k">if</span> <span class="nb">hasattr</span><span class="p">(</span><span class="n">dog</span><span class="p">,</span> <span class="s2">"name"</span><span class="p">):</span>

</code></pre></div>

<table>
<thead>
<tr>
<th>方法</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>__init__(data=None)</code></td>
<td>初始化空链表；<code>data</code> 可以是列表、元组或集合，其中的值会被初始化为链表的节点</td>
</tr>
<tr>
<td><code>traverse(callback)</code></td>
<td>遍历链表，对每个节点值调用 <code>callback(index, value)</code></td>
</tr>
<tr>
<td><code>__str__()</code></td>
<td>返回链表的字符串表示，如 <code>"1 -&gt; 2 -&gt; 3"</code></td>
</tr>
<tr>
<td><code>to_list()</code></td>
<td>将链表转换为 Python 列表并返回</td>
</tr>
<tr>
<td><code>append(value)</code></td>
<td>在链表尾部添加一个新节点</td>
</tr>
<tr>
<td><code>prepend(value)</code></td>
<td>在链表头部添加一个新节点</td>
</tr>
<tr>
<td><code>insert(index, value)</code></td>
<td>在指定索引位置插入新节点，索引从 0 开始</td>
</tr>
<tr>
<td><code>delete_by_value(value)</code></td>
<td>删除第一个值等于 <code>value</code> 的节点，返回是否删除成功</td>
</tr>
<tr>
<td><code>delete_by_index(index)</code></td>
<td>删除指定索引位置的节点，返回被删除的值，索引越界时返回 <code>None</code></td>
</tr>
<tr>
<td><code>find(value)</code></td>
<td>查找值等于 <code>value</code> 的节点，返回其索引，不存在返回 -1</td>
</tr>
<tr>
<td><code>get(index)</code></td>
<td>获取指定索引位置的值，索引越界时返回 <code>None</code></td>
</tr>
<tr>
<td><code>get_length()</code></td>
<td>返回链表长度</td>
</tr>
<tr>
<td><code>is_empty()</code></td>
<td>判断链表是否为空</td>
</tr>
