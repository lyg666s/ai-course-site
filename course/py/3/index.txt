<h3 id="三元运算符条件表达式">三元运算符（条件表达式）</h3>
<p>Python 的三元运算符（条件表达式）是一种简洁的 <code>if-else</code> 写法，用于在一行中根据条件选择不同的值。</p>
<p><strong>语法：</strong></p>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">结果</span> <span class="o">=</span> <span class="n">真值</span> <span class="k">if</span> <span class="n">条件</span> <span class="k">else</span> <span class="n">假值</span>
</code></pre></div>

<div class="codehilite lang-python"><pre><span></span><code><span class="n">score</span> <span class="o">=</span> <span class="mi">85</span>

<span class="c1"># 传统写法</span>
<span class="k">if</span> <span class="n">score</span> <span class="o">&gt;=</span> <span class="mi">60</span><span class="p">:</span>
    <span class="n">result</span> <span class="o">=</span> <span class="s2">"及格"</span>
<span class="k">else</span><span class="p">:</span>
    <span class="n">result</span> <span class="o">=</span> <span class="s2">"不及格"</span>

<span class="c1"># 三元运算符（更简洁）</span>
<span class="n">result</span> <span class="o">=</span> <span class="s2">"及格"</span> <span class="k">if</span> <span class="n">score</span> <span class="o">&gt;=</span> <span class="mi">60</span> <span class="k">else</span> <span class="s2">"不及格"</span>
<span class="nb">print</span><span class="p">(</span><span class="n">result</span><span class="p">)</span>  <span class="c1"># 及格</span>

<span class="c1"># 嵌套三元运算符（不推荐过度嵌套）</span>
<span class="n">age</span> <span class="o">=</span> <span class="mi">25</span>
<span class="n">category</span> <span class="o">=</span> <span class="s2">"青年"</span> <span class="k">if</span> <span class="n">age</span> <span class="o">&lt;</span> <span class="mi">40</span> <span class="k">else</span> <span class="p">(</span><span class="s2">"中年"</span> <span class="k">if</span> <span class="n">age</span> <span class="o">&lt;</span> <span class="mi">60</span> <span class="k">else</span> <span class="s2">"老年"</span><span class="p">)</span>
</code></pre></div>

<p><strong>注意：</strong> 三元运算符适合简单的条件判断，复杂的逻辑应使用传统的 <code>if-else</code> 结构以保持代码可读性。</p>

<h4 id="循环else子句">循环else子句</h4>
<p>循环可以带有一个<code>else</code>子句，当循环<strong>正常结束</strong>（没有被break中断）时执行。</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># while循环的else</span>
<span class="n">count</span> <span class="o">=</span> <span class="mi">0</span>
<span class="k">while</span> <span class="n">count</span> <span class="o">&lt;</span> <span class="mi">3</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">count</span><span class="p">)</span>
    <span class="n">count</span> <span class="o">+=</span> <span class="mi">1</span>
<span class="k">else</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"while循环正常完成"</span><span class="p">)</span>

<span class="c1"># 典型用法：查找元素</span>
<span class="n">num</span> <span class="o">=</span> <span class="mi">1</span>
<span class="k">while</span> <span class="n">num</span> <span class="o">&lt;=</span> <span class="mi">9</span><span class="p">:</span>
    <span class="k">if</span> <span class="n">num</span> <span class="o">==</span> <span class="mi">4</span><span class="p">:</span>
        <span class="nb">print</span><span class="p">(</span><span class="s2">"找到: 4"</span><span class="p">)</span>
        <span class="k">break</span>
    <span class="n">num</span> <span class="o">+=</span> <span class="mi">2</span>  <span class="c1"># 模拟遍历奇数1, 3, 5, 7, 9</span>
<span class="k">else</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"未找到: 4"</span><span class="p">)</span>  <span class="c1"># 会执行，因为4不在奇数序列中</span>
</code></pre></div>

<p><strong>重要区别：</strong>
- 循环被<code>break</code>中断 → <strong>不执行</strong>else
- 循环正常结束（包括<code>continue</code>）→ <strong>执行</strong>else</p>

<h3 id="作业三BMI-计算器">作业三：BMI 计算器</h3>
<p>编写一个 BMI 计算器程序，要求如下：</p>
<ol>
<li>
<p><strong>用户输入</strong>：通过 <code>input()</code> 函数获取用户的身高（单位：米）和体重（单位：千克）。</p>
</li>
<li>
<p><strong>计算 BMI</strong>：使用公式 <code>BMI = 体重(kg) / 身高(m)²</code> 计算 BMI 值。</p>
</li>
<li>
<p><strong>判断分类</strong>：根据 BMI 值判断身体状况（参考中国成人标准）：
   - BMI &lt; 18.5：偏瘦
   - 18.5 ≤ BMI &lt; 24：正常
   - 24 ≤ BMI &lt; 28：超重
   - BMI ≥ 28：肥胖</p>
</li>
<li>
<p><strong>输出结果</strong>：使用 f-string 格式化输出用户的 BMI 值和分类结果。</p>
</li>
<li>
<p><strong>健康建议</strong>：根据分类结果给出相应的健康建议，例如：
   - 偏瘦：建议适当增加营养摄入，进行适量运动
   - 正常：保持良好的生活习惯
   - 超重/肥胖：建议控制饮食，增加运动量</p>
</li>
</ol>
<p><strong>示例输出</strong>：</p>
<div class="codehilite"><pre><span></span><code>请输入您的身高（米）：1.75
请输入您的体重（千克）：70
您的 BMI 值为：22.86
身体状况：正常
建议：保持良好的生活习惯，继续保持！
</code></pre></div>
