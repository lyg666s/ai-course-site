16:T27ba,<h2 id="Python安装包">Python安装包</h2>
<p>Python安装包中包含以下核心组件：</p>
<ul>
<li>解释器：默认为<code>CPython</code></li>
<li>包管理器：<code>pip</code></li>
<li>标准库：<code>os、sys、urllib、pathlib、...</code></li>
<li>交互式终端：<code>REPL</code></li>
</ul>
<h3 id="Python发行版">Python发行版</h3>
<p>Python有很多的发行版，不同的发行版又有很多的版本</p>
<ul>
<li>
<p><strong>官方 Python (CPython)</strong>：C 语言原生实现，Python 标准参考版本，带 GIL，生态最全，日常开发默认首选</p>
</li>
<li>
<p><strong>ActivePython</strong>：商业公司打包的 CPython 发行版，企业级稳定适配，预装常用依赖，偏商用场景</p>
</li>
<li>
<p><strong>Anaconda</strong>：面向数据科学的全家桶 CPython，内置海量数据分析、AI 库，体积大，适合数据分析一站式环境</p>
</li>
<li><strong>Miniconda</strong>：Anaconda 极简精简版，仅保留 Python+conda 包管理器，无多余预装库，轻量灵活</li>
<li><strong>Miniforge</strong>：开源免费 conda 发行版，无 Anaconda 商业版权限制，社区维护，替代 Miniconda 首选</li>
<li><strong>Mambaforge</strong>：基于 Miniforge，把 conda 替换为极速 mamba 包管理器，安装依赖速度远超原生 conda</li>
<li><strong>Cinder</strong>：Meta 自研优化版 CPython，针对长驻服务、低延迟做运行时与 GC 优化，内部业务专用，通用性差</li>
<li><strong>Nogil</strong>：Python 官方无 GIL 自由线程版本，去除全局解释器锁，支持多线程真并行，适合多核并发场景</li>
<li><strong>PyPy</strong>：带 JIT 即时编译的 Python 解释器，纯 Python 代码运行速度远超 CPython，C 扩展库兼容性一般</li>
<li><strong>Jython</strong>：运行在 JVM 虚拟机上的 Python，可无缝调用 Java 类库，无 GIL，不兼容 C 语言扩展包</li>
<li><strong>IronPython</strong>：运行在.NET 平台上的 Python，可直接调用 C#/.NET 生态库，多用于 Windows 桌面与.NET 集成</li>
<li><strong>GraalPython/GraalPy</strong>：基于 GraalVM 的高性能 Python，自带强 JIT 优化，支持与 Java 等多语言互通</li>
<li><strong>Stackless Python</strong>：CPython 分支，自研无栈微协程，支持超高并发轻量任务，适合游戏、高并发服务场景</li>
<li><strong>MicroPython</strong>：极简裁剪版 Python，专为单片机、嵌入式 IoT 设备设计，体积小、占用内存极低</li>
</ul>
<h3 id="pyenv">pyenv</h3>

<h3 id="mac-安装-pyenv">mac 安装 pyenv</h3>

<h2 id="IDE">IDE</h2>
<ul>
<li><a href="https://www.jetbrains.com/pycharm/">PyCharm</a>: Python 专属 IDE，开箱即用，专为 Python 设计，官方内置了 python 开发的诸多功能。</li>
