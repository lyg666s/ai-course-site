18:T23c0,<p>Python 拥有庞大的第三方库生态，可以通过包管理工具 <code>pip</code> 来安装、升级、卸载和管理依赖。</p>
<h2 id="pip-概述">pip 概述</h2>
<p><code>pip</code> 是 Python 的官方包管理器，从 Python 3.4 开始自带。它从 <strong>PyPI（Python Package Index）</strong> 下载包，默认源为 <code>https://pypi.org</code>。</p>
<div class="codehilite lang-bash"><pre><span></span><code><span class="c1"># 查看 pip 版本</span>
pip<span class="w"> </span>--version

<span class="c1"># 查看帮助</span>
pip<span class="w"> </span><span class="nb">help</span>
</code></pre></div>

<blockquote>
<p>如果你同时安装了 Python 2 和 Python 3，可能需要用 <code>pip3</code> 代替 <code>pip</code>。或者使用 <code>python -m pip</code> 确保调用的是当前 Python 对应的 pip。</p>
</blockquote>

<h2 id="依赖管理">依赖管理</h2>

<p>在项目中使用 <code>requirements.txt</code> 记录所有依赖：</p>
<div class="codehilite lang-bash"><pre><span></span><code><span class="c1"># 生成当前环境的依赖列表</span>

</code></pre></div>

<p><code>requirements.txt</code> 文件内容示例：</p>
<div class="codehilite"><pre><span></span><code>requests==2.31.0
flask==3.0.0
numpy&gt;=1.24.0
</code></pre></div>

<div class="codehilite lang-bash"><pre><span></span><code>pip<span class="w"> </span>install<span class="w"> </span>-r<span class="w"> </span>requirements.txt
</code></pre></div>

<h2 id="虚拟环境">虚拟环境</h2>
<p>不同项目可能需要不同版本的依赖，使用虚拟环境可以隔离依赖：</p>
<div class="codehilite lang-bash"><pre><span></span><code><span class="c1"># 创建虚拟环境（Python 3.3+）</span>
python<span class="w"> </span>-m<span class="w"> </span>venv<span class="w"> </span>.venv

<span class="c1"># 激活虚拟环境</span>
<span class="c1"># macOS / Linux</span>
<span class="nb">source</span><span class="w"> </span>.venv/bin/activate

<span class="c1"># Windows</span>
.venv<span class="se">\S</span>cripts<span class="se">\a</span>ctivate

<span class="c1"># 激活后，pip 安装的包只在该环境中生效</span>
pip<span class="w"> </span>install<span class="w"> </span>requests

<span class="c1"># 退出虚拟环境</span>
deactivate
</code></pre></div>

<h3 id="使用-venv-管理项目依赖">使用 venv 管理项目依赖</h3>
<div class="codehilite lang-bash"><pre><span></span><code><span class="c1"># 1. 创建并激活虚拟环境</span>
python<span class="w"> </span>-m<span class="w"> </span>venv<span class="w"> </span>.venv
<span class="nb">source</span><span class="w"> </span>.venv/bin/activate

<span class="c1"># 2. 安装项目依赖</span>
pip<span class="w"> </span>install<span class="w"> </span>-r<span class="w"> </span>requirements.txt

<span class="c1"># 3. 开发完成后冻结依赖</span>
pip<span class="w"> </span>freeze<span class="w"> </span>&gt;<span class="w"> </span>requirements.txt

<span class="c1"># 4. 退出虚拟环境</span>
deactivate
</code></pre></div>

<blockquote>
<p>小知识：</p>
<ol>
<li><code>-m</code>表示python会按照模块的查找顺序查找模块运行</li>
<li><code>venv</code>的前身是一个第三方库<code>virtualenv</code>，从Python 3.3开始，官方将 <code>venv</code> 作为其功能的“精简版”集成到了标准库中，这样我们就不需要额外安装，开箱即用了。</li>
</ol>
