<h3 id="创建列表">创建列表</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 字面量创建</span>

<span class="n">nums2</span> <span class="o">=</span> <span class="nb">list</span><span class="p">((</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">))</span>  <span class="c1"># [1, 2, 3]</span>

<h3 id="索引与切片">索引与切片</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">fruits</span> <span class="o">=</span> <span class="p">[</span><span class="s2">"苹果"</span><span class="p">,</span> <span class="s2">"香蕉"</span><span class="p">,</span> <span class="s2">"橙子"</span><span class="p">,</span> <span class="s2">"葡萄"</span><span class="p">,</span> <span class="s2">"西瓜"</span><span class="p">]</span>

<span class="nb">print</span><span class="p">(</span><span class="n">fruits</span><span class="p">[</span><span class="mi">2</span><span class="p">:])</span>      <span class="c1"># ['橙子', '葡萄', '西瓜'] —— 从索引2到末尾</span>
<span class="nb">print</span><span class="p">(</span><span class="n">fruits</span><span class="p">[::</span><span class="mi">2</span><span class="p">])</span>     <span class="c1"># ['苹果', '橙子', '西瓜'] —— 从头到尾，每隔一个取一个,步长为2</span>

</code></pre></div>

<h2 id="元组tuple">元组（tuple）</h2>

<h3 id="创建元组">创建元组</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 字面量创建（圆括号可省略）</span>

<span class="n">empty</span> <span class="o">=</span> <span class="p">()</span>         <span class="c1"># 空元组</span>

<span class="c1"># 通过tuple()函数创建</span>
<span class="n">t</span> <span class="o">=</span> <span class="nb">tuple</span><span class="p">([</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">])</span>   <span class="c1"># (1, 2, 3)</span>
<span class="n">t</span> <span class="o">=</span> <span class="nb">tuple</span><span class="p">(</span><span class="s2">"abc"</span><span class="p">)</span>       <span class="c1"># ('a', 'b', 'c')</span>
</code></pre></div>

<h3 id="基本操作">基本操作</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">t</span> <span class="o">=</span> <span class="p">(</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">4</span><span class="p">)</span>

<span class="c1"># 索引和切片（与list相同）</span>

<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># + 连接（仅有序容器）</span>
<span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">]</span> <span class="o">+</span> <span class="p">[</span><span class="mi">3</span><span class="p">,</span> <span class="mi">4</span><span class="p">]</span>       <span class="c1"># [1, 2, 3, 4]</span>
<span class="p">(</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">)</span> <span class="o">+</span> <span class="p">(</span><span class="mi">3</span><span class="p">,</span> <span class="mi">4</span><span class="p">)</span>       <span class="c1"># (1, 2, 3, 4)</span>
<span class="s2">"hello "</span> <span class="o">+</span> <span class="s2">"world"</span>    <span class="c1"># "hello world"</span>
<span class="c1"># {1, 2} + {3, 4}    # TypeError! 集合不支持</span>

<span class="c1"># * 重复（仅有序容器）</span>
<span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">]</span> <span class="o">*</span> <span class="mi">3</span>            <span class="c1"># [1, 2, 1, 2, 1, 2]</span>
<span class="s2">"-"</span> <span class="o">*</span> <span class="mi">10</span>              <span class="c1"># "----------"</span>
</code></pre></div>

<h4 id="相等运算符">相等运算符：<code>==</code> / <code>!=</code></h4>
<p><code>==</code> 比较的是两个容器的内容是否<strong>相等</strong>，而非它们是否是同一个对象。</p>
<p><strong>比较逻辑：</strong></p>
<ol>
<li><strong>类型必须相同</strong>：不同类型的容器即使内容看起来一样，也视为不相等。<code>[1, 2] == (1, 2)</code> 结果为 <code>False</code>。</li>
<li><strong>长度必须相同</strong>：长度不同的容器一定不相等。</li>
<li><strong>逐元素比较</strong>：从第一个元素开始，依次比较对应位置的元素。对于嵌套容器，会<strong>递归</strong>地进行逐元素比较。</li>
<li><strong>元素使用自身的 <code>==</code></strong>：容器本身不定义元素如何相等，而是调用元素自身的 <code>__eq__</code> 方法。因此 <code>[1, 2] == [1.0, 2.0]</code> 为 <code>True</code>。</li>
</ol>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 基本比较</span>
<span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">]</span> <span class="o">==</span> <span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">]</span>        <span class="c1"># True，内容相同</span>
<span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">]</span> <span class="o">==</span> <span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">3</span><span class="p">,</span> <span class="mi">2</span><span class="p">]</span>        <span class="c1"># False，顺序不同</span>

<span class="c1"># 类型不同</span>
<span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">]</span> <span class="o">==</span> <span class="p">(</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">)</span>              <span class="c1"># False</span>

<span class="c1"># 嵌套容器递归比较</span>
<span class="p">[[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">],</span> <span class="p">[</span><span class="mi">3</span><span class="p">,</span> <span class="mi">4</span><span class="p">]]</span> <span class="o">==</span> <span class="p">[[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">],</span> <span class="p">[</span><span class="mi">3</span><span class="p">,</span> <span class="mi">4</span><span class="p">]]</span>  <span class="c1"># True</span>

<span class="c1"># 字典比较（键值对）</span>
<span class="p">{</span><span class="s2">"a"</span><span class="p">:</span> <span class="mi">1</span><span class="p">,</span> <span class="s2">"b"</span><span class="p">:</span> <span class="mi">2</span><span class="p">}</span> <span class="o">==</span> <span class="p">{</span><span class="s2">"b"</span><span class="p">:</span> <span class="mi">2</span><span class="p">,</span> <span class="s2">"a"</span><span class="p">:</span> <span class="mi">1</span><span class="p">}</span>  <span class="c1"># True，字典无序，键值对相同即可</span>
</code></pre></div>

<blockquote>
<p><strong>注意</strong>：<code>==</code> 比较的是<strong>值相等</strong>，不是<strong>身份相同</strong>（是否为内存中的同一个对象）。要判断身份，使用 <code>is</code>。</p>
</blockquote>
<h4 id="身份运算符is-is-not">身份运算符：<code>is</code> / <code>is not</code></h4>
<p><code>is</code> 用于判断两个变量是否指向<strong>内存中的同一个对象</strong>，即它们的 <code>id()</code> 是否相同。</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">a</span> <span class="o">=</span> <span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">]</span>
<span class="n">b</span> <span class="o">=</span> <span class="n">a</span>
<span class="n">c</span> <span class="o">=</span> <span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">]</span>

<span class="n">a</span> <span class="ow">is</span> <span class="n">b</span>        <span class="c1"># True，b 和 a 指向同一个列表对象</span>
<span class="n">a</span> <span class="ow">is</span> <span class="n">c</span>        <span class="c1"># False，c 是新创建的另一个对象，尽管内容相同</span>
<span class="n">a</span> <span class="o">==</span> <span class="n">c</span>        <span class="c1"># True，内容相等</span>

<span class="n">a</span> <span class="ow">is</span> <span class="ow">not</span> <span class="n">c</span>    <span class="c1"># True</span>
</code></pre></div>

<p><strong>常见使用场景：</strong></p>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 判断是否为 None（Python 推荐写法）</span>
<span class="n">value</span> <span class="o">=</span> <span class="kc">None</span>
<span class="k">if</span> <span class="n">value</span> <span class="ow">is</span> <span class="kc">None</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"值为空"</span><span class="p">)</span>

<span class="c1"># 判断单例对象</span>
<span class="n">x</span> <span class="o">=</span> <span class="kc">True</span>
<span class="n">x</span> <span class="ow">is</span> <span class="kc">True</span>     <span class="c1"># True</span>

<span class="c1"># 小整数缓存（Python 优化）</span>
<span class="n">a</span> <span class="o">=</span> <span class="mi">100</span>
<span class="n">b</span> <span class="o">=</span> <span class="mi">100</span>
<span class="n">a</span> <span class="ow">is</span> <span class="n">b</span>        <span class="c1"># True（-5 到 256 的整数会被缓存复用）</span>

<span class="n">x</span> <span class="o">=</span> <span class="mi">1000</span>
<span class="n">y</span> <span class="o">=</span> <span class="mi">1000</span>
<span class="n">x</span> <span class="ow">is</span> <span class="n">y</span>        <span class="c1"># False（通常，取决于解释器实现）</span>
</code></pre></div>

<blockquote>
<p><strong>重要区别</strong>：
- <code>==</code> 问的是"你们长得一样吗？"（值相等）
- <code>is</code> 问的是"你们就是同一个人吗？"（身份相同）
- 比较 <code>None</code> 时，<strong>永远使用 <code>is</code></strong>，而不是 <code>==</code></p>
</blockquote>
<h4 id="位运算符">位运算符：<code>&amp;</code>、<code>|</code>、<code>^</code>、<code>~</code></h4>
<p>对于<strong>集合（set）</strong>，位运算符有特殊的集合运算含义：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">s1</span> <span class="o">=</span> <span class="p">{</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">}</span>
<span class="n">s2</span> <span class="o">=</span> <span class="p">{</span><span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">,</span> <span class="mi">4</span><span class="p">}</span>

<span class="c1"># &amp; 交集（两个集合都有的元素）</span>
<span class="n">s1</span> <span class="o">&amp;</span> <span class="n">s2</span>       <span class="c1"># {2, 3}</span>

<span class="c1"># | 并集（两个集合所有的元素，去重）</span>
<span class="n">s1</span> <span class="o">|</span> <span class="n">s2</span>       <span class="c1"># {1, 2, 3, 4}</span>

<span class="c1"># - 差集（在 s1 中但不在 s2 中的元素）</span>
<span class="n">s1</span> <span class="o">-</span> <span class="n">s2</span>       <span class="c1"># {1}</span>
<span class="n">s2</span> <span class="o">-</span> <span class="n">s1</span>       <span class="c1"># {4}</span>

<span class="c1"># ^ 对称差集（只在其中一个集合中的元素）</span>
<span class="n">s1</span> <span class="o">^</span> <span class="n">s2</span>       <span class="c1"># {1, 4}</span>

<span class="c1"># ~ 不适用于集合，用于整数的按位取反</span>
</code></pre></div>

<p><strong>对比：位运算 vs 集合方法</strong></p>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">s1</span> <span class="o">=</span> <span class="p">{</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">}</span>
<span class="n">s2</span> <span class="o">=</span> <span class="p">{</span><span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">,</span> <span class="mi">4</span><span class="p">}</span>

<span class="c1"># 运算符写法</span>
<span class="n">s1</span> <span class="o">&amp;</span> <span class="n">s2</span>        <span class="c1"># {2, 3}</span>
<span class="n">s1</span> <span class="o">|</span> <span class="n">s2</span>        <span class="c1"># {1, 2, 3, 4}</span>
<span class="n">s1</span> <span class="o">-</span> <span class="n">s2</span>        <span class="c1"># {1}</span>
<span class="n">s1</span> <span class="o">^</span> <span class="n">s2</span>        <span class="c1"># {1, 4}</span>

<span class="c1"># 方法写法（等价）</span>
<span class="n">s1</span><span class="o">.</span><span class="n">intersection</span><span class="p">(</span><span class="n">s2</span><span class="p">)</span>      <span class="c1"># {2, 3}</span>
<span class="n">s1</span><span class="o">.</span><span class="n">union</span><span class="p">(</span><span class="n">s2</span><span class="p">)</span>             <span class="c1"># {1, 2, 3, 4}</span>
<span class="n">s1</span><span class="o">.</span><span class="n">difference</span><span class="p">(</span><span class="n">s2</span><span class="p">)</span>        <span class="c1"># {1}</span>
<span class="n">s1</span><span class="o">.</span><span class="n">symmetric_difference</span><span class="p">(</span><span class="n">s2</span><span class="p">)</span>  <span class="c1"># {1, 4}</span>
</code></pre></div>

<blockquote>
<p><strong>注意</strong>：位运算符只能用于<strong>集合（set）</strong>，不能用于 <code>list</code>、<code>tuple</code>、<code>dict</code> 等其他容器类型。</p>
</blockquote>
<h3 id="遍历容器">遍历容器</h3>
<h4 id="基本-for-循环">基本 for 循环</h4>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 遍历列表</span>
<span class="k">for</span> <span class="n">item</span> <span class="ow">in</span> <span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">]:</span>

<span class="c1"># 遍历元组</span>
<span class="k">for</span> <span class="n">char</span> <span class="ow">in</span> <span class="p">(</span><span class="s2">"a"</span><span class="p">,</span> <span class="s2">"b"</span><span class="p">,</span> <span class="s2">"c"</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">char</span><span class="p">)</span>

<span class="c1"># 遍历字符串</span>
<span class="k">for</span> <span class="n">ch</span> <span class="ow">in</span> <span class="s2">"hello"</span><span class="p">:</span>

<h4 id="遍历字典">遍历字典</h4>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">person</span> <span class="o">=</span> <span class="p">{</span><span class="s2">"name"</span><span class="p">:</span> <span class="s2">"Alice"</span><span class="p">,</span> <span class="s2">"age"</span><span class="p">:</span> <span class="mi">25</span><span class="p">,</span> <span class="s2">"city"</span><span class="p">:</span> <span class="s2">"北京"</span><span class="p">}</span>

<span class="c1"># 遍历键（默认）</span>

<span class="c1"># 仅遍历值</span>

    <span class="nb">print</span><span class="p">(</span><span class="n">value</span><span class="p">)</span>

<span class="c1"># 仅遍历键（显式）</span>
<span class="k">for</span> <span class="n">key</span> <span class="ow">in</span> <span class="n">person</span><span class="o">.</span><span class="n">keys</span><span class="p">():</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">key</span><span class="p">)</span>
</code></pre></div>

<h4 id="遍历集合">遍历集合</h4>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">s</span> <span class="o">=</span> <span class="p">{</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">}</span>

<h4 id="enumerate-函数"><code>enumerate()</code> 函数</h4>
<p>遍历容器时，如果需要同时获取索引和值，使用 <code>enumerate()</code>：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 基本用法</span>
<span class="n">fruits</span> <span class="o">=</span> <span class="p">[</span><span class="s2">"苹果"</span><span class="p">,</span> <span class="s2">"香蕉"</span><span class="p">,</span> <span class="s2">"橙子"</span><span class="p">]</span>
<span class="k">for</span> <span class="n">index</span><span class="p">,</span> <span class="n">fruit</span> <span class="ow">in</span> <span class="nb">enumerate</span><span class="p">(</span><span class="n">fruits</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="n">index</span><span class="si">}</span><span class="s2">: </span><span class="si">{</span><span class="n">fruit</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
<span class="c1"># 0: 苹果</span>
<span class="c1"># 1: 香蕉</span>
<span class="c1"># 2: 橙子</span>

<span class="c1"># 指定起始索引</span>
<span class="k">for</span> <span class="n">i</span><span class="p">,</span> <span class="n">v</span> <span class="ow">in</span> <span class="nb">enumerate</span><span class="p">(</span><span class="n">fruits</span><span class="p">,</span> <span class="n">start</span><span class="o">=</span><span class="mi">1</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="n">i</span><span class="si">}</span><span class="s2">. </span><span class="si">{</span><span class="n">v</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>
<span class="c1"># 1. 苹果</span>
<span class="c1"># 2. 香蕉</span>
<span class="c1"># 3. 橙子</span>
</code></pre></div>

<h4 id="zip-函数"><code>zip()</code> 函数</h4>
<p>并行遍历多个容器，元素按位置一一配对：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">names</span> <span class="o">=</span> <span class="p">[</span><span class="s2">"Alice"</span><span class="p">,</span> <span class="s2">"Bob"</span><span class="p">,</span> <span class="s2">"Charlie"</span><span class="p">]</span>
<span class="n">ages</span> <span class="o">=</span> <span class="p">[</span><span class="mi">25</span><span class="p">,</span> <span class="mi">30</span><span class="p">,</span> <span class="mi">35</span><span class="p">]</span>
<span class="n">cities</span> <span class="o">=</span> <span class="p">[</span><span class="s2">"北京"</span><span class="p">,</span> <span class="s2">"上海"</span><span class="p">,</span> <span class="s2">"广州"</span><span class="p">]</span>

<span class="k">for</span> <span class="n">name</span><span class="p">,</span> <span class="n">age</span><span class="p">,</span> <span class="n">city</span> <span class="ow">in</span> <span class="nb">zip</span><span class="p">(</span><span class="n">names</span><span class="p">,</span> <span class="n">ages</span><span class="p">,</span> <span class="n">cities</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="n">name</span><span class="si">}</span><span class="s2"> 今年 </span><span class="si">{</span><span class="n">age</span><span class="si">}</span><span class="s2"> 岁，住在 </span><span class="si">{</span><span class="n">city</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>

<span class="c1"># zip 以最短容器为准</span>
