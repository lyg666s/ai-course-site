<h2 id="异步生成器与异步迭代器">异步生成器与异步迭代器</h2>

<p>gather 的特点：</p>
<ul>
<li>所有协程<strong>并发</strong>执行</li>
<li>返回结果顺序与传入顺序一致</li>
<li>任何一个协程抛出异常，gather 会立即传播异常（其他协程仍会继续运行）</li>
<li>可通过 <code>return_exceptions=True</code> 让异常以结果形式返回，不中断 gather</li>
</ul>

        <span class="n">loop</span><span class="o">.</span><span class="n">add_signal_handler</span><span class="p">(</span><span class="n">signal</span><span class="o">.</span><span class="n">SIGINT</span><span class="p">,</span> <span class="n">signal_handler</span><span class="p">)</span>  <span class="c1"># Ctrl+C</span>
        <span class="n">loop</span><span class="o">.</span><span class="n">add_signal_handler</span><span class="p">(</span><span class="n">signal</span><span class="o">.</span><span class="n">SIGTERM</span><span class="p">,</span> <span class="n">signal_handler</span><span class="p">)</span>  <span class="c1"># 终止信号</span>

        <span class="n">task</span> <span class="o">=</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">create_task</span><span class="p">(</span><span class="bp">self</span><span class="o">.</span><span class="n">serve</span><span class="p">())</span>
        <span class="k">await</span> <span class="n">stop</span>  <span class="c1"># 等待关闭信号</span>
        <span class="bp">self</span><span class="o">.</span><span class="n">shutdown</span><span class="p">()</span>
        <span class="n">task</span><span class="o">.</span><span class="n">cancel</span><span class="p">()</span>
        <span class="k">await</span> <span class="n">task</span>


<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">main</span><span class="p">():</span>
    <span class="n">server</span> <span class="o">=</span> <span class="n">GracefulServer</span><span class="p">()</span>
    <span class="k">await</span> <span class="n">server</span><span class="o">.</span><span class="n">run</span><span class="p">()</span>


<span class="c1"># 按 Ctrl+C 触发 SIGINT，程序会优雅退出而非直接崩溃</span>
<span class="n">asyncio</span><span class="o">.</span><span class="n">run</span><span class="p">(</span><span class="n">main</span><span class="p">())</span>
</code></pre></div>

<h2 id="最佳实践与注意事项">最佳实践与注意事项</h2>
<h3 id="1-不要在协程中调用同步阻塞函数">1. 不要在协程中调用同步阻塞函数</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">time</span>


<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">bad</span><span class="p">():</span>
    <span class="n">time</span><span class="o">.</span><span class="n">sleep</span><span class="p">(</span><span class="mi">1</span><span class="p">)</span>  <span class="c1"># 错误！将阻塞整个事件循环</span>


<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">good</span><span class="p">():</span>
    <span class="k">await</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">sleep</span><span class="p">(</span><span class="mi">1</span><span class="p">)</span>  <span class="c1"># 正确！主动让出控制权</span>


<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">acceptable</span><span class="p">():</span>
    <span class="k">await</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">to_thread</span><span class="p">(</span><span class="n">time</span><span class="o">.</span><span class="n">sleep</span><span class="p">,</span> <span class="mi">1</span><span class="p">)</span>  <span class="c1"># 可行！让线程池去阻塞</span>
</code></pre></div>

<h3 id="2-始终使用-asynciorun-作为入口">2. 始终使用 asyncio.run 作为入口</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 错误：手动管理事件循环</span>
<span class="n">loop</span> <span class="o">=</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">new_event_loop</span><span class="p">()</span>
<span class="n">asyncio</span><span class="o">.</span><span class="n">set_event_loop</span><span class="p">(</span><span class="n">loop</span><span class="p">)</span>
<span class="n">task</span> <span class="o">=</span> <span class="n">loop</span><span class="o">.</span><span class="n">create_task</span><span class="p">(</span><span class="n">main</span><span class="p">())</span>
<span class="n">loop</span><span class="o">.</span><span class="n">run_forever</span><span class="p">()</span>

<span class="c1"># 正确：asyncio.run 自动创建和关闭事件循环</span>
<span class="n">asyncio</span><span class="o">.</span><span class="n">run</span><span class="p">(</span><span class="n">main</span><span class="p">())</span>
</code></pre></div>

<h3 id="3-小心协程对象未被-await">3. 小心协程对象未被 await</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">main</span><span class="p">():</span>
    <span class="c1"># 错误：创建了协程但未 await，协程永远不会执行</span>
    <span class="n">fetch</span><span class="p">(</span><span class="s2">"url"</span><span class="p">,</span> <span class="mi">1</span><span class="p">)</span>

    <span class="c1"># 正确</span>
    <span class="k">await</span> <span class="n">fetch</span><span class="p">(</span><span class="s2">"url"</span><span class="p">,</span> <span class="mi">1</span><span class="p">)</span>

    <span class="c1"># 或通过 gather</span>
    <span class="k">await</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">gather</span><span class="p">(</span><span class="n">fetch</span><span class="p">(</span><span class="s2">"url1"</span><span class="p">,</span> <span class="mi">1</span><span class="p">),</span> <span class="n">fetch</span><span class="p">(</span><span class="s2">"url2"</span><span class="p">,</span> <span class="mi">2</span><span class="p">))</span>
</code></pre></div>

<h3 id="4-gather-异常处理">4. gather 异常处理</h3>
<p>gather 默认任何协程异常都会立即传播，其他协程不会取消，但结果丢失</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">main</span><span class="p">():</span>
    <span class="c1"># 方式一：使用 return_exceptions=True</span>
    <span class="n">results</span> <span class="o">=</span> <span class="k">await</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">gather</span><span class="p">(</span>
        <span class="n">risky_task</span><span class="p">(),</span>
        <span class="n">safe_task</span><span class="p">(),</span>
        <span class="n">return_exceptions</span><span class="o">=</span><span class="kc">True</span><span class="p">,</span>
    <span class="p">)</span>
    <span class="k">for</span> <span class="n">r</span> <span class="ow">in</span> <span class="n">results</span><span class="p">:</span>
        <span class="k">if</span> <span class="nb">isinstance</span><span class="p">(</span><span class="n">r</span><span class="p">,</span> <span class="ne">Exception</span><span class="p">):</span>
            <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"某个任务失败: </span><span class="si">{</span><span class="n">r</span><span class="si">}</span><span class="s2">"</span><span class="p">)</span>

    <span class="c1"># 方式二：使用 TaskGroup（Python 3.11+）</span>
    <span class="c1"># 任一异常会取消组内所有任务</span>
</code></pre></div>

<h3 id="5-使用-debug-模式">5. 使用 debug 模式</h3>
<p>asyncio 的 debug 模式可以帮助你发现异步代码中的常见问题，比如协程阻塞事件循环、忘记 await、回调执行时间过长等。</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 开启 asyncio 调试模式</span>
<span class="n">asyncio</span><span class="o">.</span><span class="n">run</span><span class="p">(</span><span class="n">main</span><span class="p">(),</span> <span class="n">debug</span><span class="o">=</span><span class="kc">True</span><span class="p">)</span>

<span class="c1"># 或通过环境变量</span>
<span class="c1"># PYTHONASYNCIODEBUG=1 python script.py</span>
</code></pre></div>

<h4 id="检测长时间阻塞的协程">检测长时间阻塞的协程</h4>
<p>debug 模式下，事件循环会监控每个协程的执行时间。如果某个协程执行超过 0.1 秒（默认阈值），会在 stderr 输出警告：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">time</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">asyncio</span>

<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">blocking_coroutine</span><span class="p">():</span>
<span class="w">    </span><span class="sd">"""模拟一个协程内部做了同步阻塞操作"""</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"开始阻塞操作..."</span><span class="p">)</span>
    <span class="n">time</span><span class="o">.</span><span class="n">sleep</span><span class="p">(</span><span class="mf">0.2</span><span class="p">)</span>  <span class="c1"># 同步阻塞，会阻塞整个事件循环</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"阻塞操作结束"</span><span class="p">)</span>


<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">main</span><span class="p">():</span>
    <span class="k">await</span> <span class="n">blocking_coroutine</span><span class="p">()</span>


<span class="n">asyncio</span><span class="o">.</span><span class="n">run</span><span class="p">(</span><span class="n">main</span><span class="p">(),</span> <span class="n">debug</span><span class="o">=</span><span class="kc">True</span><span class="p">)</span>
</code></pre></div>

<p>输出类似：</p>
<div class="codehilite"><pre><span></span><code>开始阻塞操作...
阻塞操作结束
Executor &lt;TaskInfo name='Task-1' ...&gt; running at (...)
    blocking_coroutine at demo.py:12
    main at demo.py:18
    ...
</code></pre></div>

<p><code>time.sleep(0.2)</code> 是同步阻塞，但 debug 模式下检测到协程在同一个位置停留超过 0.1 秒，会打印出执行栈信息，精确定位阻塞的代码行。</p>
<h4 id="检测未-await-的协程对象">检测未 await 的协程对象</h4>
<p>忘记 <code>await</code> 协程是新手最容易犯的错误，debug 模式会检测到协程对象被创建但从未被迭代：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">asyncio</span>


<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">fetch_data</span><span class="p">(</span><span class="n">url</span><span class="p">:</span> <span class="nb">str</span><span class="p">)</span> <span class="o">-&gt;</span> <span class="nb">str</span><span class="p">:</span>
    <span class="k">await</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">sleep</span><span class="p">(</span><span class="mf">0.5</span><span class="p">)</span>
    <span class="k">return</span> <span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="n">url</span><span class="si">}</span><span class="s2"> 数据"</span>


<span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">main</span><span class="p">():</span>
    <span class="c1"># 忘记 await，协程对象永远不会执行</span>
    <span class="n">fetch_data</span><span class="p">(</span><span class="s2">"https://example.com"</span><span class="p">)</span>

    <span class="k">await</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">sleep</span><span class="p">(</span><span class="mi">1</span><span class="p">)</span>


<span class="n">asyncio</span><span class="o">.</span><span class="n">run</span><span class="p">(</span><span class="n">main</span><span class="p">(),</span> <span class="n">debug</span><span class="o">=</span><span class="kc">True</span><span class="p">)</span>
</code></pre></div>

<p>输出类似：</p>
<div class="codehilite"><pre><span></span><code>Coroutine 'fetch_data' was never awaited (at demo.py:12)
</code></pre></div>

<p>这个警告在你忘记 <code>await</code> 时非常有用，避免协程"静默丢失"。</p>
<h4 id="自定义慢操作阈值">自定义慢操作阈值</h4>
<p>通过 <code>loop.slow_callback_duration</code> 调整检测阈值：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">main</span><span class="p">():</span>
    <span class="n">loop</span> <span class="o">=</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">get_running_loop</span><span class="p">()</span>
    <span class="n">loop</span><span class="o">.</span><span class="n">slow_callback_duration</span> <span class="o">=</span> <span class="mf">0.5</span>  <span class="c1"># 改为 0.5 秒才报警</span>

    <span class="k">def</span><span class="w"> </span><span class="nf">acceptable_callback</span><span class="p">():</span>
        <span class="n">time</span><span class="o">.</span><span class="n">sleep</span><span class="p">(</span><span class="mf">0.3</span><span class="p">)</span>  <span class="c1"># 0.3 秒，低于自定义阈值，不会报警</span>

    <span class="n">loop</span><span class="o">.</span><span class="n">call_later</span><span class="p">(</span><span class="mf">0.1</span><span class="p">,</span> <span class="n">acceptable_callback</span><span class="p">)</span>
    <span class="k">await</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">sleep</span><span class="p">(</span><span class="mf">0.5</span><span class="p">)</span>


<span class="n">asyncio</span><span class="o">.</span><span class="n">run</span><span class="p">(</span><span class="n">main</span><span class="p">(),</span> <span class="n">debug</span><span class="o">=</span><span class="kc">True</span><span class="p">)</span>
</code></pre></div>

<h3 id="6-避免全局事件循环">6. 避免全局事件循环</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># 错误：在模块级别获取事件循环</span>
<span class="n">loop</span> <span class="o">=</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">get_event_loop</span><span class="p">()</span>  <span class="c1"># 可能获取到错误的事件循环</span>

    <span class="n">loop</span> <span class="o">=</span> <span class="n">asyncio</span><span class="o">.</span><span class="n">get_running_loop</span><span class="p">()</span>

<h3 id="7-CancelledError-的正确处理">7. CancelledError 的正确处理</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">async</span> <span class="k">def</span><span class="w"> </span><span class="nf">cleanup</span><span class="p">():</span>
    <span class="k">try</span><span class="p">:</span>
