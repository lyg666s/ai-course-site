<p>迭代器是实现了<code>__iter__</code>和<code>__next__</code>方法的对象</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">class</span><span class="w"> </span><span class="nc">MyIterator</span><span class="p">:</span>

    <span class="k">def</span><span class="w"> </span><span class="fm">__iter__</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
<span class="w">        </span><span class="sd">"""</span>
<span class="sd">        要求：必须返回迭代器</span>

<span class="sd">        """</span>
        <span class="k">return</span> <span class="bp">self</span>

    <span class="k">def</span><span class="w"> </span><span class="fm">__next__</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>

<h2 id="可迭代对象Iterable">可迭代对象(Iterable)</h2>
<p><strong>可迭代协议规定，只要一个对象实现了 <code>__iter__()</code> 方法，且返回一个迭代器，则它就是可迭代对象</strong></p>
<p>推理可知：<strong>迭代器一定是可迭代对象</strong></p>
<blockquote>
<p>python中的容器类型都是可迭代对象</p>
</blockquote>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">my_list</span> <span class="o">=</span> <span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="mi">2</span><span class="p">,</span> <span class="mi">3</span><span class="p">]</span>

<span class="c1"># 调用 iter() 获取迭代器</span>
<span class="n">iterator</span> <span class="o">=</span> <span class="nb">iter</span><span class="p">(</span><span class="n">my_list</span><span class="p">)</span>  <span class="c1"># 等价于 my_list.__iter__()</span>

<span class="nb">print</span><span class="p">(</span><span class="nb">type</span><span class="p">(</span><span class="n">iterator</span><span class="p">))</span>     <span class="c1"># &lt;class 'list_iterator'&gt;</span>

<span class="c1"># 使用 next() 逐个获取值</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">next</span><span class="p">(</span><span class="n">iterator</span><span class="p">))</span>     <span class="c1"># 1</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">next</span><span class="p">(</span><span class="n">iterator</span><span class="p">))</span>     <span class="c1"># 2</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">next</span><span class="p">(</span><span class="n">iterator</span><span class="p">))</span>     <span class="c1"># 3</span>

<span class="c1"># print(next(iterator))   # StopIteration! 没有更多元素了</span>
</code></pre></div>

<h3 id="range函数">range函数</h3>
<p><code>range()</code> 是 Python 中最常用的可迭代对象之一，用于生成整数序列：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># range(stop): 0 到 stop-1</span>
<span class="k">for</span> <span class="n">i</span> <span class="ow">in</span> <span class="nb">range</span><span class="p">(</span><span class="mi">5</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">i</span><span class="p">,</span> <span class="n">end</span><span class="o">=</span><span class="s2">" "</span><span class="p">)</span>  <span class="c1"># 0 1 2 3 4</span>

<span class="c1"># range(start, stop): start 到 stop-1</span>
<span class="k">for</span> <span class="n">i</span> <span class="ow">in</span> <span class="nb">range</span><span class="p">(</span><span class="mi">2</span><span class="p">,</span> <span class="mi">6</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">i</span><span class="p">,</span> <span class="n">end</span><span class="o">=</span><span class="s2">" "</span><span class="p">)</span>  <span class="c1"># 2 3 4 5</span>

<span class="c1"># range(start, stop, step): 指定步长</span>
<span class="k">for</span> <span class="n">i</span> <span class="ow">in</span> <span class="nb">range</span><span class="p">(</span><span class="mi">0</span><span class="p">,</span> <span class="mi">10</span><span class="p">,</span> <span class="mi">2</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">i</span><span class="p">,</span> <span class="n">end</span><span class="o">=</span><span class="s2">" "</span><span class="p">)</span>  <span class="c1"># 0 2 4 6 8</span>

<span class="c1"># 负数步长（倒序）</span>
<span class="k">for</span> <span class="n">i</span> <span class="ow">in</span> <span class="nb">range</span><span class="p">(</span><span class="mi">5</span><span class="p">,</span> <span class="mi">0</span><span class="p">,</span> <span class="o">-</span><span class="mi">1</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">i</span><span class="p">,</span> <span class="n">end</span><span class="o">=</span><span class="s2">" "</span><span class="p">)</span>  <span class="c1"># 5 4 3 2 1</span>
</code></pre></div>

<p><strong>重要特性：</strong></p>
<ol>
<li><strong>惰性计算</strong>：<code>range</code> 不会一次性生成所有数字，而是按需生成</li>
<li><strong>支持索引和切片</strong>：与列表不同，<code>range</code> 支持随机访问</li>
</ol>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">r</span> <span class="o">=</span> <span class="nb">range</span><span class="p">(</span><span class="mi">0</span><span class="p">,</span> <span class="mi">100</span><span class="p">,</span> <span class="mi">2</span><span class="p">)</span>

<span class="nb">print</span><span class="p">(</span><span class="nb">len</span><span class="p">(</span><span class="n">r</span><span class="p">))</span>      <span class="c1"># 50</span>
<span class="nb">print</span><span class="p">(</span><span class="n">r</span><span class="p">[</span><span class="mi">5</span><span class="p">])</span>        <span class="c1"># 10</span>
<span class="nb">print</span><span class="p">(</span><span class="n">r</span><span class="p">[</span><span class="mi">0</span><span class="p">:</span><span class="mi">5</span><span class="p">])</span>      <span class="c1"># range(0, 10, 2)</span>
<span class="nb">print</span><span class="p">(</span><span class="mi">10</span> <span class="ow">in</span> <span class="n">r</span><span class="p">)</span>     <span class="c1"># True</span>
<span class="nb">print</span><span class="p">(</span><span class="mi">11</span> <span class="ow">in</span> <span class="n">r</span><span class="p">)</span>     <span class="c1"># False</span>
</code></pre></div>

<ol start="3">
<li><strong>不是迭代器</strong>：<code>range</code> 是可迭代对象，但不是迭代器（可以重复使用）</li>
</ol>
<div class="codehilite lang-python"><pre><span></span><code><span class="n">r</span> <span class="o">=</span> <span class="nb">range</span><span class="p">(</span><span class="mi">3</span><span class="p">)</span>

<span class="k">for</span> <span class="n">i</span> <span class="ow">in</span> <span class="n">r</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">i</span><span class="p">,</span> <span class="n">end</span><span class="o">=</span><span class="s2">" "</span><span class="p">)</span>  <span class="c1"># 0 1 2</span>
<span class="nb">print</span><span class="p">()</span>

<span class="k">for</span> <span class="n">i</span> <span class="ow">in</span> <span class="n">r</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">i</span><span class="p">,</span> <span class="n">end</span><span class="o">=</span><span class="s2">" "</span><span class="p">)</span>  <span class="c1"># 0 1 2（可以再次遍历）</span>
</code></pre></div>

<blockquote>
<p><code>range</code> 对象在内存中只存储 <code>start</code>、<code>stop</code>、<code>step</code> 三个值，无论范围多大都占用固定内存</p>
</blockquote>

<h2 id="生成器Generator">生成器(Generator)</h2>
<h3 id="生成器函数">生成器函数</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># Python识别到这个函数中包含yield的关键字，因此该函数是一个生成器函数。</span>
<span class="k">def</span><span class="w"> </span><span class="nf">simple_generator</span><span class="p">():</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"开始"</span><span class="p">)</span>
    <span class="k">yield</span> <span class="mi">1</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"继续"</span><span class="p">)</span>
    <span class="k">yield</span> <span class="mi">2</span>
    <span class="nb">print</span><span class="p">(</span><span class="s2">"结束"</span><span class="p">)</span>
    <span class="k">yield</span> <span class="mi">3</span>


<span class="n">g</span> <span class="o">=</span> <span class="n">simple_generator</span><span class="p">()</span> <span class="c1"># 生成器函数返回的是生成器，生成器是一个迭代器。</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">next</span><span class="p">(</span><span class="n">g</span><span class="p">))</span>  <span class="c1"># 开始</span>
                <span class="c1"># 1</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">next</span><span class="p">(</span><span class="n">g</span><span class="p">))</span>  <span class="c1"># 继续</span>
                <span class="c1"># 2</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">next</span><span class="p">(</span><span class="n">g</span><span class="p">))</span>  <span class="c1"># 结束</span>
                <span class="c1"># 3</span>
<span class="c1"># print(next(g))  # StopIteration!</span>
</code></pre></div>

<p>可以利用生成器这种简易写法，快速完成迭代器的编写。</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">def</span><span class="w"> </span><span class="nf">countdown</span><span class="p">(</span><span class="n">start</span><span class="p">):</span>
<span class="w">    </span><span class="sd">"""生成器函数"""</span>
    <span class="k">while</span> <span class="n">start</span> <span class="o">&gt;=</span> <span class="mi">0</span><span class="p">:</span>
        <span class="k">yield</span> <span class="n">start</span>
        <span class="n">start</span> <span class="o">-=</span> <span class="mi">1</span>


<span class="c1"># 调用生成器函数，返回生成器</span>
<span class="n">cd</span> <span class="o">=</span> <span class="n">countdown</span><span class="p">(</span><span class="mi">5</span><span class="p">)</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">type</span><span class="p">(</span><span class="n">cd</span><span class="p">))</span>       <span class="c1"># &lt;class 'generator'&gt;</span>

<span class="k">for</span> <span class="n">n</span> <span class="ow">in</span> <span class="n">cd</span><span class="p">:</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">n</span><span class="p">,</span> <span class="n">end</span><span class="o">=</span><span class="s2">" "</span><span class="p">)</span>  <span class="c1"># 5 4 3 2 1 0</span>
</code></pre></div>

<p><strong>生成器的特点：</strong></p>
<ol>
<li><strong>惰性计算</strong>：只在需要时生成值，不占用大量内存</li>
<li><strong>状态保存</strong>：每次 <code>yield</code> 后暂停，下次从暂停处继续</li>
<li><strong>一次性</strong>：和迭代器一样，只能遍历一次</li>
</ol>
<h3 id="链式调用">链式调用</h3>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">def</span><span class="w"> </span><span class="nf">sub_generator</span><span class="p">():</span>
    <span class="k">yield</span> <span class="mi">1</span>
    <span class="k">yield</span> <span class="mi">2</span>


<span class="k">def</span><span class="w"> </span><span class="nf">main_generator</span><span class="p">():</span>
    <span class="k">yield</span> <span class="s2">"开始"</span>
    <span class="k">for</span> <span class="n">value</span> <span class="ow">in</span> <span class="n">sub_generator</span><span class="p">():</span>
        <span class="k">yield</span> <span class="n">value</span>
    <span class="k">yield</span> <span class="s2">"结束"</span>


<span class="k">for</span> <span class="n">value</span> <span class="ow">in</span> <span class="n">main_generator</span><span class="p">():</span>
    <span class="nb">print</span><span class="p">(</span><span class="n">value</span><span class="p">)</span>
<span class="c1"># 开始</span>
<span class="c1"># 1</span>
<span class="c1"># 2</span>
<span class="c1"># 结束</span>
</code></pre></div>

<p>可使用<code>yield from</code> 语法糖简化代码：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">def</span><span class="w"> </span><span class="nf">main_generator</span><span class="p">():</span>
    <span class="k">yield</span> <span class="s2">"开始"</span>
    <span class="k">yield from</span> <span class="n">sub_generator</span><span class="p">()</span>  <span class="c1"># 委托给子生成器</span>
    <span class="k">yield</span> <span class="s2">"结束"</span>
</code></pre></div>

<h3 id="发送数据">发送数据</h3>
<p>当调用生成器的<code>send</code>函数的时候，可以向生成器发送数据，该数据会导致<code>yield</code>的表达式返回对应的值。</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="k">def</span><span class="w"> </span><span class="nf">calculator</span><span class="p">():</span>
    <span class="n">total</span> <span class="o">=</span> <span class="mi">0</span>
    <span class="k">while</span> <span class="kc">True</span><span class="p">:</span>
        <span class="n">x</span> <span class="o">=</span> <span class="k">yield</span> <span class="n">total</span>  <span class="c1"># yield 返回当前总数，并接收新值</span>
        <span class="k">if</span> <span class="n">x</span> <span class="ow">is</span> <span class="kc">None</span><span class="p">:</span>
            <span class="k">break</span>
        <span class="n">total</span> <span class="o">+=</span> <span class="n">x</span>

<span class="n">calc</span> <span class="o">=</span> <span class="n">calculator</span><span class="p">()</span>
<span class="nb">print</span><span class="p">(</span><span class="nb">next</span><span class="p">(</span><span class="n">calc</span><span class="p">))</span>      <span class="c1"># 输出: 0 (启动)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">calc</span><span class="o">.</span><span class="n">send</span><span class="p">(</span><span class="mi">10</span><span class="p">))</span>   <span class="c1"># 输出: 10 (发送10，累加后返回)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">calc</span><span class="o">.</span><span class="n">send</span><span class="p">(</span><span class="mi">20</span><span class="p">))</span>   <span class="c1"># 输出: 30</span>
<span class="nb">print</span><span class="p">(</span><span class="n">calc</span><span class="o">.</span><span class="n">send</span><span class="p">(</span><span class="mi">5</span><span class="p">))</span>    <span class="c1"># 输出: 35</span>
</code></pre></div>
