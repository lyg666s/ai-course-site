<h3 id="使用-type-动态定义类">使用 <code>type()</code> 动态定义类</h3>
<p>类本身也是对象，<code>type()</code> 是创建类的内置函数。可以动态地创建类：</p>
<div class="codehilite lang-python"><pre><span></span><code><span class="c1"># type(类名, (父类元组,), {属性字典})</span>

<span class="c1"># 定义方法</span>
<span class="k">def</span><span class="w"> </span><span class="nf">bark</span><span class="p">(</span><span class="bp">self</span><span class="p">):</span>
    <span class="nb">print</span><span class="p">(</span><span class="sa">f</span><span class="s2">"</span><span class="si">{</span><span class="bp">self</span><span class="o">.</span><span class="n">name</span><span class="si">}</span><span class="s2"> says: Woof!"</span><span class="p">)</span>

<span class="c1"># 动态创建 Dog 类</span>
<span class="n">Dog</span> <span class="o">=</span> <span class="nb">type</span><span class="p">(</span><span class="s1">'Dog'</span><span class="p">,</span> <span class="p">(),</span> <span class="p">{</span><span class="s1">'name'</span><span class="p">:</span> <span class="s1">'Buddy'</span><span class="p">,</span> <span class="s1">'bark'</span><span class="p">:</span> <span class="n">bark</span><span class="p">})</span>

<span class="c1"># 创建实例</span>
<span class="n">my_dog</span> <span class="o">=</span> <span class="n">Dog</span><span class="p">()</span>
<span class="nb">print</span><span class="p">(</span><span class="n">my_dog</span><span class="o">.</span><span class="n">name</span><span class="p">)</span>  <span class="c1"># Buddy</span>
<span class="n">my_dog</span><span class="o">.</span><span class="n">bark</span><span class="p">()</span>       <span class="c1"># Buddy says: Woof!</span>
</code></pre></div>

<p><strong>参数说明：</strong></p>
<ul>
<li>第一个参数：类名（字符串）</li>
<li>第二个参数：继承的父类元组</li>
<li>第三个参数：类属性和方法的字典</li>
</ul>
<p><strong>实际应用场景：</strong> 在 ORM 框架或需要根据配置动态生成类的场景中经常使用。</p>
