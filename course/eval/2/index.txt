18:T11aa,<h1 id="安装-langfuse">安装 langfuse</h1>
<p>官网：https://langfuse.com/</p>
<h2 id="准备工作">准备工作</h2>
<ol>
<li>
<p>停用所有<code>postgresql</code>、<code>redis</code>服务，避免端口号冲突</p>
</li>
<li>
<p>使用<code>git clone</code>克隆<code>langfuse</code>项目到本地</p>
</li>
</ol>
<p><code>shell
   # 最近版本
   git clone https://github.com/langfuse/langfuse.git
   # 指定版本
   git clone --branch v4.30.0 --single-branch --depth 1 https://github.com/langfuse/langfuse.git</code></p>
<ol start="3">
<li>进入目录，新建环境变量文件<code>.env</code>，配置如下：</li>
</ol>
<p>```yaml
   # [可选]对导出启用S3对象存储
   LANGFUSE_S3_BATCH_EXPORT_ENABLED=true</p>
<p># [可选]配置事务邮件发送
   # Langfuse 对外访问地址，用于生成邀请和密码重置链接
   NEXTAUTH_URL=""
   # 发件人地址，必须是邮件服务商允许发送的地址
   EMAIL_FROM_ADDRESS=""
   # SMTP SSL，通常使用 465 端口
   SMTP_CONNECTION_URL=""</p>
<p># [可选]设置AI提供商
   LANGFUSE_AI_PROVIDER=openai
   LANGFUSE_AI_MODEL=qwen3.7-plus
   LANGFUSE_AI_API_KEY=
   LANGFUSE_AI_BASE_URL=
   ```</p>
<h2 id="容器管理">容器管理</h2>
<p><code>langfuse</code>已为你写好了容器编排脚本：<code>docker-compose.yml</code></p>
<p>以下命令需要在<code>langfuse</code>项目根目录中执行。</p>
<div class="codehilite lang-shell"><pre><span></span><code><span class="c1"># 创建并在后台启动所有容器</span>
docker<span class="w"> </span>compose<span class="w"> </span>up<span class="w"> </span>-d

<span class="c1"># 查看容器状态</span>
docker<span class="w"> </span>compose<span class="w"> </span>ps

<span class="c1"># 持续查看所有容器的日志，按 Ctrl+C 退出</span>
docker<span class="w"> </span>compose<span class="w"> </span>logs<span class="w"> </span>-f

<span class="c1"># 停止容器，但保留容器</span>
docker<span class="w"> </span>compose<span class="w"> </span>stop

<span class="c1"># 启动已经停止的容器</span>
docker<span class="w"> </span>compose<span class="w"> </span>start

<span class="c1"># 重启所有容器</span>
docker<span class="w"> </span>compose<span class="w"> </span>restart

<span class="c1"># 停止并删除容器和网络，不会删除数据卷</span>
docker<span class="w"> </span>compose<span class="w"> </span>down

<span class="c1"># 重新创建并在后台启动所有容器</span>
docker<span class="w"> </span>compose<span class="w"> </span>up<span class="w"> </span>-d<span class="w"> </span>--force-recreate
</code></pre></div>
