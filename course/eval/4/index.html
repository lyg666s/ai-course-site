Observation

我的理解基于本章内容 · 站点补充

Observation 是 Trace 里的节点，type 决定控制台如何解释它，status、耗时和成本决定如何分析它。排障时先看 type 与父子关系，再看输入输出，比一上来翻日志更有效。

Observation

Control Plane

在langfuse控制面中，可以通过Observation的属性来筛选行列

Type

每个Observation带有一个type字段，type 主要负责两件事：

  1. 用于筛选、统计和评估。

  2. 告诉 Langfuse 控制面应该如何展示和解释这条 Observation。

langfuse支持的type如下：

  • agent：负责决策应用流程，并在大模型的指导下编排工具等步骤。

graph_id中包含 agent 时自动上报。

  • chain：连接不同应用步骤。

graph_id不包含agent时，以及其他未知步骤会被识别为chain

  • generation：一次大模型生成

调用 Chat Model 或 LLM 时自动上报。

  • tool：执行工具。

LangChain Tool 被实际执行时自动上报

  • retriever：从向量库、数据库或其他知识源中执行只读的数据检索。

调用 LangChain Retriever 时自动上报。

  • event：用于记录 Trace 中某个时间点发生的离散事件。

不会自动上报，需要通过 Langfuse SDK 单独记录。

  • span：一段通用的、有开始和结束时间的工作。

不会自动上报，手动上报时自行标记为 span。

  • evaluator：评估大模型输出的相关性、正确性或有用性。

不会自动上报，LangChain 评估链通常仍会上报为 chain，需要手动标记为 evaluator。

  • embedding：调用模型生成向量，可以记录模型、Token 用量和费用。

不会自动上报，通过 LangChain Embeddings 生成向量时也需要手动标记为 embedding。

  • guardrail：检查并拦截恶意内容、越狱攻击或不符合规则的输入输出。

不会自动上报，需要通过 Langfuse SDK 手动标记为 guardrail。

Name

自动上报时，Observation 的 name 来自 Runnable 的 name 值：

  • Tool：工具名称，例如 search_web
  • Model：模型类名，例如 ChatOpenAI
  • LangGraph 节点：通常是节点名称
  • Chain/Agent：graph_id的名称

另外有一个Trace Name，通常情况下，用根Observation代表一个Trace，将其Trace Name设置为Name的值，其他Observation留空

ID

  • 每个Observation都会归属于一个Trace ID
  • 通常会将根Observation归属于一个User ID和Session ID

time

  • Start Time：起始时间
  • Latency：总耗时

Environment

自动上报时，会读取环境变量LANGFUSE_TRACING_ENVIRONMENT的值作为上报环境。

比如：LANGFUSE_TRACING_ENVIRONMENT=development，则上报的Observation的Environment为development

Status

对应日志级别：

  • Status
  • DEBUG: 自动上报通常不会产生此状态
  • DEFAULT: 无错误的自动上报都会使用此状态。
  • WARNING: 自动上报通常不会产生此状态。
  • ERROR: 发生错误时会使用此状态。
  • Status Message: 通常用于保存异常信息。

Costs

Cost 可以评估大模型调用时产生的成本。该功能依赖模型配置。

配置位置：settings/Model Definitions

导出

你可以将筛选出来的Observation导出，以供将来分析。

导出依赖环境变量的配置

LANGFUSE_S3_BATCH_EXPORT_ENABLED=true

Ask AI

当你不知道怎么筛选的时候，可以询问AI，让它帮你生成筛选条件。

该功能依赖环境变量的配置。

# 设置AI提供商
LANGFUSE_AI_PROVIDER=
LANGFUSE_AI_MODEL=
LANGFUSE_AI_API_KEY=
LANGFUSE_AI_BASE_URL=

Comment

你可以给每一个观测添加评论，并根据评论来进行筛选。
