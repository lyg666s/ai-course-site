核心定义：图片和代码整体保留；表格保留第一行表头，按数据行逐行切片；页面和章节正文优先按段落、再按句子切分，控制字符数并保留 overlap，不截断引用占位符。

<span class="p">)</span> <span class="o">-&gt;</span> <span class="nb">list</span><span class="p">[</span><span class="n">Document</span><span class="p">]:</span> <span class="o">...</span>
<span class="sb">```</span>

<span class="k">-</span><span class="w"> </span>docs 是上一节 load_feishu_doc_structre 的输出，包含页面、章节、图片、表格和代码 Document；输入 Document.id 等于 metadata.block_id，且 ID 非空、不重复。
<span class="k">-</span><span class="w"> </span>长度统一使用字符数：chunk_size 是切片长度上限，chunk_overlap 是相邻正文切片的目标重叠长度。要求二者为整数，chunk_size &gt; 0，0 &lt;= chunk_overlap &lt; chunk_size。
<span class="k">-</span><span class="w"> </span>返回 list[Document]；按输入 Document 顺序输出，同一来源的切片按正文顺序排列。空列表返回空列表。
<span class="k">-</span><span class="w"> </span>不修改输入 Documents 或 metadata，不重新读取飞书、不重新构树、不修改上一节 loader 的接口和结构提取规则。

<span class="gu">## 图片与代码</span>

<span class="k">-</span><span class="w"> </span>kind 为 image 或 code 时，一份输入 Document 对应一个 chunk，page_content 原封不动保留。
<span class="k">-</span><span class="w"> </span>不裁剪图片描述、不拆分代码，不改变代码缩进、换行或围栏；即使长度超过 chunk_size，也保持完整。
<span class="k">-</span><span class="w"> </span>不下载图片，不调用视觉模型。图片描述或代码中的普通标签示例，不当成新增结构引用。

<span class="gu">## 页面与章节正文</span>

<span class="k">-</span><span class="w"> </span>kind 为 page 或 heading 时，短 Document 保留一片，过长才继续切分。
<span class="k">-</span><span class="w"> </span>每片开头保留完整 title_path 对应的 Markdown 标题路径，只重复标题上下文，不复制父章节正文或展开子文档内容。
<span class="k">-</span><span class="w"> </span>优先沿段落边界切分并组合；单段过长时按句子继续切，考虑中文和英文句末标点。单句仍过长时才沿换行、空白和字符继续细分。
<span class="k">-</span><span class="w"> </span>保留原文、顺序和分隔符；除标题重复及 overlap 外，不重复或遗漏正文。空正文、只有标题或只有占位符的 Document 也要保留。
<span class="k">-</span><span class="w"> </span>同一来源的相邻正文切片保留 overlap，不跨来源 Document 重叠。overlap 是目标上限，受自然边界和完整占位符约束，实际可能更小或为零。
<span class="k">-</span><span class="w"> </span>重复标题、完整占位符和 overlap 均计入最终字符数。标题使正文无可用预算，或单个完整占位符超过正文预算时，明确抛出 ValueError，不截断、不静默返回超限正文片。

<span class="gu">## 占位符与引用</span>

上一节的占位符形式如下：

<span class="sb">```html</span>
<span class="p">&lt;</span><span class="nt">document-ref</span> <span class="na">id</span><span class="o">=</span><span class="s">"子文档ID"</span> <span class="na">kind</span><span class="o">=</span><span class="s">"子文档kind"</span><span class="p">&gt;</span>可读标签<span class="p">&lt;/</span><span class="nt">document-ref</span><span class="p">&gt;</span>
<span class="sb">```</span>

<span class="k">-</span><span class="w"> </span>完整占位符作为不可拆分单元，包括切分边界和 overlap 边界；不能丢失或截断标签、属性、标签文本及转义字符。
<span class="k">-</span><span class="w"> </span>可以临时保护占位符，但长度必须按还原后的完整文本计算，输出中不得残留临时标记。
<span class="k">-</span><span class="w"> </span>每片 references 只记录该片正文实际包含的引用，按首次出现顺序去重；每项继续只包含 id、kind、placeholder。
<span class="k">-</span><span class="w"> </span>overlap、重复表头或跨行合并展开带入的完整占位符，也要出现在该片 references 中。
<span class="k">-</span><span class="w"> </span>references.id 和 parent_document_id 继续表示来源 block_id，通过切片的 metadata.block_id 分组关联；不要改成某个随机切片的 ID，也不要要求原始 Document 必须额外入库。

<span class="gu">## 表格</span>

<span class="k">-</span><span class="w"> </span>kind 为 table 时，解析上一节生成的 HTML 表格，本节明确将第一物理行作为表头，不改变 loader 本身的表头约定。
<span class="k">-</span><span class="w"> </span>每个数据物理行形成一片，内容为“完整标题路径＋第一行表头＋当前数据行”，不把多行数据合为一片，不做表格 overlap。
<span class="k">-</span><span class="w"> </span>保留列顺序、空单元格、单元格内容和完整引用占位符；表格前后的已有说明文字也要保留。
<span class="k">-</span><span class="w"> </span>横向合并保留 colspan；纵向合并将原单元格内容补到它覆盖的各行，去除跨行的 rowspan，使每个行片可以独立理解。不丢弃原合并信息，原 payload 保留不变。
<span class="k">-</span><span class="w"> </span>校验 HTML 行列及合并关系与原表尺寸一致；缺失单元格、合并越界或重叠时明确报错。
<span class="k">-</span><span class="w"> </span>只有表头时仍保留一片；“标题＋表头＋单行数据”超过 chunk_size 时明确报错，不继续拆单元格或截断内容。

<span class="gu">## ID 与 Metadata</span>

<span class="k">-</span><span class="w"> </span>一个来源只生成一片时保留原 Document.id；生成多片时，ID 为 <span class="sb">`&lt;block_id&gt;::chunk:&lt;chunk_index&gt;`</span>，序号从 0 开始。检查来源与输出之间的 ID 冲突，不生成随机 ID。
<span class="k">-</span><span class="w"> </span>metadata.block_id 始终表示来源节点，同一来源的多个切片可以相同；不新增重复的 source_document_id。
<span class="k">-</span><span class="w"> </span>每片独立深拷贝原 metadata，保留外部附加信息及原有八个字段。其中 references 按实际切片内容更新，其余字段保留来源结构含义：
<span class="w">  </span><span class="k">-</span><span class="w"> </span>block_id、block_type、kind：仍然表示来源节点。
<span class="w">  </span><span class="k">-</span><span class="w"> </span>payload：仍然表示原始节点信息，不改成切片尺寸。
<span class="w">  </span><span class="k">-</span><span class="w"> </span>order：仍然表示来源 Document 的顺序，不改成全局切片序号。
<span class="w">  </span><span class="k">-</span><span class="w"> </span>parent_document_id、title_path：保留来源父关系和标题路径。
<span class="k">-</span><span class="w"> </span>所有切片只新增 chunk_index 和 chunk_count，分别表示来源内的切片序号和切片总数；未拆分时为 0 和 1。
<span class="k">-</span><span class="w"> </span>表格切片再新增 table_row_index，表示原表物理行号：表头为 0，第一条数据行为 1；只有表头时为 0。
<span class="k">-</span><span class="w"> </span>输入已有 chunk_index、chunk_count 或 table_row_index 时，明确抛出 ValueError，不静默覆盖。不同切片与输入之间不得共享可变 metadata。

<span class="gu">## 实现边界</span>

<span class="k">-</span><span class="w"> </span>复用现有 LangChain Document 和 langchain-text-splitters；HTML 表格解析可复用已有 BeautifulSoup4。不为本节安装新依赖。
<span class="k">-</span><span class="w"> </span>入口保持简短，可在同目录拆分正文切分、引用保护和表格处理辅助模块，不限定内部类名。
<span class="k">-</span><span class="w"> </span>对非法参数、来源 ID 不一致或重复、未知 kind、占位符与 references 不一致及非法表格明确报错，不伪装成功或返回部分结果。
<span class="k">-</span><span class="w"> </span>不执行模型调用、向量化、索引、检索或入库；保留无关改动，按接口与行为变化同步维护相关 AGENTS.md。
