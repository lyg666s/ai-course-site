RAG完整流程

我的理解基于本章内容 · 站点补充

RAG 分成索引和检索生成两段：Document 规格化、切片、向量化、入库；问题向量化、相似度召回、拼上下文、生成。每一段都可评估，排障时要先判断是「没检索到」还是「检索到但没答好」。

文档内容规格化

将任何格式的文档转换为统一格式。

在langchain中，这种统一格式为：langchain_core.documents:Document

from langchain_core.documents import Document
# 一个 Document 表示一个文档片段 
Document(
    page_content="这种行为引出了另一种有趣的能力：可以将前面的参数作为后面参数的默认值，这里有个例子：",
    metadata={"source": "resource/ECMA.pdf", "page": 48}
)

import pypdf

pdf_path = "../resource/ECMA.pdf"

reader = pypdf.PdfReader(pdf_path)

len(reader.pages)

[
    page.extract_text()
    for i, page in enumerate(reader.pages)
    if i < 3
]

docs = [
    Document(
        page_content=page.extract_text(),
        metadata={"source": pdf_path, "page": i+1}
    )
    for i, page in enumerate(reader.pages)
]

len(docs)

docs[:3]

切片

from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size = 1000, # 每片最大字符量
    chunk_overlap = 200, # 相邻切片字符重叠量,
    add_start_index = True
)

chunks = splitter.split_documents(docs)

len(chunks)

chunks[10:13]

向量化

embeddings = OpenAIEmbeddings(
