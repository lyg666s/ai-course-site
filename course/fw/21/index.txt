18:T246d,<h1 id="部署-认识Docker">部署-认识Docker</h1>
<h2 id="运行时的问题">运行时的问题</h2>
<p>你有一个从git拉取下来的FastAPI应用的全部源码。</p>
<p>如果你要在一个崭新的操作系统上启动它，需要做哪些事情？</p>
<details> 
  <summary>📖 查看参考答案</summary> 
  <ol>
    <li>安装Python</li>
    <li>从镜像源安装uv</li>
    <li>设置uv镜像源</li>
    <li>安装运行时依赖：uv sync --frozen --no-dev --no-editable</li>
    <li>删除除.venv外的全部文件</li>
    <li>启动服务：uvicorn api.main:app --host 0.0.0.0 --port 8080</li>
  </ol> 
</details>

<p>这些操作涉及到：</p>
<ul>
<li>准备环境</li>
<li>准备必须的文件</li>
<li>启动命令</li>
</ul>
<p>越是复杂的应用，需要安装的前置软件就越多，需要准备文件的过程就越复杂。</p>
<p>如果一台服务器中需要跑多个应用：</p>
<ul>
<li>如何才能保证不同的应用环境互不干扰？</li>
<li>如何才能保证每一次在服务器端准备环境和文件的过程快捷而高效？</li>
<li>如何才能保证当应用更新过后，当环境和必须的文件发生变化过后，快速的更新？</li>
</ul>
<p>这就是Docker要解决的问题。</p>
<h2 id="Docker">Docker</h2>
<p><img loading="lazy" alt="image-20260702135701716" src="https://resource.duyiedu.com/yuanjin/202608012025285.png" /></p>
<h3 id="Dockerfile">Dockerfile</h3>
<p>一个配置文件，通过该文件产生一个镜像</p>

<h3 id="镜像">镜像</h3>
<p>包含运行所需要的一切，比如<code>python</code>、<code>uv</code>、<code>.venv</code></p>
<h3 id="容器">容器</h3>
<p>通过镜像启动，启动时会运行镜像中的<code>CMD</code></p>
<div class="codehilite lang-shell"><pre><span></span><code>docker<span class="w"> </span>run<span class="w"> </span>-d<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>--name<span class="w"> </span>my-app<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-p<span class="w"> </span><span class="m">9090</span>:8080<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>-e<span class="w"> </span><span class="nv">environment</span><span class="o">=</span>production<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>--restart<span class="w"> </span>unless-stopped<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>--memory<span class="o">=</span>512m<span class="w"> </span><span class="se">\</span>
<span class="w">  </span>--cpus<span class="o">=</span><span class="m">1</span><span class="w"> </span><span class="se">\</span>
<span class="w">  </span>&lt;镜像名&gt;:&lt;tag&gt;
</code></pre></div>

<ul>
<li><strong><code>-d</code> (detach)</strong>: <strong>后台运行容器</strong>。这是生产环境中最常用的参数，让容器在后台默默运行，并把容器ID返回给你。</li>
<li><strong><code>--name</code></strong>: <strong>给容器起个名字</strong>。如果不指定，Docker 会随机生成一个名字。</li>
<li><strong><code>-p 9090:8080</code> (publish)</strong>: <strong>端口映射</strong>。将宿主机的 <code>9090</code> 端口，映射到容器内部的 <code>8080</code> 端口。</li>
<li><code>-e environment=production</code> 设置环境变量。</li>
<li><strong><code>--restart unless-stopped</code></strong>: <strong>重启策略</strong>。告诉 Docker 当容器意外退出或宿主机重启时，自动重新启动容器（除非你手动停止了它）。</li>
<li><strong><code>--memory=512m</code> / <code>--cpus=1</code></strong>: <strong>资源限制</strong>。限制容器最多只能使用 512MB 内存和 1 个 CPU 核心，防止单个容器耗尽宿主机所有资源。</li>
</ul>
