<h2 id="核心概念">核心概念</h2>
<h3 id="WSGI-vs-ASGI"><code>WSGI</code> vs <code>ASGI</code></h3>
<p><code>WSGI / ASGI</code>是一套<code>Python</code>的社区规范，主要为<strong>Web服务器</strong>和<strong>Web应用程序</strong>提供统一的交互标准</p>
<p><img loading="lazy" alt="image-20260605143504189" src="https://resource.duyiedu.com/yuanjin/202606051435295.png" /></p>
<p>其中，<code>WSGI</code>是一个早期标准，用于<strong>多线程</strong>处理请求任务，<code>ASGI</code>是一个现代标准，用于<strong>异步</strong>处理请求任务。</p>
<p>理解<code>ASGI</code>关键是要理解：</p>
<ol>
<li><code>ASGI</code>服务器在做什么？</li>
<li><code>ASGI</code>应用程序在做什么？</li>
<li>服务器和应用程序如何对接？</li>
</ol>
<h4 id="ASGI服务器">ASGI服务器</h4>
<p>主要负责：</p>
<ul>
<li><code>socket</code>通信</li>
<li>端口监听</li>
<li>接受新的客户端连接</li>
<li>从 socket 读取原始字节流</li>
<li>将响应字节流写回 socket</li>
<li>报文解析</li>
<li>解析 HTTP/1.1、HTTP/2、WebSocket 协议</li>
<li>将原始字节（如 <code>b'GET /users/123 HTTP/1.1\r\n...'</code>）转换成结构化数据（如 method、path、headers）</li>
<li>处理分块传输、Keep-Alive、管道化等协议细节</li>
<li>实现和启动事件循环</li>
<li>管理进程和线程</li>
<li>...</li>
</ul>

<h4 id="ASGI应用程序">ASGI应用程序</h4>
<p>主要负责：业务逻辑</p>
<p>常见<code>ASGI</code>应用框架：<code>Django</code>、<code>FastAPI</code>、<code>starlette</code>、<code>...</code></p>
<h4 id="如何对接">如何对接</h4>
<p><code>ASGI</code>标准规定，<code>ASGI</code>应用程序必须通过<code>ASGI</code>服务器启动，启动时，<code>ASGI</code>应用程序必须对外暴露一个可调用对象：<code>app</code></p>
<div class="codehilite lang-python lang-norun"><pre><span></span><code><span class="c1"># app规格</span>
<span class="n">app</span><span class="p">(</span><span class="n">scope</span><span class="p">,</span> <span class="n">receive</span><span class="p">,</span> <span class="n">send</span><span class="p">)</span> <span class="o">-&gt;</span> <span class="n">CoroutineType</span><span class="p">:</span>
<span class="w">    </span><span class="sd">"""</span>
<span class="sd">    ASGI 应用程序的调用签名</span>

<span class="sd">    参数:</span>
<span class="sd">        scope (dict): 包含连接上下文信息的字典</span>
<span class="sd">                      - type: 连接类型，如 "http", "websocket", "lifespan"</span>
<span class="sd">                      - path: 请求路径 (http)</span>
<span class="sd">                      - method: 请求方法 (http)</span>
<span class="sd">                      - headers: 请求头列表</span>
<span class="sd">                      - ... 其他协议相关字段</span>

<span class="sd">        receive (callable): 异步无参数函数，用于接收消息</span>
<span class="sd">                            await receive() -&gt; dict</span>
<span class="sd">                            用于获取请求体 (http) 或客户端消息 (websocket)</span>

<span class="sd">        send (callable): 异步单参数函数，用于发送消息</span>
<span class="sd">                         await send(message)</span>
<span class="sd">                        用于发送响应头/体 (http) 或服务端消息 (websocket)</span>
<span class="sd">    """</span>
    <span class="c1"># 应用程序逻辑</span>
    <span class="k">pass</span>
</code></pre></div>

<h4 id="完整流程">完整流程</h4>
<ol>
<li>ASGI服务器监听端口</li>
<li>请求到达ASGI服务器</li>
<li>处理字节流</li>
<li>构建scope字典</li>
<li>定义send函数</li>
<li>定义receive函数</li>
<li>调用<code>app</code></li>
<li>请求进入ASGI应用程序（期间调用<code>receive</code>和<code>send</code>）</li>
<li>ASGI框架调用预定义的程序（路由）</li>
<li>处理业务逻辑</li>
<li>控制权交给ASGI服务器</li>
<li>组装完整响应报文</li>
<li>发送响应给客户端</li>
</ol>
<h3 id="Swagger-UI-vs-Redoc"><code>Swagger UI</code> vs <code>Redoc</code></h3>
<p>OpenAPI规范指的是用一个标准的JSON格式来描述API接口</p>
<p>试试这个地址：http://localhost:8080/openapi.json</p>
<blockquote>
<p><code>openapi.json</code> 遵循的标准是 <strong>OpenAPI 规范 (OpenAPI Specification, OAS)</strong>。</p>
<p>这个规范最初由 <strong>Swagger</strong> 工具集的创建者 <strong>Tony Tam</strong> 于 2010 年发起，当时被称为 <strong>Swagger 规范</strong>。为了让其成为行业通用标准，Swagger 规范的核心被捐赠给了 <strong>Linux 基金会</strong>，并于 2015 年成立了 <strong>OpenAPI 倡议 (OpenAPI Initiative, OAI)</strong> 来专门负责它的演进和管理。从 3.0 版本开始，这个规范正式更名为 <strong>OpenAPI 规范</strong>。</p>
</blockquote>
<p>当首次启动时，<code>FastAPI</code>会自动生成<code>openapi.json</code>，并将其暴露到<code>/openapi.json</code>路由中</p>

<h3 id="Pydantic">Pydantic</h3>
<p>官方网站：https://pydantic.dev/</p>
<p><code>Pydantic</code> 是一个全能的<strong>数据建模与处理框架</strong>，它的核心功能是实现数据校验和转换，从而确保数据的高可用</p>
<div class="codehilite lang-python lang-norun"><pre><span></span><code><span class="kn">from</span><span class="w"> </span><span class="nn">datetime</span><span class="w"> </span><span class="kn">import</span> <span class="n">datetime</span>
<span class="kn">from</span><span class="w"> </span><span class="nn">pydantic</span><span class="w"> </span><span class="kn">import</span> <span class="n">BaseModel</span>


<span class="c1"># 1. 定义数据模型（就像一个表单模板）</span>
<span class="k">class</span><span class="w"> </span><span class="nc">User</span><span class="p">(</span><span class="n">BaseModel</span><span class="p">):</span>
    <span class="nb">id</span><span class="p">:</span> <span class="nb">int</span>  <span class="c1"># 要求必须是整数</span>
    <span class="n">name</span><span class="p">:</span> <span class="nb">str</span> <span class="o">=</span> <span class="s2">"John Doe"</span>  <span class="c1"># 字符串，且有默认值</span>
    <span class="n">signup_ts</span><span class="p">:</span> <span class="n">datetime</span> <span class="o">|</span> <span class="kc">None</span> <span class="o">=</span> <span class="kc">None</span>  <span class="c1"># 可以是日期时间或空</span>
    <span class="n">friends</span><span class="p">:</span> <span class="nb">list</span><span class="p">[</span><span class="nb">int</span><span class="p">]</span> <span class="o">=</span> <span class="p">[]</span>  <span class="c1"># 整数列表</span>


<span class="c1"># 2. 输入外部数据（通常是 API 请求或文件读取）</span>
<span class="c1"># 注意：这里的 'id' 是字符串 '123'，'friends' 中包含了字符串和字节数据</span>
<span class="n">external_data</span> <span class="o">=</span> <span class="p">{</span>
    <span class="s2">"id"</span><span class="p">:</span> <span class="s2">"123abc"</span><span class="p">,</span>
    <span class="s2">"signup_ts"</span><span class="p">:</span> <span class="s2">"2024-06-01 12:22"</span><span class="p">,</span>
    <span class="s2">"friends"</span><span class="p">:</span> <span class="p">[</span><span class="mi">1</span><span class="p">,</span> <span class="s2">"2"</span><span class="p">,</span> <span class="sa">b</span><span class="s2">"3"</span><span class="p">],</span>
<span class="p">}</span>

<span class="c1"># 3. Pydantic 进行验证和转换</span>
<span class="n">user</span> <span class="o">=</span> <span class="n">User</span><span class="p">(</span><span class="o">**</span><span class="n">external_data</span><span class="p">)</span>

<span class="c1"># 4. 打印结果</span>
<span class="nb">print</span><span class="p">(</span><span class="n">user</span><span class="p">)</span>
<span class="c1"># &gt; User id=123 name='John Doe' signup_ts=datetime.datetime(2024, 6, 1, 12, 22) friends=[1, 2, 3]</span>
<span class="nb">print</span><span class="p">(</span><span class="n">user</span><span class="o">.</span><span class="n">id</span><span class="p">)</span>
<span class="c1"># &gt; 123 (这里已经是整数类型，不再是字符串)</span>
<span class="nb">print</span><span class="p">(</span><span class="n">user</span><span class="o">.</span><span class="n">friends</span><span class="p">)</span>
<span class="c1"># &gt; [1, 2, 3]</span>
</code></pre></div>

<p><code>Pydantic</code>集成到了<code>FastAPI</code>中，在请求和响应时会自动进行验证，验证失败会抛出<code>ValidationError</code></p>
<p><code>FastAPI</code>也会读取到<code>Pydantic</code>的模型，将其生成到<code>openapi.json</code>中</p>
<p>你可以精细的描述模型内部字段</p>
