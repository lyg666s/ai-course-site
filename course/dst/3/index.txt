<h1 id="NumPy-核心概念">NumPy 核心概念</h1>
<p>NumPy 是 Python 科学计算的基石库，几乎所有数据科学生态（Pandas、PyTorch 等）都建立在 NumPy 之上。</p>
<p>它的底层是使用 <code>C</code> 和 <code>C++</code> 编写的，因此在处理大规模数据时具有极高的性能。</p>
<p>本节课只讲 NumPy 的核心概念——理解 ndarray 这个数据结构本身，后续课程再讲具体操作。</p>
<h2 id="ndarray">ndarray</h2>
<p><code>ndarray</code>（N-dimensional array）是 NumPy 的核心数据结构，表示一个<strong>多维数组</strong>。</p>
<p>它与 Python 原生列表的关键区别：
- <strong>同质化</strong>：所有元素必须是相同类型（dtype）
- <strong>连续内存</strong>：数据存储在连续内存块中，访问效率高
- <strong>向量化运算</strong>：无需循环即可对整个数组执行运算</p>

<h2 id="核心概念">核心概念</h2>
<p>理解 NumPy 的关键在于掌握以下几个概念，它们决定了数组的<strong>形状</strong>、<strong>存储方式</strong>和<strong>运算规则</strong>。</p>
<h3 id="shape形状">shape（形状）</h3>
<p><code>shape</code> 是一个元组，描述数组在每个维度上的大小。它是理解数组结构的起点。</p>

<li>1D 数组：<code>(n,)</code></li>

<h3 id="dtype数据类型">dtype（数据类型）</h3>
<p><code>dtype</code> 指定数组中每个元素的数据类型。因为 ndarray 是同质的，所以 dtype 统一描述所有元素。</p>
<p>常见 dtype：
- <code>float64</code> / <code>float32</code>：浮点数（Embedding 常用 float32 来节省内存）
- <code>int64</code> / <code>int32</code> / <code>int8</code>：整数
- <code>bool</code>：布尔值
- <code>object</code>：Python 对象（尽量避免，会失去向量化优势）</p>
<p>dtype 本质上是把 <strong>C 的类型系统</strong>暴露给了 Python：</p>
<table>
<thead>
<tr>
<th>NumPy dtype</th>
<th>C 类型</th>
<th>大小</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>int64</code></td>
<td><code>int64_t</code></td>
<td>8 字节</td>
</tr>
<tr>
<td><code>int32</code></td>
<td><code>int32_t</code></td>
<td>4 字节</td>
</tr>
<tr>
<td><code>float64</code></td>
<td><code>double</code></td>
<td>8 字节</td>
</tr>
<tr>
<td><code>float32</code></td>
<td><code>float</code></td>
<td>4 字节</td>
</tr>
</tbody>
</table>
<p>而 Python 的 <code>int</code> 是<strong>不定长</strong>对象，每个对象头就有 28+ 字节开销。ndarray 用 C 的固定类型，才能实现连续存储和向量化计算。</p>
<blockquote>
<p><strong>Agent 场景</strong>：Embedding 向量通常用 <code>float32</code>，Token ID 用 <code>int64</code>，Mask 用 <code>bool</code>。</p>

<h3 id="strides步幅">strides（步幅）</h3>
