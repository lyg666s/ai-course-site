<h1 id="Pandas-核心数据结构">Pandas 核心数据结构</h1>
<p>Pandas 是 Python 数据分析的核心库，它提供了两种核心数据结构：<strong>Series</strong> 和 <strong>DataFrame</strong>。</p>
<p>简单来说：
- <strong>Series</strong> → 一列带标签的数据（类似一个带索引的数组或 Excel 中的一列）
- <strong>DataFrame</strong> → 一个带标签的二维表格（类似 Excel 工作表或 SQL 表）</p>
<h2 id="Series">Series</h2>
<p>Series 可以理解为「带标签的一维数组」。它由两个核心部分组成：
- <code>values</code>：数据本身（类似 NumPy 数组）
- <code>index</code>：每个数据点的标签</p>

<span class="s1">    CREATE TABLE employees (</span>

<span class="s1">    )</span>
<span class="s1">'''</span><span class="p">)</span>
<span class="n">conn</span><span class="o">.</span><span class="n">execute</span><span class="p">(</span><span class="s2">"INSERT INTO employees VALUES ('张三', 25, '北京', 15000)"</span><span class="p">)</span>
