<p>面向对象编程（Object-Oriented Programming，OOP）是一种编程范式，它将程序组织为<strong>对象</strong>的集合，每个对象包含<strong>数据</strong>（属性）和<strong>行为</strong>（方法）。</p>
<h3 id="核心概念">核心概念</h3>
<table>
<thead>
<tr>
<th>概念</th>
<th>说明</th>
<th>生活中的例子</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>类（Class）</strong></td>
<td>对象的蓝图或模板</td>
<td>建筑设计图</td>
</tr>
<tr>
<td><strong>对象（Object）</strong></td>
<td>类的具体实例</td>
<td>根据图纸建造的房子</td>
</tr>
<tr>
<td><strong>封装（Encapsulation）</strong></td>
<td>隐藏内部实现细节，暴露必要接口</td>
<td>汽车的方向盘和踏板</td>
</tr>
<tr>
<td><strong>继承（Inheritance）</strong></td>
<td>子类复用父类的属性和方法</td>
<td>子承父业</td>
</tr>
<tr>
<td><strong>多态（Polymorphism）</strong></td>
<td>同一接口，不同实现</td>
<td>人都会“说话”，但不同人说话方式不同</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]</p>
<p>本讲聚焦于<strong>类和对象</strong>的基本概念，封装、继承、多态将在下一节中详细展开。</p>
</blockquote>

<h2 id="类的基本定义">类的基本定义</h2>
<h3 id="类的组成">类的组成</h3>
<p>一个类通常包含以下组成部分：</p>
<ul>
<li><strong>属性（字段/成员变量）</strong>：描述对象的状态</li>
<li><strong>方法</strong>：描述对象的行为</li>
<li><strong>构造方法</strong>：用于创建和初始化对象</li>
</ul>

<h2 id="构造方法Constructor">构造方法（Constructor）</h2>
<p>构造方法是一种<strong>特殊的方法</strong>，用于在创建对象时初始化对象的状态。</p>
<h3 id="构造方法的特征">构造方法的特征</h3>
<ul>
<li>方法名与类名<strong>完全相同</strong></li>
<li><strong>没有返回值类型</strong>（包括 <code>void</code>）</li>
<li>在 <code>new</code> 创建对象时<strong>自动调用</strong></li>
<li>如果不提供，编译器会生成默认无参构造方法</li>
</ul>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Student</span><span class="w"> </span><span class="p">{</span>

<li>如果定义了有参构造方法，系统<strong>不会</strong>自动生成无参构造方法。建议显式定义无参构造。</li>
<li>构造方法中可以使用 <code>this()</code> 调用其他构造方法，但必须是第一条语句。</li>
</ul>
</blockquote>

<h2 id="this-关键字">this 关键字</h2>
<p><code>this</code> 关键字在实例方法或构造方法中，指向<strong>当前对象</strong>。</p>
<h3 id="this-的使用场景">this 的使用场景</h3>
<ol>
<li><strong>区分成员变量和局部变量</strong>（当它们同名时）</li>
</ol>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Person</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">name</span><span class="p">;</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="nf">Person</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">name</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">name</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">name</span><span class="p">;</span><span class="w">  </span><span class="c1">// this.name 是成员变量，name 是参数</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<ol start="2">
<li><strong>在构造方法中调用另一个构造方法</strong></li>
</ol>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Person</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">name</span><span class="p">;</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">age</span><span class="p">;</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="nf">Person</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">this</span><span class="p">(</span><span class="s">"Unknown"</span><span class="p">,</span><span class="w"> </span><span class="mi">0</span><span class="p">);</span><span class="w">  </span><span class="c1">// 调用另一个构造方法</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="nf">Person</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">name</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">age</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">name</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">name</span><span class="p">;</span>
<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">age</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">age</span><span class="p">;</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<ol start="3">
<li><strong>作为方法的返回值（链式调用）</strong></li>
</ol>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Builder</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">value</span><span class="p">;</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">Builder</span><span class="w"> </span><span class="nf">setValue</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">value</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="c1">// 使用</span>
<span class="n">Builder</span><span class="w"> </span><span class="n">b</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Builder</span><span class="p">().</span><span class="na">setValue</span><span class="p">(</span><span class="s">"hello"</span><span class="p">).</span><span class="na">setValue</span><span class="p">(</span><span class="s">"world"</span><span class="p">);</span>
</code></pre></div>

<blockquote>
<p>[!CAUTION]</p>
<p><code>this</code> 不能在静态方法中使用（因为静态方法不属于对象）。</p>
</blockquote>

<h3 id="静态-vs-实例成员总结">静态 vs 实例成员总结</h3>
<table>
<thead>
<tr>
<th>特性</th>
<th>静态成员</th>
<th>实例成员</th>
</tr>
</thead>
<tbody>
<tr>
<td>属于</td>
<td>类</td>
<td>对象</td>
</tr>
<tr>
<td>内存分配</td>
<td>类加载时分配一次</td>
<td>每次创建对象分配</td>
</tr>
<tr>
<td>访问方式</td>
<td>类名.成员</td>
<td>对象.成员</td>
</tr>
<tr>
<td><code>this</code> 可用</td>
<td>否</td>
<td>是</td>
</tr>
<tr>
<td>生命周期</td>
<td>类加载到类卸载</td>
<td>对象创建到垃圾回收</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]</p>
<ul>
<li>静态方法只能直接访问静态成员，不能直接访问实例成员。</li>
<li>实例方法可以访问静态成员和实例成员。</li>
</ul>
</blockquote>

<h2 id="代码块">代码块</h2>
<h3 id="初始化块">初始化块</h3>
<p>初始化块在创建对象时执行，用于初始化实例成员。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Person</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="c1">// 实例初始化块：每次创建对象时执行</span>
<span class="w">    </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"执行实例初始化块"</span><span class="p">);</span>
<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">age</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mi">0</span><span class="p">;</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="c1">// 静态初始化块：类加载时执行一次</span>
<span class="w">    </span><span class="kd">static</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"执行静态初始化块"</span><span class="p">);</span>

<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">name</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">name</span><span class="p">;</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"执行构造方法"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">Person</span><span class="w"> </span><span class="n">p1</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Person</span><span class="p">(</span><span class="s">"Alice"</span><span class="p">);</span>
