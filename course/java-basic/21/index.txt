<h2 id="ConcurrentHashMap"><code>ConcurrentHashMap</code></h2>
<h3 id="简介">简介</h3>
<p><code>ConcurrentHashMap</code> 是 Java 并发包中最常用的并发容器，用于替代 <code>HashMap</code>（非线程安全）和 <code>Hashtable</code>（全部加锁，性能差）。</p>
<p><strong>核心设计：</strong></p>
<ul>
<li><strong>Java 7</strong>：分段锁（Segment 数组），每个 Segment 独立锁。</li>
<li><strong>Java 8+</strong>：CAS + synchronized（锁粒度更细，仅锁特定桶）。</li>
</ul>
<h3 id="特点">特点</h3>
<ul>
<li>线程安全，允许并发读和一定程度的并发写</li>
<li>不支持 <code>null</code> 键或值（与 <code>HashMap</code> 不同）</li>
<li>性能远高于 <code>Hashtable</code> 和 <code>Collections.synchronizedMap</code></li>
</ul>

<h2 id="CopyOnWriteArrayList"><code>CopyOnWriteArrayList</code></h2>
<h3 id="简介_1">简介</h3>
<p>写时复制容器，任何写操作（<code>add</code>、<code>set</code>、<code>remove</code>）都会创建底层数组的副本，然后在副本上修改，最后将引用指向新数组。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    subgraph 读操作
        R1[读取数组引用] --&gt; R2[直接读取数组]
    end

    subgraph 写操作
        W1[复制原数组] --&gt; W2[在副本上修改] --&gt; W3[替换引用]
    end

    style W2 fill:#ffeb3b
</code></pre></div>

<h3 id="特点_1">特点</h3>
<ul>
<li>读操作无锁，性能极高</li>
<li>写操作需要复制整个数组，开销大</li>
<li>保证最终一致性，适用于<strong>读多写少</strong>场景</li>
</ul>
<h3 id="适用场景">适用场景</h3>
<ul>
<li>监听器列表（添加/删除监听器不频繁，读取频繁）</li>
<li>缓存配置（偶尔更新，频繁读取）</li>
<li>白名单/黑名单（只读为主）</li>
</ul>

<h2 id="阻塞队列-BlockingQueue">阻塞队列 <code>BlockingQueue</code></h2>
<h3 id="简介_2">简介</h3>
<p><code>BlockingQueue</code> 是支持阻塞操作的队列，当队列空时获取元素会阻塞，当队列满时插入元素会阻塞。常用于生产者-消费者模式。</p>
<h3 id="核心方法">核心方法</h3>
<p><strong>插入操作</strong></p>
<ul>
<li><strong><code>add(e)</code></strong>：将元素插入队列。<strong>若队列已满</strong>，立即抛出 <code>IllegalStateException</code>（非法状态异常），不等待。</li>
<li><strong><code>offer(e)</code></strong>：将元素插入队列。<strong>若队列已满</strong>，立即返回 <code>false</code> 表示插入失败，不抛异常。</li>
<li><strong><code>put(e)</code></strong>：将元素插入队列。<strong>若队列已满</strong>，当前线程将无限期阻塞，直到队列腾出空间并被唤醒。</li>
<li><strong><code>offer(e, time, unit)</code></strong>：将元素插入队列。<strong>若队列已满</strong>，则限时阻塞等待；超时前有空位则返回 <code>true</code>，否则返回 <code>false</code>。</li>
</ul>
<p><strong>移除操作（取出并删除队首）</strong></p>
<ul>
<li><strong><code>remove()</code></strong>：取出并移除队首元素。<strong>若队列为空</strong>，立即抛出 <code>NoSuchElementException</code>（无元素异常）。</li>
<li><strong><code>poll()</code></strong>：取出并移除队首元素。<strong>若队列为空</strong>，立即返回 <code>null</code>，不抛异常。</li>
<li><strong><code>take()</code></strong>：取出并移除队首元素。<strong>若队列为空</strong>，当前线程将无限期阻塞，直到队列有元素可取。</li>
<li><strong><code>poll(time, unit)</code></strong>：取出并移除队首元素。<strong>若队列为空</strong>，则限时阻塞等待；超时前取到则返回该元素，否则返回 <code>null</code>。</li>
</ul>
<p><strong>检查操作（只获取不删除）</strong></p>
<ul>
<li><strong><code>element()</code></strong>：获取（不移除）队首元素。<strong>若队列为空</strong>，立即抛出 <code>NoSuchElementException</code>。</li>
<li><strong><code>peek()</code></strong>：获取（不移除）队首元素。<strong>若队列为空</strong>，立即返回 <code>null</code>，不抛异常。</li>
</ul>

<h3 id="CountDownLatch-等待多个事件"><code>CountDownLatch</code> —— 等待多个事件</h3>
<p><strong>作用：</strong> 使一个或多个线程等待其他线程完成一组操作。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>sequenceDiagram
    participant Main as 主线程
    participant T1 as 线程1
    participant T2 as 线程2
    participant T3 as 线程3

    Main-&gt;&gt;T1: 启动
    Main-&gt;&gt;T2: 启动
    Main-&gt;&gt;T3: 启动
    Main-&gt;&gt;Main: await()（阻塞）

    T1-&gt;&gt;T1: 执行任务
    T1-&gt;&gt;Main: countDown()
    T2-&gt;&gt;T2: 执行任务
    T2-&gt;&gt;Main: countDown()
    T3-&gt;&gt;T3: 执行任务
    T3-&gt;&gt;Main: countDown()

</code></pre></div>

<p><strong>作用：</strong> 让一组线程等待彼此达到某个公共屏障点。与 <code>CountDownLatch</code> 区别在于：<code>CyclicBarrier</code> 可以重复使用（循环）。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>sequenceDiagram
    participant T1 as 线程1
    participant T2 as 线程2
    participant T3 as 线程3

    T1-&gt;&gt;T1: await()
    T2-&gt;&gt;T2: await()
    T3-&gt;&gt;T3: await()
    Note over T1,T3: 所有线程到达屏障后同时继续

    T1-&gt;&gt;T1: 继续执行
    T2-&gt;&gt;T2: 继续执行
    T3-&gt;&gt;T3: 继续执行

<h3 id="技术选型">技术选型</h3>
<p>选择并发工具时，先理解具体场景（读多写少、生产者-消费者、限流等），再选择合适的工具</p>
<ol>
<li><strong>并发集合</strong>：
   - <code>ConcurrentHashMap</code>：高并发读写，原子操作丰富。
   - <code>CopyOnWriteArrayList</code>：读多写少场景，写时复制。
   - <code>BlockingQueue</code>：线程安全队列，支持阻塞操作（<code>put</code>/<code>take</code>）。</li>
<li><strong>同步工具类</strong>：
   - <code>CountDownLatch</code>：等待一组任务完成。
   - <code>CyclicBarrier</code>：让多个线程等待彼此到达。
   - <code>Semaphore</code>：控制并发线程数。</li>
<li><strong>选择原则</strong>：
   - 高并发读写 → <code>ConcurrentHashMap</code>。
   - 读多写少 → <code>CopyOnWriteArrayList</code>。
   - 生产者-消费者 → <code>BlockingQueue</code>。
   - 等待多个事件 → <code>CountDownLatch</code>。
   - 线程互相等待 → <code>CyclicBarrier</code>。
   - 限流 → <code>Semaphore</code>。</li>
</ol>
