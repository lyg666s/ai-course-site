<h2 id="什么是-Lambda-表达式">什么是 Lambda 表达式</h2>
<p><strong>Lambda 表达式</strong>（Lambda Expression）是 Java 8 引入的一个核心特性，它允许将<strong>函数作为参数</strong>传递给方法，或者将<strong>代码块作为数据</strong>进行处理。</p>
<p>Lambda 表达式是一种<strong>匿名函数</strong>，它没有名称，但有参数列表、函数体和返回值类型。</p>
<p>Lambda 表达式是<strong>函数式编程</strong>思想在 Java 中的体现，它使得代码更加简洁、灵活，尤其在与 <code>Stream API</code> 结合使用时效果显著。</p>
<h3 id="为什么需要-Lambda-表达式">为什么需要 Lambda 表达式</h3>
<p>在没有 Lambda 表达式之前，如果需要将一个行为传递给方法，通常需要使用<strong>匿名内部类</strong>，代码冗长且不易读。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 使用匿名内部类的方式：对列表进行排序</span>
<span class="n">List</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="w"> </span><span class="n">list</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Arrays</span><span class="p">.</span><span class="na">asList</span><span class="p">(</span><span class="s">"banana"</span><span class="p">,</span><span class="w"> </span><span class="s">"apple"</span><span class="p">,</span><span class="w"> </span><span class="s">"cherry"</span><span class="p">);</span>
<span class="n">Collections</span><span class="p">.</span><span class="na">sort</span><span class="p">(</span><span class="n">list</span><span class="p">,</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Comparator</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Override</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="nf">compare</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">s1</span><span class="p">,</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">s2</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="n">s1</span><span class="p">.</span><span class="na">compareTo</span><span class="p">(</span><span class="n">s2</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">});</span>

<span class="c1">// 使用 Lambda 表达式简化</span>
<span class="n">Collections</span><span class="p">.</span><span class="na">sort</span><span class="p">(</span><span class="n">list</span><span class="p">,</span><span class="w"> </span><span class="p">(</span><span class="n">s1</span><span class="p">,</span><span class="w"> </span><span class="n">s2</span><span class="p">)</span><span class="w"> </span><span class="o">-&gt;</span><span class="w"> </span><span class="n">s1</span><span class="p">.</span><span class="na">compareTo</span><span class="p">(</span><span class="n">s2</span><span class="p">));</span>

<span class="c1">// 或者更简洁</span>
<span class="n">list</span><span class="p">.</span><span class="na">sort</span><span class="p">(</span><span class="n">String</span><span class="p">::</span><span class="n">compareTo</span><span class="p">);</span>
</code></pre></div>

<h3 id="Lambda-表达式的核心思想">Lambda 表达式的核心思想</h3>
<p>Lambda 表达式可以理解为<strong>可传递的代码块</strong>，它将行为（逻辑）作为数据进行传递，而不是将数据传递给固定逻辑。这种思想类似于<strong>策略模式</strong>，但更简洁、更灵活。</p>
<hr />
<h2 id="函数式接口Functional-Interface">函数式接口（Functional Interface）</h2>
<h3 id="什么是函数式接口">什么是函数式接口</h3>
<p><strong>函数式接口</strong>是指<strong>只有一个抽象方法</strong>的接口。</p>
<p>Java中的接口是一组方法签名的集合，用关键字<code>interface</code>定义，示例如下：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 定义一个接口</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">interface</span> <span class="nc">Calculator</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="nf">add</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">);</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="nf">subtract</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">);</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="nf">multiply</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">);</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="nf">divide</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">);</span><span class="w">   </span>
<span class="p">}</span>
</code></pre></div>

<p>Lambda 表达式可以看作是函数式接口的具体实现，类似于匿名内部类的简化写法。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 定义一个函数式接口</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">interface</span> <span class="nc">Calculator</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="nf">calculate</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">);</span>
<span class="p">}</span>

<span class="c1">// 使用 Lambda 表达式实现</span>
<span class="n">Calculator</span><span class="w"> </span><span class="n">add</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="p">(</span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="n">b</span><span class="p">)</span><span class="w"> </span><span class="o">-&gt;</span><span class="w"> </span><span class="n">a</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">b</span><span class="p">;</span>
<span class="n">Calculator</span><span class="w"> </span><span class="n">multiply</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="p">(</span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="n">b</span><span class="p">)</span><span class="w"> </span><span class="o">-&gt;</span><span class="w"> </span><span class="n">a</span><span class="w"> </span><span class="o">*</span><span class="w"> </span><span class="n">b</span><span class="p">;</span>

<span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="n">add</span><span class="p">.</span><span class="na">calculate</span><span class="p">(</span><span class="mi">3</span><span class="p">,</span><span class="w"> </span><span class="mi">5</span><span class="p">));</span><span class="w">      </span><span class="c1">// 8</span>
<span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="n">multiply</span><span class="p">.</span><span class="na">calculate</span><span class="p">(</span><span class="mi">3</span><span class="p">,</span><span class="w"> </span><span class="mi">5</span><span class="p">));</span><span class="w"> </span><span class="c1">// 15</span>
</code></pre></div>

<h2 id="Lambda-表达式语法">Lambda 表达式语法</h2>
<h3 id="基本语法">基本语法</h3>
<p>Lambda 表达式由三部分组成：</p>
<ol>
<li><strong>参数列表</strong>：用小括号包裹，多个参数用逗号分隔。</li>
<li><strong>箭头符号</strong>：<code>-&gt;</code>。</li>
<li><strong>方法体</strong>：代码块（单个表达式或语句块）。</li>
</ol>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 完整语法</span>
<span class="p">(</span><span class="n">参数类型</span><span class="w"> </span><span class="n">参数名1</span><span class="p">,</span><span class="w"> </span><span class="n">参数类型</span><span class="w"> </span><span class="n">参数名2</span><span class="p">,</span><span class="w"> </span><span class="p">...)</span><span class="w"> </span><span class="o">-&gt;</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="n">方法体</span><span class="w"> </span><span class="p">}</span>

<span class="c1">// 简化形式（单一表达式）</span>
<span class="p">(</span><span class="n">参数1</span><span class="p">,</span><span class="w"> </span><span class="n">参数2</span><span class="p">)</span><span class="w"> </span><span class="o">-&gt;</span><span class="w"> </span><span class="n">表达式</span>

<span class="c1">// 简化形式（单参数，可省略括号）</span>
<span class="n">参数</span><span class="w"> </span><span class="o">-&gt;</span><span class="w"> </span><span class="n">表达式</span>

<h3 id="Lambda-表达式本质">Lambda 表达式本质</h3>
<p>Lambda 表达式本质上是一个<strong>函数式接口的实例</strong>，它可以在以下上下文中使用：</p>
<ul>
<li>赋值给函数式接口类型的变量</li>
<li>作为方法参数传递</li>
<li>作为方法的返回值</li>
</ul>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 赋值给函数式接口变量</span>

<span class="c1">// 作为方法返回值</span>

<h2 id="注意事项">注意事项</h2>
<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>Lambda 表达式<strong>只能用于函数式接口</strong>（只有一个抽象方法的接口）。</li>
<li>Lambda 表达式<strong>不能独立存在</strong>，必须赋值给函数式接口变量或作为参数传递。</li>
</ul>
</blockquote>

<h3 id="作业四Predicate-组合使用">作业四：Predicate 组合使用</h3>
<p>编写一个方法 <code>filterAndPrint</code>，接收一个 <code>List&lt;Integer&gt;</code> 和两个 <code>Predicate&lt;Integer&gt;</code>，使用以下逻辑处理：</p>
<ol>
<li>使用第一个 Predicate 筛选元素（如过滤偶数）。</li>
<li>再使用第二个 Predicate 进行二次筛选（如过滤大于 5 的数）。</li>
