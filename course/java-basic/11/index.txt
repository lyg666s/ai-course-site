<p><strong>包（Package）</strong> 是 Java 中用于<strong>组织类和接口</strong>的机制，类似于文件系统中的文件夹。包将功能相关的类分组在一起，形成一个<strong>命名空间</strong>，避免类名冲突，并提供访问控制层级。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 包的声明必须放在文件第一行</span>
<span class="kn">package</span><span class="w"> </span><span class="nn">com.example.demo</span><span class="p">;</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">HelloWorld</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"Hello, World!"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<p>一个 Java 源文件只能有一个 <code>package</code> 语句，且必须放在文件的最前面（注释除外）。</p>
</blockquote>

<h2 id="包名命名规范">包名命名规范</h2>
<p>为了确保包名的<strong>全局唯一性</strong>，Java 社区遵循以下规范：</p>
<table>
<thead>
<tr>
<th>规范</th>
<th>说明</th>
<th>示例</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>全小写</strong></td>
<td>包名全部使用小写字母</td>
<td><code>com.example.util</code></td>
</tr>
<tr>
<td><strong>域名倒序</strong></td>
<td>使用公司/组织的域名倒序作为前缀</td>
<td><code>com.example.project</code></td>
</tr>
<tr>
<td><strong>有意义的名称</strong></td>
<td>反映模块的功能</td>
<td><code>com.example.user</code>、<code>com.example.order</code></td>
</tr>
<tr>
<td><strong>不以下划线开头</strong></td>
<td>避免与 Java 关键字混淆</td>
<td><code>com.example</code>（而非 <code>_com.example</code>）</td>
</tr>
</tbody>
</table>
<p>包结构示例：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="n">com</span><span class="p">.</span><span class="na">example</span><span class="p">.</span><span class="na">project</span>
<span class="w">    </span><span class="err">├──</span><span class="w"> </span><span class="n">controller</span><span class="w">    </span><span class="c1">// 控制器层</span>
<span class="w">    </span><span class="err">├──</span><span class="w"> </span><span class="n">service</span><span class="w">       </span><span class="c1">// 业务逻辑层</span>
<span class="w">    </span><span class="err">├──</span><span class="w"> </span><span class="n">dao</span><span class="w">           </span><span class="c1">// 数据访问层</span>
<span class="w">    </span><span class="err">├──</span><span class="w"> </span><span class="n">model</span><span class="w">         </span><span class="c1">// 数据模型</span>
<span class="w">    </span><span class="err">└──</span><span class="w"> </span><span class="n">util</span><span class="w">          </span><span class="c1">// 工具类</span>
</code></pre></div>

<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>不要使用 Java 保留关键字作为包名（如 <code>int</code>、<code>class</code>）。</li>
<li>包名应使用 <code>.</code> 分隔，不允许使用连字符 <code>-</code> 或其他特殊字符。</li>
</ul>
</blockquote>

<h2 id="包的声明">包的声明</h2>
<p>使用 <code>package</code> 关键字声明类所在的包。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 文件: com/example/demo/Calculator.java</span>
<span class="kn">package</span><span class="w"> </span><span class="nn">com.example.demo</span><span class="p">;</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Calculator</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="nf">add</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="n">a</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">b</span><span class="p">;</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="无名包默认包">无名包（默认包）</h3>
<p>如果源文件中没有 <code>package</code> 语句，类就属于<strong>无名包</strong>（默认包）。<strong>不推荐</strong>使用无名包，因为无法被其他包中的类导入，且容易造成命名冲突。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 不建议：没有 package 声明</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">DefaultClass</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 该类位于默认包中</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="包描述文件-package-infojava">包描述文件 <code>package-info.java</code></h3>
<p><code>package-info.java</code> 是 Java 中一个<strong>特殊的元数据文件</strong>，专门用于为<strong>整个包</strong>提供注释和声明。它并不是普通的 Java 类（没有 <code>public class</code> 定义），而是放在包的根目录下，充当该包的“介绍信”和“注解挂载点”。它主要有<strong>两大核心使命</strong>：</p>
<ul>
<li><strong>提供包级注解</strong>：将注解（如 <code>@Deprecated</code>、<code>@NonNullApi</code>）应用到包下的所有类上，无需逐个类重复标注。</li>
<li><strong>生成包级 Javadoc</strong>：在生成 API 文档时，文件开头的 <code>/** ... */</code> 注释会作为该包的详细说明文档。</li>
</ul>
<div class="codehilite lang-java"><pre><span></span><code><span class="cm">/**</span>
<span class="cm"> * 提供 Demo 项目的公共 API 接口。</span>
<span class="cm"> * &lt;p&gt;</span>
<span class="cm"> * 此包包含所有对外暴露的服务契约，外部模块只需依赖此包即可调用。</span>
<span class="cm"> * 使用此包时，请确保传入的参数符合非空约束。</span>
<span class="cm"> * &lt;/p&gt;</span>
<span class="cm"> *</span>
<span class="cm"> * @author 你的名字</span>
<span class="cm"> * @since 1.0.0</span>
<span class="cm"> */</span>
<span class="c1">// 1. 包级注解（放在 package 声明之前）</span>
<span class="nd">@Deprecated</span><span class="w">  </span><span class="c1">// 示例：标记整个包为已弃用（若需要）</span>
<span class="kn">package</span><span class="w"> </span><span class="nn">com.example.demo.api</span><span class="p">;</span>

<span class="c1">// 2. 导入放在 package 声明之后</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.Deprecated</span><span class="p">;</span>
</code></pre></div>

<p><strong>格式规则</strong>：</p>
<ul>
<li>Javadoc 注释（<code>/**</code>）必须在最顶部。</li>
<li>注解必须紧跟在 Javadoc 之后，且在 <code>package</code> 声明<strong>之前</strong>。</li>
<li><code>package</code> 声明必须存在且放在中间。</li>
<li><code>import</code> 语句必须放在 <code>package</code> 声明<strong>之后</strong></li>
</ul>
<hr />
<h2 id="包的导入">包的导入</h2>
<p>使用 <code>import</code> 语句导入其他包中的类，避免每次使用时都写完整类名。</p>
<h3 id="导入单个类">导入单个类</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.util.ArrayList</span><span class="p">;</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">java.util.List</span><span class="p">;</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">ImportDemo</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">List</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="w"> </span><span class="n">list</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">ArrayList</span><span class="o">&lt;&gt;</span><span class="p">();</span><span class="w">  </span><span class="c1">// 无需写完整类名</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="按需导入通配符">按需导入（通配符 <code>*</code>）</h3>
<p>使用 <code>*</code> 导入包中所有类，<strong>不会</strong>递归导入子包中的类。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.util.*</span><span class="p">;</span><span class="w">      </span><span class="c1">// 导入 java.util 包中的所有类</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">java.io.*</span><span class="p">;</span><span class="w">        </span><span class="c1">// 导入 java.io 包中的所有类</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">WildcardImport</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">List</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="w"> </span><span class="n">list</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">ArrayList</span><span class="o">&lt;&gt;</span><span class="p">();</span>
<span class="w">        </span><span class="n">File</span><span class="w"> </span><span class="n">file</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">File</span><span class="p">(</span><span class="s">"test.txt"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<ul>
<li>通配符导入不会影响性能，编译时会解析为实际需要的类。</li>
<li>推荐导入具体的类，以提高代码可读性（IDE 可自动管理）。</li>
</ul>
</blockquote>
<h3 id="静态导入import-static">静态导入（<code>import static</code>）</h3>
<p>使用 <code>import static</code> 导入类的<strong>静态成员</strong>（静态字段和方法），可以直接使用静态成员名而无需类名前缀。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import static</span><span class="w"> </span><span class="nn">java.lang.Math.PI</span><span class="p">;</span>
<span class="kn">import static</span><span class="w"> </span><span class="nn">java.lang.Math.pow</span><span class="p">;</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">StaticImportDemo</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 直接使用 PI 和 pow，无需 Math.PI / Math.pow</span>
<span class="w">        </span><span class="kt">double</span><span class="w"> </span><span class="n">area</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">PI</span><span class="w"> </span><span class="o">*</span><span class="w"> </span><span class="n">pow</span><span class="p">(</span><span class="mi">5</span><span class="p">,</span><span class="w"> </span><span class="mi">2</span><span class="p">);</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="n">area</span><span class="p">);</span><span class="w">  </span><span class="c1">// 78.53981633974483</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p>导入所有静态成员：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import static</span><span class="w"> </span><span class="nn">java.lang.Math.*</span><span class="p">;</span><span class="w">   </span><span class="c1">// 导入所有静态成员</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">StaticImportAll</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="kt">double</span><span class="w"> </span><span class="n">result</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">sqrt</span><span class="p">(</span><span class="mi">16</span><span class="p">)</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">pow</span><span class="p">(</span><span class="mi">2</span><span class="p">,</span><span class="w"> </span><span class="mi">3</span><span class="p">);</span><span class="w">  </span><span class="c1">// 直接使用</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>静态导入<strong>可能降低代码可读性</strong>，读者需要判断某个静态成员来自哪个类。</li>
<li>当多个类有同名静态成员时，容易产生混淆，应谨慎使用。</li>
</ul>
</blockquote>

<h2 id="包与目录结构">包与目录结构</h2>

    └── com/
        └── example/

</code></pre></div>

javac com/example/demo/Calculator.java

# 运行
java com.example.demo.Calculator
</code></pre></div>

<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>编译和运行时的<strong>当前工作目录</strong>必须与包结构匹配。</li>
<li>运行时要使用<strong>完整类名</strong>（包含包路径）。</li>
</ul>
</blockquote>

<h2 id="Java-模块化系统Java-9">Java 模块化系统（Java 9+）</h2>
<p>Java 9 引入了<strong>模块化系统</strong>（Project Jigsaw），在包的基础上增加了模块（Module）的概念。</p>
<h3 id="模块描述文件-module-infojava">模块描述文件 <code>module-info.java</code></h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">module</span> <span class="nc">com</span><span class="p">.</span><span class="na">example</span><span class="p">.</span><span class="na">demo</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 导出包，使其对外可见</span>
<span class="w">    </span><span class="kd">exports</span><span class="w"> </span><span class="n">com</span><span class="p">.</span><span class="na">example</span><span class="p">.</span><span class="na">demo</span><span class="p">.</span><span class="na">api</span><span class="p">;</span>

<span class="w">    </span><span class="c1">// 依赖其他模块</span>
<span class="w">    </span><span class="kd">requires</span><span class="w"> </span><span class="n">java</span><span class="p">.</span><span class="na">sql</span><span class="p">;</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="对比module-infojava和package-infojava">对比<code>module-info.java</code>和<code>package-info.java</code></h3>
<table>
<thead>
<tr>
<th>对比维度</th>
<th><strong><code>module-info.java</code></strong></th>
<th><strong><code>package-info.java</code></strong></th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>作用层级</strong></td>
<td><strong>模块级</strong>（整个 Jar 包）</td>
<td><strong>包级</strong>（仅限当前包及其子包）</td>
</tr>
<tr>
<td><strong>核心职责</strong></td>
<td>定义模块依赖（<code>requires</code>）、导出接口（<code>exports</code>）</td>
<td>定义包文档、包级注解、包级可见性（如 <code>@Deprecated</code>）</td>
</tr>
<tr>
<td><strong>放置位置</strong></td>
<td>源码根目录（如 <code>src/main/java</code> 下）</td>
<td>具体包的目录下（如 <code>com/example/demo/api</code> 内）</td>
</tr>
<tr>
<td><strong>是否必须</strong></td>
<td><strong>必须</strong>（模块化项目启动的必要条件）</td>
<td><strong>可选</strong>（按需添加，强烈建议用于核心导出包）</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]</p>
<p>本课程重点掌握包的使用，模块化系统作为补充了解即可。</p>
</blockquote>

<h2 id="注意事项">注意事项</h2>
<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>包名必须与目录结构完全一致，否则编译会报错。</li>
<li>避免使用 Java 标准库的包名（如 <code>java.*</code>、<code>javax.*</code>）。</li>
<li>一个源文件最多只能有一个 <code>package</code> 语句。</li>
<li><code>import</code> 语句必须放在 <code>package</code> 语句之后，类声明之前。</li>
<li>静态导入要慎用，避免混淆代码可读性。</li>
</ul>
</blockquote>
