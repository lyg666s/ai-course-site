<h2 id="什么是注解">什么是注解</h2>
<p><strong>注解（Annotation）</strong> 是 Java 5 引入的一种<strong>元数据</strong>（Metadata）机制，它允许我们在代码中添加<strong>标记</strong>或<strong>配置信息</strong>，而这些信息本身并不直接影响程序的逻辑，但可以被编译器、开发工具或框架在编译时或运行时读取和处理。</p>
<blockquote>
<p>[!NOTE]</p>
<p>所谓元数据就是 <strong>“用于描述数据的数据”</strong>，这个概念在各种语言以及大模型领域都适用。</p>
<p>例如<strong>书的正文内容</strong> = <strong>数据</strong>（具体信息）。而<strong>图书馆的索书号、书名、作者、出版日期、摘要、在哪个书架</strong> = <strong>元数据</strong>（描述这本书的辅助信息）。
没有元数据，数据就像散落在地上的无尽文字，无法检索、无法归类、无法理解。</p>
</blockquote>
<p>注解本质上是一种<strong>特殊的接口</strong>，用 <code>@interface</code> 关键字定义。</p>
<h3 id="注解的作用">注解的作用</h3>
<table>
<thead>
<tr>
<th>作用</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>给编译器提供信息</strong></td>
<td>如 <code>@Override</code> 告诉编译器该方法覆盖了父类方法</td>
</tr>
<tr>
<td><strong>编译期处理</strong></td>
<td>在编译时生成代码、配置文件等（如 Lombok）</td>
</tr>
<tr>
<td><strong>运行时处理</strong></td>
<td>通过反射在运行时读取注解，用于配置框架（如 Spring）</td>
</tr>
<tr>
<td><strong>代码文档化</strong></td>
<td>可被 javadoc 工具提取生成文档</td>
</tr>
</tbody>
</table>

<h2 id="内置注解Built-in-Annotations">内置注解（Built-in Annotations）</h2>
<p>Java 提供了几个常用的内置注解，位于 <code>java.lang</code> 包中。</p>
<h3 id="Override"><code>@Override</code></h3>
<p>标记方法<strong>覆盖</strong>（重写）了父类或接口中的方法。如果方法签名与父类不匹配，编译器会报错。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">class</span> <span class="nc">Animal</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">speak</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"Animal speaks"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="kd">class</span> <span class="nc">Dog</span><span class="w"> </span><span class="kd">extends</span><span class="w"> </span><span class="n">Animal</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Override</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">speak</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w">   </span><span class="c1">// 正确覆盖</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"Dog barks"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="c1">// @Override</span>
<span class="w">    </span><span class="c1">// public void speak(String sound) { }  // 编译错误：方法签名不匹配</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="Deprecated"><code>@Deprecated</code></h3>
<p>标记某个元素（类、方法、字段等）已过时，不推荐使用，但仍然可以使用。编译器会生成警告。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">OldClass</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Deprecated</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">oldMethod</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 旧实现</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">newMethod</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 新实现</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="c1">// 使用</span>
<span class="n">OldClass</span><span class="w"> </span><span class="n">obj</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">OldClass</span><span class="p">();</span>
<span class="n">obj</span><span class="p">.</span><span class="na">oldMethod</span><span class="p">();</span><span class="w">  </span><span class="c1">// 编译器警告</span>
<span class="n">obj</span><span class="p">.</span><span class="na">newMethod</span><span class="p">();</span>
</code></pre></div>

<h3 id="SuppressWarnings"><code>@SuppressWarnings</code></h3>
<p>抑制编译器警告。通常用于已知无法避免的警告（如未使用变量、泛型转换等）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">SuppressDemo</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@SuppressWarnings</span><span class="p">(</span><span class="s">"unused"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">test</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="kt">int</span><span class="w"> </span><span class="n">unused</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mi">10</span><span class="p">;</span><span class="w">   </span><span class="c1">// 通常会有警告，此处被抑制</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="nd">@SuppressWarnings</span><span class="p">({</span><span class="s">"unchecked"</span><span class="p">,</span><span class="w"> </span><span class="s">"rawtypes"</span><span class="p">})</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">rawType</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">List</span><span class="w"> </span><span class="n">list</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">ArrayList</span><span class="p">();</span><span class="w">   </span><span class="c1">// 抑制 raw type 警告</span>
<span class="w">        </span><span class="n">list</span><span class="p">.</span><span class="na">add</span><span class="p">(</span><span class="s">"hello"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="FunctionalInterface"><code>@FunctionalInterface</code></h3>
<p>标记接口为<strong>函数式接口</strong>（即只有一个抽象方法的接口），编译器会检查是否符合规范。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@FunctionalInterface</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">interface</span> <span class="nc">Calculator</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="nf">calculate</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">);</span>
<span class="w">    </span><span class="c1">// int another();  // 编译错误：函数式接口只能有一个抽象方法</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<p>函数式接口相关内容可以回顾<code>Lambda表达式</code>这一节内容</p>
</blockquote>
<hr />
<h2 id="元注解Meta-Annotations">元注解（Meta-Annotations）</h2>
<p><strong>元注解</strong>是用于<strong>修饰注解</strong>的注解，它们控制注解的行为和适用范围。所有元注解都位于 <code>java.lang.annotation</code> 包中。</p>
<h3 id="Target"><code>@Target</code></h3>
<p>指定注解可以应用的<strong>目标位置</strong>（如类、方法、字段等）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.annotation.Target</span><span class="p">;</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.annotation.ElementType</span><span class="p">;</span>

<span class="nd">@Target</span><span class="p">(</span><span class="n">ElementType</span><span class="p">.</span><span class="na">METHOD</span><span class="p">)</span><span class="w">   </span><span class="c1">// 该注解只能用于方法</span>
<span class="kd">public</span><span class="w"> </span><span class="nd">@interface</span><span class="w"> </span><span class="n">MyMethodAnnotation</span><span class="w"> </span><span class="p">{</span>
<span class="p">}</span>

<span class="c1">// 使用</span>
<span class="c1">// @MyMethodAnnotation   // 错误：不能用于类</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Demo</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@MyMethodAnnotation</span><span class="w">    </span><span class="c1">// 正确</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">test</span><span class="p">()</span><span class="w"> </span><span class="p">{}</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>常用 <code>ElementType</code> 取值：</strong></p>
<table>
<thead>
<tr>
<th>取值</th>
<th>目标</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>TYPE</code></td>
<td>类、接口、枚举</td>
</tr>
<tr>
<td><code>FIELD</code></td>
<td>字段（成员变量）</td>
</tr>
<tr>
<td><code>METHOD</code></td>
<td>方法</td>
</tr>
<tr>
<td><code>PARAMETER</code></td>
<td>方法参数</td>
</tr>
<tr>
<td><code>CONSTRUCTOR</code></td>
<td>构造方法</td>
</tr>
<tr>
<td><code>LOCAL_VARIABLE</code></td>
<td>局部变量</td>
</tr>
<tr>
<td><code>ANNOTATION_TYPE</code></td>
<td>注解类型</td>
</tr>
<tr>
<td><code>PACKAGE</code></td>
<td>包</td>
</tr>
</tbody>
</table>
<p>多个目标可用花括号指定：<code>{ElementType.METHOD, ElementType.FIELD}</code></p>
<h3 id="Retention"><code>@Retention</code></h3>
<p>指定注解的<strong>保留策略</strong>，即注解信息保留到哪个阶段。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.annotation.Retention</span><span class="p">;</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.annotation.RetentionPolicy</span><span class="p">;</span>

<span class="nd">@Retention</span><span class="p">(</span><span class="n">RetentionPolicy</span><span class="p">.</span><span class="na">RUNTIME</span><span class="p">)</span><span class="w">   </span><span class="c1">// 注解在运行时保留（可通过反射读取）</span>
<span class="kd">public</span><span class="w"> </span><span class="nd">@interface</span><span class="w"> </span><span class="n">RuntimeAnnotation</span><span class="w"> </span><span class="p">{</span>
<span class="p">}</span>
</code></pre></div>

<p><strong><code>RetentionPolicy</code> 取值：</strong></p>
<table>
<thead>
<tr>
<th>取值</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>SOURCE</code></td>
<td>只保留在源码中，编译时丢失（如 <code>@SuppressWarnings</code>）</td>
</tr>
<tr>
<td><code>CLASS</code></td>
<td>保留在字节码中，但 JVM 加载时丢失（默认值）</td>
</tr>
<tr>
<td><code>RUNTIME</code></td>
<td>保留在运行时，可通过反射读取（用于框架配置）</td>
</tr>
</tbody>
</table>
<h3 id="Documented"><code>@Documented</code></h3>
<p>使注解信息出现在生成的 Javadoc 文档中。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.annotation.Documented</span><span class="p">;</span>

<span class="nd">@Documented</span>
<span class="kd">public</span><span class="w"> </span><span class="nd">@interface</span><span class="w"> </span><span class="n">DocAnnotation</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">String</span><span class="w"> </span><span class="nf">value</span><span class="p">();</span>
<span class="p">}</span>

<span class="c1">// 使用该注解的类，在 Javadoc 中会显示注解信息</span>
</code></pre></div>

<h3 id="Inherited"><code>@Inherited</code></h3>
<p>允许子类<strong>继承</strong>父类上的注解（仅对类继承有效，对接口无效）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.annotation.Inherited</span><span class="p">;</span>

<span class="nd">@Inherited</span>
<span class="kd">public</span><span class="w"> </span><span class="nd">@interface</span><span class="w"> </span><span class="n">InheritedAnnotation</span><span class="w"> </span><span class="p">{</span>
<span class="p">}</span>

<span class="nd">@InheritedAnnotation</span>
<span class="kd">class</span> <span class="nc">Parent</span><span class="w"> </span><span class="p">{}</span>

<span class="kd">class</span> <span class="nc">Child</span><span class="w"> </span><span class="kd">extends</span><span class="w"> </span><span class="n">Parent</span><span class="w"> </span><span class="p">{}</span><span class="w">  </span><span class="c1">// Child 自动拥有该注解</span>
</code></pre></div>

<h2 id="自定义注解">自定义注解</h2>
<h3 id="定义注解">定义注解</h3>
<p>使用 <code>@interface</code> 关键字，可定义<strong>属性</strong>（类似方法声明）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.annotation.*</span><span class="p">;</span>

<span class="nd">@Target</span><span class="p">(</span><span class="n">ElementType</span><span class="p">.</span><span class="na">METHOD</span><span class="p">)</span>
<span class="nd">@Retention</span><span class="p">(</span><span class="n">RetentionPolicy</span><span class="p">.</span><span class="na">RUNTIME</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="nd">@interface</span><span class="w"> </span><span class="n">Log</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 属性：没有默认值，使用时必须指定</span>
<span class="w">    </span><span class="n">String</span><span class="w"> </span><span class="nf">value</span><span class="p">();</span>

<span class="w">    </span><span class="c1">// 属性：有默认值，可选</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="nf">level</span><span class="p">()</span><span class="w"> </span><span class="k">default</span><span class="w"> </span><span class="mi">1</span><span class="p">;</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="使用自定义注解">使用自定义注解</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Service</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Log</span><span class="p">(</span><span class="n">value</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"执行 save 操作"</span><span class="p">,</span><span class="w"> </span><span class="n">level</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mi">2</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">save</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"保存数据..."</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="nd">@Log</span><span class="p">(</span><span class="s">"执行 delete 操作"</span><span class="p">)</span><span class="w">   </span><span class="c1">// 当只有一个 value 属性时，可以省略 value= </span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">delete</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"删除数据..."</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="读取注解运行时通过反射">读取注解（运行时通过反射）</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">import</span><span class="w"> </span><span class="nn">java.lang.reflect.Method</span><span class="p">;</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">AnnotationReader</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="kd">throws</span><span class="w"> </span><span class="n">Exception</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">Method</span><span class="o">[]</span><span class="w"> </span><span class="n">methods</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Service</span><span class="p">.</span><span class="na">class</span><span class="p">.</span><span class="na">getDeclaredMethods</span><span class="p">();</span>
<span class="w">        </span><span class="k">for</span><span class="w"> </span><span class="p">(</span><span class="n">Method</span><span class="w"> </span><span class="n">method</span><span class="w"> </span><span class="p">:</span><span class="w"> </span><span class="n">methods</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">            </span><span class="k">if</span><span class="w"> </span><span class="p">(</span><span class="n">method</span><span class="p">.</span><span class="na">isAnnotationPresent</span><span class="p">(</span><span class="n">Log</span><span class="p">.</span><span class="na">class</span><span class="p">))</span><span class="w"> </span><span class="p">{</span>
<span class="w">                </span><span class="n">Log</span><span class="w"> </span><span class="n">log</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">method</span><span class="p">.</span><span class="na">getAnnotation</span><span class="p">(</span><span class="n">Log</span><span class="p">.</span><span class="na">class</span><span class="p">);</span>

<blockquote>
<p>[!NOTE]</p>
<ul>
<li>注解属性支持的类型：基本类型、<code>String</code>、<code>Class</code>、枚举、注解类型以及以上类型的数组。</li>
<li>若属性名为 <code>value</code>，使用时可以省略属性名。</li>
</ul>

<h2 id="注意事项">注意事项</h2>
<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>注解本身<strong>不包含业务逻辑</strong>，它只是标记。需要配合<strong>注解处理器</strong>（编译期）或<strong>反射</strong>（运行时）才能真正发挥作用。</li>
<li>注解不能继承（但可以通过 <code>@Inherited</code> 让子类继承父类的注解）。</li>
<li>注解的属性值必须是<strong>常量表达式</strong>（编译期确定）。</li>
</ul>
</blockquote>
