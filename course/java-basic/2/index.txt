<h3 id="配置环境变量">配置环境变量</h3>
<p>为什么要配置环境变量：让命令行找到Java命令。例如：</p>
<ul>
<li>javac命令把.java源文件编译成.class文件</li>
<li>java命令执行编译后的.class文件</li>
</ul>
<blockquote>
<p>[!NOTE]</p>
<p>类比：安装Node.js后会自动添加node到PATH，但Java需要手动配置</p>
</blockquote>
<p>如何设置环境变量？设置哪些环境变量？</p>
<ul>
<li>JAVA_HOME：指向JDK安装目录（给其他软件用）</li>
<li>PATH：添加 %JAVA_HOME%\bin（让命令行直接识别命令）</li>
</ul>
<p>如何验证环境变量是否设置正确？</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="n">java</span><span class="w"> </span><span class="o">-</span><span class="n">version</span>
<span class="n">javac</span><span class="w"> </span><span class="o">-</span><span class="n">version</span>
</code></pre></div>

<p>预计输出：显示版本号（如 java version "17.0.x" 和 javac 17.0.x），无“不是内部或外部命令”错误。</p>
<blockquote>
<p>[!NOTE]</p>
<p>类比node -v和npm -v命令</p>
</blockquote>
