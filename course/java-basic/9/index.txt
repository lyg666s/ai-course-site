<h2 id="封装Encapsulation">封装（Encapsulation）</h2>
<p>封装是将数据（属性）和操作数据的方法捆绑在一起，并<strong>隐藏内部实现细节</strong>，仅通过公共方法访问数据。</p>
<h3 id="封装的好处">封装的好处</h3>
<table>
<thead>
<tr>
<th>好处</th>
<th>说明</th>
</tr>
</thead>

<tr>
<td><strong>数据安全</strong></td>
<td>防止外部直接修改敏感数据</td>
</tr>
<tr>
<td><strong>数据完整性</strong></td>
<td>在 setter 中添加校验逻辑，保证数据合法性</td>
</tr>

</tr>

<td>将变化隔离在类内部</td>

<h2 id="继承Inheritance">继承（Inheritance）</h2>
<p>继承允许一个类（子类）复用另一个类（父类）的属性和方法，实现<strong>代码复用</strong>和<strong>层次化</strong>设计。</p>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">sleep</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>

<h3 id="继承的特性">继承的特性</h3>
<ul>
<li>Java 只支持<strong>单继承</strong>（一个类只能有一个直接父类）</li>
<li>子类会继承父类所有非 <code>private</code> 的成员（属性和方法）</li>
<li>子类可以添加新的属性和方法</li>
<li>子类可以重写父类的方法</li>
</ul>
<h3 id="super-关键字">super 关键字</h3>
<p><code>super</code> 用于引用父类的成员（属性和方法）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Dog</span><span class="w"> </span><span class="kd">extends</span><span class="w"> </span><span class="n">Animal</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">breed</span><span class="p">;</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="nf">Dog</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">name</span><span class="p">,</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">breed</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="kd">super</span><span class="p">(</span><span class="n">name</span><span class="p">);</span><span class="w">      </span><span class="c1">// 调用父类构造方法（必须是第一条语句）</span>
<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">breed</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">breed</span><span class="p">;</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">display</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"名字: "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">name</span><span class="p">);</span><span class="w">        </span><span class="c1">// 继承自父类的属性</span>
<span class="w">        </span><span class="kd">super</span><span class="p">.</span><span class="na">eat</span><span class="p">();</span><span class="w">                    </span><span class="c1">// 调用父类方法</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"品种: "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">breed</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<ul>
<li><code>super()</code> 调用父类构造方法，必须是子类构造方法的第一条语句。</li>
<li>如果父类没有无参构造，子类必须显式调用父类有参构造。</li>
<li><code>super</code> 和 <code>this</code> 一样，不能在静态方法中使用。</li>
</ul>

<h3 id="方法重写Override">方法重写（Override）</h3>
<p>子类可以重新定义父类的方法，称为<strong>方法重写</strong>（Override）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">class</span> <span class="nc">Animal</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">sound</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"动物发出声音"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="kd">class</span> <span class="nc">Cat</span><span class="w"> </span><span class="kd">extends</span><span class="w"> </span><span class="n">Animal</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Override</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">sound</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"喵喵"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="kd">class</span> <span class="nc">Dog</span><span class="w"> </span><span class="kd">extends</span><span class="w"> </span><span class="n">Animal</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Override</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">sound</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"汪汪"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>重写规则：</strong></p>
<ul>
<li>方法名、参数列表必须相同</li>
<li>返回值类型必须相同或是其子类型（协变返回类型）</li>
<li>访问修饰符不能比父类更严格（例如父类为 <code>protected</code>，子类不能为 <code>private</code>）</li>
<li>不能重写 <code>final</code> 方法</li>
<li>使用 <code>@Override</code> 注解可以检查重写是否正确</li>
</ul>
<h3 id="方法重载-vs-方法重写">方法重载 vs 方法重写</h3>
<table>
<thead>
<tr>
<th>特性</th>
<th>方法重载（Overload）</th>
<th>方法重写（Override）</th>
</tr>
</thead>
<tbody>
<tr>
<td>发生位置</td>
<td>同一个类中</td>
<td>子类和父类之间</td>
</tr>
<tr>
<td>方法名</td>
<td>相同</td>
<td>相同</td>
</tr>
<tr>
<td>参数列表</td>
<td>必须不同</td>
<td>必须相同</td>
</tr>

<h2 id="多态Polymorphism">多态（Polymorphism）</h2>
<p>多态指同一个引用类型在不同情况下表现出不同的行为。</p>
<h3 id="向上转型Upcasting">向上转型（Upcasting）</h3>
<p>子类对象可以赋值给父类引用（自动转型）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="n">Animal</span><span class="w"> </span><span class="n">a1</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Dog</span><span class="p">(</span><span class="s">"旺财"</span><span class="p">);</span><span class="w">   </span><span class="c1">// 向上转型</span>
<span class="n">Animal</span><span class="w"> </span><span class="n">a2</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Cat</span><span class="p">(</span><span class="s">"咪咪"</span><span class="p">);</span>
</code></pre></div>

<h3 id="向上转型的应用">向上转型的应用</h3>
<ol>
<li><strong>方法参数使用父类类型</strong>，可传入任何子类对象。</li>
</ol>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">feedAnimal</span><span class="p">(</span><span class="n">Animal</span><span class="w"> </span><span class="n">a</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">a</span><span class="p">.</span><span class="na">eat</span><span class="p">();</span>
<span class="p">}</span>

<span class="n">feedAnimal</span><span class="p">(</span><span class="k">new</span><span class="w"> </span><span class="n">Dog</span><span class="p">(</span><span class="s">"旺财"</span><span class="p">));</span>
<span class="n">feedAnimal</span><span class="p">(</span><span class="k">new</span><span class="w"> </span><span class="n">Cat</span><span class="p">(</span><span class="s">"咪咪"</span><span class="p">));</span>
</code></pre></div>

<ol start="2">
<li><strong>返回类型为父类</strong>，实际返回子类对象。</li>
</ol>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="n">Animal</span><span class="w"> </span><span class="nf">getAnimal</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">type</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="k">if</span><span class="w"> </span><span class="p">(</span><span class="s">"dog"</span><span class="p">.</span><span class="na">equals</span><span class="p">(</span><span class="n">type</span><span class="p">))</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Dog</span><span class="p">(</span><span class="s">"旺财"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span><span class="w"> </span><span class="k">else</span><span class="w"> </span><span class="k">if</span><span class="w"> </span><span class="p">(</span><span class="s">"cat"</span><span class="p">.</span><span class="na">equals</span><span class="p">(</span><span class="n">type</span><span class="p">))</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Cat</span><span class="p">(</span><span class="s">"咪咪"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span><span class="w"> </span><span class="k">else</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Animal</span><span class="p">(</span><span class="s">"未知"</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="动态绑定-Dynamic-Binding">动态绑定 (Dynamic Binding)</h3>
<p>动态绑定（也称“运行时绑定”或“后期绑定”）是Java在<strong>运行时</strong>决定调用哪个方法的机制</p>
<p>要实现动态绑定，必须同时满足以下两个条件：</p>
<ol>
<li><strong>必须发生向上转型</strong>：即“父类引用子类对象”。</li>
<li><strong>子类必须重写父类的方法</strong>：即父类和子类拥有<strong>同名、同参数列表</strong>的方法</li>
</ol>
<div class="codehilite lang-java"><pre><span></span><code><span class="n">a1</span><span class="p">.</span><span class="na">sound</span><span class="p">();</span><span class="w">   </span><span class="c1">// 调用实际对象的 sound()，输出 "汪汪"</span>
<span class="n">a2</span><span class="p">.</span><span class="na">sound</span><span class="p">();</span><span class="w">   </span><span class="c1">// 输出 "喵喵"</span>
</code></pre></div>

<h3 id="向下转型Downcasting">向下转型（Downcasting）</h3>
<p>将父类引用强制转换为子类类型，用于调用子类特有的方法。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="n">Animal</span><span class="w"> </span><span class="n">a</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Dog</span><span class="p">(</span><span class="s">"旺财"</span><span class="p">);</span>
<span class="k">if</span><span class="w"> </span><span class="p">(</span><span class="n">a</span><span class="w"> </span><span class="k">instanceof</span><span class="w"> </span><span class="n">Dog</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">Dog</span><span class="w"> </span><span class="n">d</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="p">(</span><span class="n">Dog</span><span class="p">)</span><span class="w"> </span><span class="n">a</span><span class="p">;</span><span class="w">   </span><span class="c1">// 向下转型</span>
<span class="w">    </span><span class="n">d</span><span class="p">.</span><span class="na">bark</span><span class="p">();</span><span class="w">          </span><span class="c1">// 调用 Dog 特有的方法</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>使用父类引用调用方法时，只能调用父类中声明的方法，不能调用子类特有的方法。</li>
<li>向下转型前应使用 <code>instanceof</code> 检查，否则可能抛出 <code>ClassCastException</code>。</li>
<li>多态只针对<strong>方法</strong>，不针对属性（属性不参与多态）。</li>
</ul>
</blockquote>
