封装、继承和多态

课程目标

  • 理解封装的概念并掌握访问修饰符的使用
  • 理解继承的概念，掌握 extends 关键字和 super 的使用
  • 掌握方法重写（Override）和 @Override 注解
  • 理解多态的概念及其实现方式（向上转型、向下转型）
  • 能够运用封装、继承、多态设计程序

封装（Encapsulation）

封装是将数据（属性）和操作数据的方法捆绑在一起，并隐藏内部实现细节，仅通过公共方法访问数据。

封装的好处

好处 说明
数据安全 防止外部直接修改敏感数据
数据完整性 在 setter 中添加校验逻辑，保证数据合法性
灵活性 修改内部实现不影响外部调用
可维护性 将变化隔离在类内部

回顾：访问修饰符

修饰符 同一类 同一包 子类 任何地方
private ✓
default（无修饰符） ✓ ✓
protected ✓ ✓ ✓
public ✓ ✓ ✓ ✓

封装示例

public class BankAccount {
    private String accountNumber;
    private double balance;

    public BankAccount(String accountNumber, double initialBalance) {
        this.accountNumber = accountNumber;
        if (initialBalance >= 0) {
            this.balance = initialBalance;
        }
    }

    public String getAccountNumber() {
        return accountNumber;
    }

    public double getBalance() {
        return balance;
    }

    /**
     * 封装存款操作，不要直接修改余额字段
     */
    public void deposit(double amount) {
        if (isPositive(amount)) {
            balance += amount;
            printTransaction("存入", amount);
        } else {
            System.out.println("存款金额必须大于 0");
        }
    }

    /**
     * 封装提取操作，不要直接修改余额字段
     */
    public void withdraw(double amount) {
        if (isPositive(amount) && amount <= balance) {
            balance -= amount;
            printTransaction("取出", amount);
        } else {
            System.out.println("余额不足或金额无效");
        }
    }

    /**
     * 检查金额是否为正数
     */
    private boolean isPositive(double amount) {
        return amount > 0;
    }

    /**
     * 打印交易操作及当前余额
     */
    private void printTransaction(String operation, double amount) {
        System.out.println(operation + " " + amount + "，当前余额: " + balance);
    }
}

[!CAUTION]

  • 属性一般使用 private，提供 public getter/setter。
  • 不要为所有属性都生成 getter/setter，只暴露必要的。
  • 可以在 setter 中添加业务校验逻辑。

继承（Inheritance）

继承允许一个类（子类）复用另一个类（父类）的属性和方法，实现代码复用和层次化设计。

基本语法

使用 extends 关键字实现继承。

// 父类
public class Animal {
    protected String name;

    public Animal(String name) {
        this.name = name;
    }

    public void eat() {
        System.out.println(name + " 正在吃东西");
    }

    public void sleep() {
        System.out.println(name + " 正在睡觉");
    }
}

// 子类
public class Dog extends Animal {
    public Dog(String name) {
        super(name);  // 调用父类构造方法
    }

    public void bark() {
        System.out.println(name + " 汪汪叫");
    }
}

继承的特性

  • Java 只支持单继承（一个类只能有一个直接父类）
  • 子类会继承父类所有非 private 的成员（属性和方法）
  • 子类可以添加新的属性和方法
  • 子类可以重写父类的方法

super 关键字

super 用于引用父类的成员（属性和方法）。

public class Dog extends Animal {
    private String breed;

    public Dog(String name, String breed) {
        super(name);      // 调用父类构造方法（必须是第一条语句）
        this.breed = breed;
    }

    public void display() {
        System.out.println("名字: " + name);        // 继承自父类的属性
        super.eat();                    // 调用父类方法
        System.out.println("品种: " + breed);
    }
}

[!NOTE]

  • super() 调用父类构造方法，必须是子类构造方法的第一条语句。
  • 如果父类没有无参构造，子类必须显式调用父类有参构造。
  • super 和 this 一样，不能在静态方法中使用。

方法重写（Override）

子类可以重新定义父类的方法，称为方法重写（Override）。

class Animal {
    public void sound() {
        System.out.println("动物发出声音");
    }
}

class Cat extends Animal {
    @Override
    public void sound() {
        System.out.println("喵喵");
    }
}

class Dog extends Animal {
    @Override
    public void sound() {
        System.out.println("汪汪");
    }
}

重写规则：

  • 方法名、参数列表必须相同
  • 返回值类型必须相同或是其子类型（协变返回类型）
  • 访问修饰符不能比父类更严格（例如父类为 protected，子类不能为 private）
  • 不能重写 final 方法
  • 使用 @Override 注解可以检查重写是否正确

方法重载 vs 方法重写

特性 方法重载（Overload） 方法重写（Override）
发生位置 同一个类中 子类和父类之间
方法名 相同 相同
参数列表 必须不同 必须相同
返回值 无关 必须相同或其子类型
访问修饰符 无关 不能比父类更严格
注解 无专用注解 @Override

多态（Polymorphism）

多态指同一个引用类型在不同情况下表现出不同的行为。

向上转型（Upcasting）

子类对象可以赋值给父类引用（自动转型）。

Animal a1 = new Dog("旺财");   // 向上转型
Animal a2 = new Cat("咪咪");

向上转型的应用

  1. 方法参数使用父类类型，可传入任何子类对象。
public void feedAnimal(Animal a) {
    a.eat();
}

feedAnimal(new Dog("旺财"));
feedAnimal(new Cat("咪咪"));
  1. 返回类型为父类，实际返回子类对象。
public Animal getAnimal(String type) {
    if ("dog".equals(type)) {
        return new Dog("旺财");
    } else if ("cat".equals(type)) {
        return new Cat("咪咪");
    } else {
        return new Animal("未知");
    }
}

动态绑定 (Dynamic Binding)

动态绑定（也称“运行时绑定”或“后期绑定”）是Java在运行时决定调用哪个方法的机制

要实现动态绑定，必须同时满足以下两个条件：

  1. 必须发生向上转型：即“父类引用子类对象”。
  2. 子类必须重写父类的方法：即父类和子类拥有同名、同参数列表的方法
a1.sound();   // 调用实际对象的 sound()，输出 "汪汪"
a2.sound();   // 输出 "喵喵"

向下转型（Downcasting）

将父类引用强制转换为子类类型，用于调用子类特有的方法。

Animal a = new Dog("旺财");
if (a instanceof Dog) {
    Dog d = (Dog) a;   // 向下转型
    d.bark();          // 调用 Dog 特有的方法
}

[!CAUTION]

  • 使用父类引用调用方法时，只能调用父类中声明的方法，不能调用子类特有的方法。
  • 向下转型前应使用 instanceof 检查，否则可能抛出 ClassCastException。
  • 多态只针对方法，不针对属性（属性不参与多态）。

综合示例：动物园饲养系统

// 父类
class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + " 正在吃东西");
    }

    public void sleep() {
        System.out.println(name + " 正在睡觉");
    }

    public void displayInfo() {
        System.out.println("名字: " + name + ", 年龄: " + age);
    }
}

// 子类 Lion
class Lion extends Animal {
    public Lion(String name, int age) {
        super(name, age);
    }

    @Override
    public void eat() {
        System.out.println(name + " 正在吃肉");
    }

    public void roar() {
        System.out.println(name + " 吼叫！");
    }
}

// 子类 Elephant
class Elephant extends Animal {
    public Elephant(String name, int age) {
        super(name, age);
    }

    @Override
    public void eat() {
        System.out.println(name + " 正在吃草");
    }

    public void trumpet() {
        System.out.println(name + " 鸣叫！");
    }
}

// 饲养员
class ZooKeeper {
    public void feed(Animal a) {
        a.eat();  // 多态调用
    }
}

// 测试
public class ZooDemo {
    public static void main(String[] args) {
        ZooKeeper keeper = new ZooKeeper();
        Animal[] animals = {
            new Lion("辛巴", 5),
            new Elephant("多多", 8)
        };

        for (Animal a : animals) {
            a.displayInfo();
            keeper.feed(a);
            if (a instanceof Lion) {
                ((Lion) a).roar();
            } else if (a instanceof Elephant) {
                ((Elephant) a).trumpet();
            }
            System.out.println();
        }
    }
}

class Shape {
    public void draw() {
        System.out.println("绘制形状");
    }
}

class Circle extends Shape {
    @Override
    public void draw() {
        System.out.println("绘制圆形");
    }
}

class Square extends Shape {
    @Override
    public void draw() {
        System.out.println("绘制正方形");
    }
}

public class PolymorphismTest {
    public static void main(String[] args) {
        Shape s1 = new Circle();
        Shape s2 = new Square();
        Shape[] shapes = {s1, s2, new Shape()};
        for (Shape s : shapes) {
            s.draw();
        }
    }
}
