<h2 id="什么是泛型">什么是泛型</h2>
<p><strong>泛型（Generics）</strong> 是 Java SE 5 引入的特性，允许在定义类、接口和方法时使用<strong>类型参数</strong>（Type Parameter）。类型参数在使用时被具体的类型（如 <code>String</code>、<code>Integer</code>）替换，从而让代码能够适用于多种数据类型。</p>
<p>泛型的本质是<strong>参数化类型</strong>，即“类型”本身可以作为参数传递。</p>
<h3 id="为什么需要泛型">为什么需要泛型</h3>
<p>在引入泛型之前，Java 使用 <code>Object</code> 类型来实现通用代码，但存在两个严重问题：</p>
<p><strong>问题 1：类型不安全</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 没有泛型时：使用 Object 存储</span>
<span class="n">List</span><span class="w"> </span><span class="n">list</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">ArrayList</span><span class="p">();</span>
<span class="n">list</span><span class="p">.</span><span class="na">add</span><span class="p">(</span><span class="s">"hello"</span><span class="p">);</span>
<span class="n">list</span><span class="p">.</span><span class="na">add</span><span class="p">(</span><span class="mi">123</span><span class="p">);</span><span class="w">        </span><span class="c1">// 可以存入任何类型</span>

<span class="n">String</span><span class="w"> </span><span class="n">s</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="p">(</span><span class="n">String</span><span class="p">)</span><span class="w"> </span><span class="n">list</span><span class="p">.</span><span class="na">get</span><span class="p">(</span><span class="mi">0</span><span class="p">);</span><span class="w">  </span><span class="c1">// 需要强制转换</span>
<span class="c1">// String s2 = (String) list.get(1); // 运行时 ClassCastException！</span>
</code></pre></div>

<p><strong>问题 2：需要强制类型转换</strong></p>
<p>每次从集合中取出元素，都必须手动转换为目标类型，繁琐且容易出错。</p>
<p><strong>使用泛型后的改进：</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 使用泛型：指定元素类型</span>
<span class="n">List</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="w"> </span><span class="n">list</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">ArrayList</span><span class="o">&lt;&gt;</span><span class="p">();</span>
<span class="n">list</span><span class="p">.</span><span class="na">add</span><span class="p">(</span><span class="s">"hello"</span><span class="p">);</span>
<span class="c1">// list.add(123);   // 编译错误！类型不匹配</span>

<span class="n">String</span><span class="w"> </span><span class="n">s</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">list</span><span class="p">.</span><span class="na">get</span><span class="p">(</span><span class="mi">0</span><span class="p">);</span><span class="w">   </span><span class="c1">// 无需强制转换</span>
</code></pre></div>

<h2 id="类型通配符Wildcard">类型通配符（Wildcard）</h2>
<p>使用 <code>?</code> 表示<strong>未知类型</strong>，用于泛型参数中的灵活匹配。</p>
<h3 id="无界通配符">无界通配符：<code>&lt;?&gt;</code></h3>

<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="c1">// 调用</span>
<span class="n">List</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="w"> </span><span class="n">names</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Arrays</span><span class="p">.</span><span class="na">asList</span><span class="p">(</span><span class="s">"Alice"</span><span class="p">,</span><span class="w"> </span><span class="s">"Bob"</span><span class="p">);</span>

<h3 id="PECS-原则Producer-Extends-Consumer-Super">PECS 原则（Producer-Extends, Consumer-Super）</h3>
<table>
<thead>
<tr>
<th>场景</th>
<th>推荐通配符</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td>读取数据（Producer）</td>

<tr>
<td>写入数据（Consumer）</td>

</tr>
</tbody>
</table>
