<p><strong>编译型</strong>：源代码通过 <code>javac</code> 编译为字节码（<code>.class</code>），再由 JVM 解释/编译执行</p>
</li>
<li>
<p><strong>强类型</strong>：所有变量和表达式都有确定的类型，类型不匹配时编译报错</p>
</li>
<li>
<p><strong>静态类型</strong>：变量类型在编译时确定，不能动态改变</p>
</li>
<li>
<p><strong>面向对象</strong>：一切皆对象（除基本类型外），支持类、继承、多态、封装</p>
</li>
<li>
<p><strong>平台无关</strong>：通过 JVM 实现“一次编写，到处运行”</p>
</li>
<li>
<p><strong>自动内存管理</strong>：垃圾回收器（GC）自动回收不再使用的对象</p>
</li>
</ul>

<h3 id="类型转换">类型转换</h3>
<p>Java 的类型转换分为<strong>自动类型转换</strong>（隐式）和<strong>强制类型转换</strong>（显式）。</p>
<p><strong>自动类型转换</strong>（小范围 → 大范围，无精度损失）：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// byte -&gt; short -&gt; int -&gt; long -&gt; float -&gt; double（自动提升）</span>

<span class="kt">int</span><span class="w"> </span><span class="n">i</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">b</span><span class="p">;</span><span class="w">           </span><span class="c1">// 自动转换</span>
<span class="kt">long</span><span class="w"> </span><span class="n">l</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">i</span><span class="p">;</span><span class="w">          </span><span class="c1">// 自动转换</span>
<span class="kt">double</span><span class="w"> </span><span class="n">d</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">l</span><span class="p">;</span><span class="w">        </span><span class="c1">// 自动转换</span>
</code></pre></div>

<p><strong>强制类型转换</strong>（大范围 → 小范围，可能丢失精度）：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kt">double</span><span class="w"> </span><span class="n">d</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mf">3.9</span><span class="p">;</span>

<span class="kt">long</span><span class="w"> </span><span class="n">l</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mi">100L</span><span class="p">;</span>

<span class="c1">// 字符串与基本类型互转</span>
<span class="n">String</span><span class="w"> </span><span class="n">ageStr</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"25"</span><span class="p">;</span>

<span class="n">String</span><span class="w"> </span><span class="n">numStr</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">String</span><span class="p">.</span><span class="na">valueOf</span><span class="p">(</span><span class="mi">100</span><span class="p">);</span><span class="w">  </span><span class="c1">// int → 字符串</span>

<h3 id="作业三猜数字游戏">作业三：猜数字游戏</h3>
<p>编写一个猜数字游戏程序，要求如下：</p>
<ol>
<li><strong>随机生成数字</strong>：程序在 1~100 之间随机生成一个整数（含 1 和 100）。</li>
<li><strong>用户猜测</strong>：通过 <code>Scanner</code> 让用户输入猜测的数字。</li>
<li><strong>反馈与循环</strong>：
   - 如果猜测数字大于目标数字，提示“猜大了”；
   - 如果小于目标数字，提示“猜小了”；
   - 如果猜中，提示“恭喜你猜对了！”并结束游戏。
   - 每次猜测后，程序应继续让用户输入，直到猜对为止。</li>
<li><strong>统计次数</strong>：猜对后，输出用户一共猜了多少次。</li>
<li><strong>输入合法性检查</strong>：如果用户输入的不是整数（或超出 1~100 范围），给出错误提示并要求重新输入（可选，加分项）。</li>
</ol>

<h3 id="作业四简易计算器">作业四：简易计算器</h3>
<p>编写一个命令行计算器程序，支持加、减、乘、除四种运算，要求如下：</p>
<ol>
<li><strong>用户输入</strong>：循环读取用户输入，格式为 <code>数字1 运算符 数字2</code>，例如 <code>10 + 5</code>。</li>
<li><strong>支持运算符</strong>：<code>+</code>、<code>-</code>、<code>*</code>、<code>/</code>。</li>
<li><strong>计算结果</strong>：根据运算符计算并输出结果，结果保留两位小数（除法结果可能是浮点数）。</li>
<li><strong>异常处理</strong>：
   - 如果除法中除数为 0，输出“错误：除数不能为 0！”。
   - 如果输入格式不正确，提示“输入格式错误，请重新输入”。</li>
<li><strong>退出循环</strong>：当用户输入 <code>exit</code> 或 <code>quit</code> 时退出程序。</li>
<li><strong>循环执行</strong>：每次计算完成后，自动等待下一次输入，直到用户退出。</li>
</ol>
