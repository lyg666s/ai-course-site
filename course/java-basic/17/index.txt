<li><strong>单线程</strong>：你一个人先洗菜、再切菜、再炒菜、最后装盘——所有事情一步一步按顺序做。</li>

</ul>
<p>在这个例子中：</p>

<h2 id="进程与线程概述">进程与线程概述</h2>
<h3 id="进程Process">进程（Process）</h3>
<p>打开电脑的任务管理器，你会看到很多正在运行的程序：浏览器、音乐播放器、文本编辑器……每个运行中的程序就是一个<strong>进程</strong>。</p>
<p><strong>进程</strong>是操作系统进行资源分配的基本单位，是正在运行的程序实例。</p>
<p><strong>进程的特点：</strong></p>
<div class="codehilite lang-mermaid"><pre><span></span><code>graph TB
    subgraph OS[操作系统]
        subgraph P1[进程 A]
            M1[独立内存空间]
            R1[独立资源]
        end
        subgraph P2[进程 B]
            M2[独立内存空间]
            R2[独立资源]
        end
        subgraph P3[进程 C]
            M3[独立内存空间]
            R3[独立资源]
        end
    end

    P1 -.-&gt;|相互隔离| P2
    P2 -.-&gt;|相互隔离| P3

    style OS fill:#e1f5fe
    style P1 fill:#fff3e0
    style P2 fill:#fff3e0
    style P3 fill:#fff3e0
</code></pre></div>

<ul>
<li>每个进程有<strong>独立</strong>的内存空间（代码、数据、堆栈）。</li>
<li>进程之间相互隔离，一个进程崩溃不会影响其他进程。</li>
<li>进程切换开销较大（好比搬家，要把所有东西搬走再搬新的进来）。</li>
</ul>
<h3 id="线程Thread">线程（Thread）</h3>
<p>一个进程内部可以包含多个执行路径，每个执行路径就是一个<strong>线程</strong>。</p>
<p><strong>线程</strong>是操作系统调度的最小单位，是进程中的一条执行路径。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    subgraph Browser[进程：浏览器]
        T1[渲染线程&lt;br/&gt;显示页面]
        T2[JS 线程&lt;br/&gt;执行逻辑]
        T3[网络线程&lt;br/&gt;下载资源]
        T4[其他线程...]
    end

    T1 ~~~ T2
    T2 ~~~ T3
    T3 ~~~ T4

    Note1[同一进程内的所有线程&lt;br/&gt;共享内存空间]

    Browser -.-&gt; Note1

    style Browser fill:#e3f2fd
    style T1 fill:#e8f5e9
    style T2 fill:#e8f5e9
    style T3 fill:#e8f5e9
    style T4 fill:#e8f5e9
</code></pre></div>

<p><strong>线程的特点：</strong></p>
<ul>
<li>同一进程内的多个线程<strong>共享</strong>进程的内存空间。</li>
<li>每个线程有自己的存储局部变量和方法调用信息，并记录执行位置。</li>
<li>线程切换开销较小（好比在房间里换个人干活，不需要重新装修）。</li>
</ul>

<h3 id="并发与并行">并发与并行</h3>
<p>这两个概念很容易混淆，我们用图来理解：</p>
<p><strong>并发（Concurrency）</strong>：多个任务在<strong>同一时间段内</strong>交替执行。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>gantt
    title 并发执行（单核或多核 CPU）
    dateFormat HH:mm:ss
    axisFormat %H:%M:%S

    section 线程1
    执行 :a1, 00:00:00, 2s
    等待 :a2, after a1, 1s
    执行 :a3, after a2, 2s
    等待 :a4, after a3, 1s
    执行 :a5, after a4, 2s

    section 线程2
    等待 :b1, 00:00:00, 1s
    执行 :b2, after b1, 2s
    等待 :b3, after b2, 1s
    执行 :b4, after b3, 2s
    等待 :b5, after b4, 1s

    section 线程3
    等待 :c1, 00:00:00, 2s
    执行 :c2, after c1, 2s
    等待 :c3, after c2, 2s
    执行 :c4, after c3, 2s
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<p>同一时刻只有一个线程在执行，但看起来像同时进行</p>
</blockquote>
<p><strong>并行（Parallelism）</strong>：多个任务在<strong>同一时刻</strong>同时执行。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>gantt
    title 并行执行（多核 CPU）
    dateFormat HH:mm:ss
    axisFormat %H:%M:%S

    section CPU核心1
    线程1执行 :a1, 00:00:00, 6s

    section CPU核心2
    线程2执行 :b1, 00:00:00, 6s

    section CPU核心3
    线程3执行 :c1, 00:00:00, 6s
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<p>多个核心同时执行不同的线程</p>
</blockquote>

<p>在单核 CPU 上，多线程实现的是<strong>并发</strong>；在多核 CPU 上，多线程可以实现<strong>并行</strong>。Java 的多线程代码在两种情况下都能正常工作，由操作系统负责调度。</p>
</blockquote>

<h2 id="创建线程的三种方式">创建线程的三种方式</h2>
<h3 id="继承-Thread-类">继承 Thread 类</h3>
<p><strong>步骤拆解：</strong></p>
<ol>
<li>创建一个类，继承 <code>Thread</code></li>
<li>重写 <code>run()</code> 方法，把要执行的任务写在里面</li>
<li>创建该类的实例</li>
<li>调用 <code>start()</code> 方法启动线程</li>
</ol>
<p><strong>完整代码示例：</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 步骤1 + 步骤2：继承 Thread，重写 run()</span>
<span class="kd">class</span> <span class="nc">MyThread</span><span class="w"> </span><span class="kd">extends</span><span class="w"> </span><span class="n">Thread</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">run</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 这个线程要执行的任务</span>
<span class="w">        </span><span class="k">for</span><span class="w"> </span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">i</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mi">1</span><span class="p">;</span><span class="w"> </span><span class="n">i</span><span class="w"> </span><span class="o">&lt;=</span><span class="w"> </span><span class="mi">5</span><span class="p">;</span><span class="w"> </span><span class="n">i</span><span class="o">++</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>

<span class="w">            </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="n">getName</span><span class="p">()</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="s">" 打印: "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">i</span><span class="p">);</span>

<span class="w">        </span><span class="p">}</span>

<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">ThreadDemo1</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>

</blockquote>

<span class="n">t</span><span class="p">.</span><span class="na">run</span><span class="p">();</span><span class="w">  </span><span class="c1">// 错误！这不会启动新线程，只是在当前线程中执行 run()</span>
</code></pre></div>

<h3 id="实现-Runnable-接口">实现 Runnable 接口</h3>
<p>继承 <code>Thread</code> 有局限——Java 是单继承，如果类已经继承了别的类，就不能继承 <code>Thread</code> 了。这时可以用 <code>Runnable</code> 接口。</p>
<p><strong>步骤拆解：</strong></p>
<ol>
<li>创建一个类，实现 <code>Runnable</code> 接口</li>
<li>实现 <code>run()</code> 方法</li>
<li>创建 <code>Runnable</code> 实例</li>
<li>用 <code>Runnable</code> 实例作为参数创建 <code>Thread</code> 对象</li>
<li>调用 <code>Thread</code> 的 <code>start()</code> 方法</li>
</ol>
<p><strong>完整代码示例：</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 步骤1 + 步骤2：实现 Runnable 接口</span>
<span class="kd">class</span> <span class="nc">MyRunnable</span><span class="w"> </span><span class="kd">implements</span><span class="w"> </span><span class="n">Runnable</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Override</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">run</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>

<h3 id="实现-Callable-接口-FutureTask">实现 Callable 接口 + FutureTask</h3>
<p>前面的两种方式都不能<strong>返回结果</strong>。如果需要线程执行后返回一个结果，用 <code>Callable</code>。</p>
<p><strong>步骤拆解：</strong></p>
<ol>
<li>创建一个类，实现 <code>Callable&lt;V&gt;</code> 接口（<code>V</code> 是返回类型）</li>
<li>实现 <code>call()</code> 方法，返回结果</li>
<li>用 <code>Callable</code> 实例创建 <code>FutureTask</code></li>
<li>用 <code>FutureTask</code> 作为参数创建 <code>Thread</code></li>
<li>启动线程</li>
<li>调用 <code>futureTask.get()</code> 获取结果</li>
</ol>
