<h2 id="什么是异常">什么是异常</h2>
<p><strong>异常（Exception）</strong> 是程序在运行过程中发生的<strong>意外事件</strong>，它会中断程序的正常执行流程。Java 提供了一套完善的异常处理机制，使得程序能够<strong>优雅地处理错误</strong>，而不是直接崩溃。</p>
<h3 id="异常-vs-错误">异常 vs 错误</h3>
<table>
<thead>
<tr>
<th>概念</th>
<th>说明</th>
<th>示例</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>异常（Exception）</strong></td>
<td>程序可以捕获并处理的意外情况</td>
<td>文件不存在、网络断开、数组越界</td>
</tr>
<tr>
<td><strong>错误（Error）</strong></td>
<td>程序无法处理的严重问题，通常由 JVM 引发</td>
<td>内存溢出、栈溢出、虚拟机错误</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]</p>
<p>错误（<code>Error</code>）通常不是应用程序能够处理或应该处理的，因此异常处理主要针对 <code>Exception</code> 及其子类。</p>
</blockquote>
<h3 id="为什么需要异常处理">为什么需要异常处理</h3>
<ol>
<li><strong>程序健壮性</strong>：避免程序因意外情况而崩溃。</li>
<li><strong>用户友好</strong>：给出有意义的错误提示，而不是晦涩的底层错误信息。</li>
<li><strong>资源释放</strong>：确保在错误发生时也能正确释放资源（如文件流、数据库连接）。</li>
<li><strong>业务逻辑分离</strong>：将正常逻辑与错误处理逻辑分开，提高代码可读性。</li>
</ol>

<h3 id="检查异常Checked-Exceptionvs-非检查异常Unchecked-Exception">检查异常（Checked Exception）vs 非检查异常（Unchecked Exception）</h3>
<table>
<thead>
<tr>
<th>类型</th>
<th>说明</th>
<th>编译时检查</th>
<th>常见示例</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>检查异常</strong></td>
<td>必须<strong>显式处理</strong>（try-catch 或 throws），否则编译报错</td>
<td>是</td>
<td><code>IOException</code>, <code>SQLException</code>, <code>FileNotFoundException</code></td>
</tr>
<tr>
<td><strong>非检查异常</strong></td>
<td>不强制处理，通常由编程错误导致</td>
<td>否</td>
<td><code>NullPointerException</code>, <code>ArithmeticException</code>, <code>ArrayIndexOutOfBoundsException</code></td>
</tr>
<tr>
<td><strong>错误</strong></td>
<td>与异常类似，但表示严重问题，不推荐捕获</td>
<td>否</td>
<td><code>OutOfMemoryError</code>, <code>StackOverflowError</code></td>
</tr>
</tbody>
</table>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 检查异常：必须处理</span>

<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">readFile</span><span class="p">()</span><span class="w"> </span><span class="kd">throws</span><span class="w"> </span><span class="n">IOException</span><span class="w"> </span><span class="p">{</span><span class="w">  </span><span class="c1">// 必须声明或捕获</span>
<span class="w">    </span><span class="n">FileReader</span><span class="w"> </span><span class="n">fr</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">FileReader</span><span class="p">(</span><span class="s">"file.txt"</span><span class="p">);</span>
<span class="p">}</span>

<span class="c1">// 非检查异常：可以不处理（但建议处理）</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">divide</span><span class="p">(</span><span class="kt">int</span><span class="w"> </span><span class="n">a</span><span class="p">,</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">b</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="n">result</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">a</span><span class="w"> </span><span class="o">/</span><span class="w"> </span><span class="n">b</span><span class="p">;</span><span class="w">  </span><span class="c1">// 若 b=0，抛出 ArithmeticException（运行时异常）</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!CAUTION]</p>
<ul>
<li><strong>检查异常</strong>必须处理，体现了 Java 的“<strong>编译时安全</strong>”哲学。</li>
<li><strong>非检查异常</strong>通常是程序逻辑错误导致，应当通过改进代码来避免，而不是简单地捕获。</li>
</ul>
</blockquote>

<span class="w">            </span><span class="k">return</span><span class="w"> </span><span class="mi">1</span><span class="p">;</span>
<span class="w">        </span><span class="p">}</span><span class="w"> </span><span class="k">finally</span><span class="w"> </span><span class="p">{</span>
<span class="w">            </span><span class="k">return</span><span class="w"> </span><span class="mi">2</span><span class="p">;</span><span class="w">   </span><span class="c1">// 覆盖了 try 中的 return</span>
<span class="w">        </span><span class="p">}</span>
<span class="w">    </span><span class="p">}</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kd">static</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">main</span><span class="p">(</span><span class="n">String</span><span class="o">[]</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>

<p>如果方法内部可能抛出检查异常，有两种方式：</p>
<ol>
<li><strong>捕获处理</strong>（try-catch）</li>
<li><strong>声明抛出</strong>（throws），交由上层调用者处理</li>

<span class="p">}</span>

<span class="c1">// 方式2：声明抛出</span>

<span class="p">}</span>

<p>[!NOTE]</p>
<ul>
<li><code>throws</code> 可以声明多个异常类型，用逗号分隔。</li>

</ul>
</blockquote>
