<h2 id="什么是-Stream-API">什么是 Stream API</h2>
<p>回顾：<strong>函数式编程</strong>就是将函数作为一等公民，即允许把方法当作参数传递、赋值给变量。</p>
<p><strong>Stream API</strong> 是 Java 8 引入的一套用于处理集合数据的<strong>函数式编程</strong>工具。它允许我们以<strong>声明式</strong>的方式对数据源（如集合、数组）进行复杂的查询和变换操作，类似于 SQL 语句的<code>查询</code>风格。</p>
<p>Stream 本身<strong>不存储数据</strong>，而是从数据源（如 集合、数组）获取数据，通过<strong>流水线</strong>（Pipeline）的方式依次执行一系列操作，最终得到结果。</p>
<h3 id="为什么需要-Stream-API">为什么需要 Stream API</h3>
<p>在 Stream 出现之前，对集合的操作通常依赖 <strong>for 循环</strong> 或 <strong>Iterator</strong>，代码冗长且容易出错。</p>

<td><strong>声明式</strong></td>

<td><strong>流水线</strong></td>
<td>多个操作链接成一个流水线，按顺序执行</td>

</tr>

</tr>
<tr>
<td><strong>不可变</strong></td>
<td>Stream 不会修改数据源，而是产生新的结果</td>

<h2 id="注意事项">注意事项</h2>
<blockquote>
<p>[!CAUTION]</p>
<ul>
<li>Stream <strong>不会修改数据源</strong>。</li>
<li>一个 Stream <strong>只能被消费一次</strong>，终端操作后流即关闭，再次使用会抛出 <code>IllegalStateException</code>。</li>
<li>中间操作是<strong>惰性</strong>的，如果没有终端操作，中间操作不会执行。</li>
</ul>
</blockquote>
