<h2 id="枚举enum">枚举（enum）</h2>
<h3 id="什么是枚举">什么是枚举</h3>
<p>枚举是一种<strong>特殊的类</strong>，用于定义一组<strong>固定的常量</strong>。它提供类型安全的常量定义方式，比传统的<code>public static final</code>更强大、更安全。</p>
<p><strong>为什么需要枚举：</strong></p>
<ul>
<li>让代码更易读、更安全（限定取值范围）</li>
<li>可附加方法和字段，不仅仅是常量</li>
<li>编译器会检查赋值是否合法</li>
</ul>

<h2 id="文本块Text-Blocks">文本块（Text Blocks）</h2>
<h3 id="什么是文本块">什么是文本块</h3>
<p><strong>文本块（Text Blocks）</strong> 是Java 15引入的特性，用于简化多行字符串的编写。它以<code>"""</code>开头和结尾，保留换行和缩进。</p>
<p><strong>在文本块之前：</strong></p>

<h2 id="Record类">Record类</h2>
<h3 id="什么是Record">什么是Record</h3>
<p><strong>Record</strong>是Java 14引入的<strong>数据载体类</strong>，用于代替传统的Java Bean类（只有字段、构造方法、getter、equals/hashCode/toString）。Record会自动生成构造方法、访问器、<code>equals()</code>、<code>hashCode()</code>和<code>toString()</code>方法。</p>

<h2 id="Optional-容器类">Optional 容器类</h2>

<h3 id="判断规则速查">判断规则速查</h3>
<div class="codehilite"><pre><span></span><code>== 判断规则：

<h2 id="assert-断言语法">assert 断言语法</h2>

<p><strong>断言（assert）</strong> 是Java中的一种<strong>调试工具</strong>，用于在开发阶段检测程序中的假定条件是否为真。断言默认是禁用的，需要JVM参数启用。</p>

<span class="k">assert</span><span class="w"> </span><span class="n">条件</span><span class="w"> </span><span class="p">:</span><span class="w"> </span><span class="s">"错误消息"</span><span class="p">;</span>

<h3 id="作业一枚举使用">作业一：枚举使用</h3>

<ul>
<li><code>PENDING</code>（code=0, desc="待支付"）</li>
<li><code>PAID</code>（code=1, desc="已支付"）</li>
<li><code>CANCELLED</code>（code=2, desc="已取消"）</li>
<li><code>REFUNDED</code>（code=3, desc="已退款"）</li>
</ul>
<p>要求：枚举包含 <code>code</code> 和 <code>desc</code> 字段，提供构造方法、getter，并提供一个 <code>fromCode(int code)</code> 静态方法。</p>
