17:T4543,<h1 id="PII">PII</h1>
<p>本节学习如何使用 <code>PIIMiddleware</code> 检测并处理 Agent 中的个人身份信息。</p>
<h2 id="什么是-PII">什么是 PII</h2>
<p>PII 是 <strong>Personally Identifiable Information</strong> 的缩写，即个人身份信息。它是能够直接或间接识别某个人的信息，例如：</p>
<ul>
<li>姓名、身份证号、学号</li>
<li>手机号、邮箱、家庭住址</li>
<li>银行卡号、信用卡号</li>
<li>IP 地址、设备地址</li>
</ul>
<h2 id="PIIMiddleware">PIIMiddleware</h2>
<p><code>PIIMiddleware</code> 是 LangChain 提供的预置中间件。它使用确定性的检测规则找到消息中的 PII，再按照指定策略处理。</p>

<h3 id="拦截位置">拦截位置</h3>
<p><code>PIIMiddleware</code> 使用的是<strong>节点钩子</strong>，不是 <code>wrap_model_call</code> 或 <code>wrap_tool_call</code>。</p>
<div class="codehilite"><pre><span></span><code>  ...
   ↓
before_model  ← 检查点
   ↓
model
   ↓
after_model   ← 检查点
   ↓
  ...
</code></pre></div>

<p><code>before_model</code> 和 <code>after_model</code> 都可能在一次 Run 中执行多次，因此模型输出检查针对的是<strong>每次模型调用产生的 <code>AIMessage</code></strong>，而不只是 Run 的最终输出。</p>
<table>
<thead>
<tr>
<th>参数</th>
<th>默认值</th>
<th>检查对象</th>
<th>执行位置</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>apply_to_input</code></td>
<td><code>True</code></td>
<td>最近一条 <code>HumanMessage</code></td>
<td><code>before_model</code></td>
</tr>
<tr>
<td><code>apply_to_output</code></td>
<td><code>False</code></td>
<td>最近一条 <code>AIMessage</code></td>
<td><code>after_model</code></td>
</tr>
<tr>
<td><code>apply_to_tool_results</code></td>
<td><code>False</code></td>
<td>工具产生的 <code>ToolMessage</code></td>
<td>下一次调用模型前的 <code>before_model</code></td>
</tr>
</tbody>
</table>
<p>检测到 PII 后，中间件会创建处理后的新消息，并返回 <code>{'messages': new_messages}</code> 更新图状态。因此它修改的不只是临时模型请求，最终图状态中的对应消息也会改变。</p>
<blockquote>
<p><code>block</code> 是例外：它会抛出异常并终止 Run，不会把脱敏消息写入状态。</p>
</blockquote>
