18:T1287,<h1 id="认识-Docker-Compose">认识 Docker Compose</h1>
<h2 id="动机">动机</h2>
<p>在真实的企业开发中，无论是传统的后端应用，还是 Agent 应用，都需要一系列基础设施作为支持。</p>
<p>比如，一个 Agent 应用需要：</p>
<ul>
<li><code>langfuse</code>：实现 Agent 的观察与评估</li>
<li><code>PostgreSQL</code>：存储业务数据，比如：用户会话、检查点、DataSet 等等</li>
<li><code>Redis</code>：存储临时数据，比如缓存、消息队列等</li>
<li><code>minio</code>：对象存储，保存静态数据</li>
<li><code>clickhouse</code>：存储日志、指标等分析型数据，可进行高速统计查询</li>
<li><code>pgadmin</code>：数据管理控制面</li>
<li>...</li>
</ul>
<p>这些基础设施在开发阶段，往往都是以 Docker容器 的形态启动。</p>
<p>如果分开管理，就涉及到一系列的问题：</p>
<ol>
<li>容器之间如何通信</li>
</ol>
<p>只能手动的把它们加到一个docker网络。</p>
<ol start="2">
<li>每个容器需要的环境变量不一致</li>
</ol>
<p>只能在每次启动容器时，手动给它设置环境变量。</p>
<ol start="3">
<li>容器间存在依赖怎么处理？</li>
</ol>
<p>只能在脑海中记住它们的依赖关系：先启动被依赖的容器，再启动依赖它的容器。</p>
<p>我们希望以上问题能以更加简洁、优雅、自动化的方式处理。</p>
<p>这就要依靠<code>Docker Compose</code>。</p>
<p><code>Docker Compose</code>称之为容器编排，它允许通过一个配置文件（<code>docker-compose.yml</code>），集中性的管理一个企业级工程所需要的所有容器。</p>
<p>简单来说：<code>Docker Compose</code>提供一个入口，通过该入口，统一管理多个容器。</p>
<h2 id="认识-docker-composeyml">认识 docker-compose.yml</h2>
<div class="codehilite lang-yaml"><pre><span></span><code><span class="nt">name</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">deal-pilot</span><span class="w">  </span><span class="c1"># 提供一个分组名称，所有的容器都收归进该分组，通常为项目名称</span>

<span class="nt">services</span><span class="p">:</span><span class="w"> </span><span class="c1"># 核心配置，描述当前分组下，有哪些服务，每个服务对应一个容器</span>
<span class="w">    </span><span class="nt">pgadmin</span><span class="p">:</span><span class="w"> </span>
<span class="w">    </span><span class="nt">langfuse-worker</span><span class="p">:</span>
<span class="w">    </span><span class="nt">langfuse-web</span><span class="p">:</span>
<span class="w">    </span><span class="nt">clickhouse</span><span class="p">:</span>
<span class="w">    </span><span class="nt">minio</span><span class="p">:</span>
<span class="w">    </span><span class="nt">redis</span><span class="p">:</span>

<h2 id="常用命令">常用命令</h2>
<div class="codehilite lang-shell"><pre><span></span><code><span class="c1"># 创建并在后台启动所有容器</span>
docker<span class="w"> </span>compose<span class="w"> </span>up<span class="w"> </span>-d

<span class="c1"># 查看容器状态</span>
docker<span class="w"> </span>compose<span class="w"> </span>ps

<span class="c1"># 持续查看所有容器的日志，按 Ctrl+C 退出</span>
