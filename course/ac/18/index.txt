<h1 id="Tool-Calling">Tool Calling</h1>
<p>大模型只能处理输入得到输出，没有任何其他功能。</p>
<p>而在Agent应用中，经常会出现希望：</p>
<ul>
<li>大模型读取或写入一个文件</li>
<li>执行一段命令</li>
<li>联网搜索一些资料</li>
<li>...</li>
</ul>
<p>这些功能大模型都无法直接处理。</p>
<p>如果需要大模型去完成一些除了文本输出之外的功能的时候，就需要借助<code>Tool Calling</code></p>
<p><img loading="lazy" src="/ai-course-site/ac/assets/ch18/tool_calling.svg" ></p>

<h2 id="调用模型">调用模型</h2>
<p>大模型厂商通常会将你传递的工具放到系统上下文的末尾，比如：</p>
<div class="codehilite"><pre><span></span><code>&lt;|im_start|&gt;system&lt;|im_sep|&gt;

namespace functions {
    // 读取文件
    type read_file = ({
        // 文件的绝对路径，或相对于cwd的路径
        file_path: string
    }) =&gt; any;
    // 写入文件
    type write_file = ({
        // 文件的绝对路径，或相对于cwd的路径
        file_path: string;
        // 待写入的内容
        content: string
    }) =&gt; any;
}
