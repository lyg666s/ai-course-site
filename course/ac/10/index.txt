16:Tbf0,<h1 id="词嵌入-word-embedding">词嵌入 word embedding</h1>
<blockquote>
<p>词嵌入是 transformer 架构前向传播的第一个阶段</p>
</blockquote>
<h2 id="Token的问题">Token的问题</h2>
<p>在预处理阶段，通过分词器，拿到了一个Token ID的序列</p>
<p>但Token ID序列是不能直接拿来进行训练的。</p>
<p>问题的根源在于：</p>
<ul>
<li><strong>Token ID 无法表示语义</strong></li>
</ul>
<p>Token ID 只是表示一个文字符号。仅靠单个符号无法表示它背后丰富的语义。</p>
<p>比如：你知道某个Token 对应的文字 <code>كِتاب</code> 是什么含义吗</p>
<ul>
<li><strong>Token ID 无法表达语义之间的数学关系</strong></li>
</ul>
<p>假设"吃苹果"，对应的 Token 序列是 <code>[33256, 11789]</code></p>
<p>请问<code>33256 + 11789</code>是什么含义？</p>
<p>因此我们需要<strong>更多的维度</strong>来描述一个token。</p>
<h2 id="使用向量描述-Token">使用向量描述 Token</h2>
<p>比如，<strong>苹果</strong>这个词，可以描述为：</p>
<ul>
<li>一种食物</li>
<li>和科技有关系</li>
<li>昂贵的</li>
</ul>
<p>如果数字化来表示，可以表示为3个维度：</p>
<ul>
<li>维度1（可被食用的程度）：0.9</li>
<li>维度2（科技程度）：0.6</li>
<li>维度3（消费水平）：0.5</li>
</ul>
<p>此时如果有另一个Token，它被描述为：</p>
<ul>
<li>维度1（可被食用的程度）：0.7</li>
<li>维度2（科技程度）：0.8</li>
<li>维度3（消费水平）：0.3</li>
</ul>
<p>如果把这个维度的值放到一个三维空间中，可以想象，这两个token在空间中是比较接近的。</p>
<blockquote>
<p>向量可视化：https://projector.tensorflow.org/</p>
</blockquote>
<p>当我们把Token转换成多个维度的数字来表达后，它们之间就可以形成一些有趣的数学关系，比如：</p>
<ul>
<li>$苹果\approx Apple$</li>
<li>$国王 - 王后 \approx 男人 - 女人$</li>
<li>$男人+医生\approx男医生$</li>
<li>$2×开心≈狂喜$</li>
<li>...</li>
</ul>
<p>把一个token转换成多个维度的数字向量，这一过程称之为<strong>词嵌入 word embedding</strong></p>
<blockquote>
<p>嵌入（Embedding）这个词的本意，就是把低维离散对象，“镶嵌、植入” 到一个连续高维几何空间里。</p>
</blockquote>
<p>但问题是，我们应该规定每个token有多少个维度呢？每个维度又表达什么含义呢？每个维度的值又是什么呢？</p>
<p><strong>在深度学习中，我们只规定学习方法，永远不要告诉机器答案</strong></p>
<p>因此，我们仅规定有多少维度即可，让机器在训练的过程中，为每一个Token的每一个维度填写具体的值。</p>
