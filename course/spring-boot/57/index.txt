<h2 id="Micrometer-核心概念">Micrometer 核心概念</h2>
<h3 id="核心接口">核心接口</h3>
<p>Micrometer 的核心接口是 <code>Meter</code>，所有度量类型都继承自它：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kd">interface</span> <span class="nc">Meter</span><span class="w"> </span><span class="kd">extends</span><span class="w"> </span><span class="n">AutoCloseable</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 获取 Meter 的唯一标识</span>
<span class="w">    </span><span class="n">Id</span><span class="w"> </span><span class="nf">getId</span><span class="p">();</span>
<span class="w">    </span><span class="c1">// 获取 Meter 类型</span>
<span class="w">    </span><span class="n">Meter</span><span class="p">.</span><span class="na">Type</span><span class="w"> </span><span class="nf">getType</span><span class="p">();</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="Meter-三要素">Meter 三要素</h3>
<p>每个 Meter 由<strong>名称</strong>和<strong>标签（Tag）</strong> 唯一标识：</p>
<table>
<thead>
<tr>
<th>要素</th>
<th>说明</th>
<th>示例</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>name</code></td>
<td>指标名称，主键</td>
<td><code>http.server.requests</code></td>
</tr>
<tr>
<td><code>tags</code></td>
<td>维度键值对，用于切片和钻取</td>
<td><code>uri=/api/books</code>, <code>status=200</code></td>
</tr>
<tr>
<td><code>type</code></td>
<td>Meter 类型（Counter、Gauge、Timer 等）</td>
<td><code>Counter</code></td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]
Micrometer 会将名称和标签统一存储，通过 Actuator 端点可以查看和过滤。</p>
</blockquote>
<h3 id="MeterRegistry">MeterRegistry</h3>
<p><code>MeterRegistry</code> 是 Meter 的工厂和缓存中心：</p>
<ul>
<li><strong>工厂</strong>：负责创建各类 Meter</li>
<li><strong>缓存</strong>：同一名称 + 标签组合的 Meter 只创建一次</li>
<li><strong>存储</strong>：保存所有已注册的 Meter 实例</li>
</ul>
<p>Spring Boot 会自动配置一个 <code>CompositeMeterRegistry</code> 和合适的实现（默认是 <code>SimpleMeterRegistry</code>），无需额外依赖。</p>
<h3 id="Meter-类型体系">Meter 类型体系</h3>
<table>
<thead>
<tr>
<th>类型</th>
<th>语义</th>
<th>典型场景</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Counter</strong></td>
<td>单调递增计数器</td>
<td>请求总数、错误次数</td>
</tr>
<tr>
<td><strong>Gauge</strong></td>
<td>瞬时值，可增可减</td>
<td>内存使用量、队列大小、线程数</td>
</tr>
<tr>
<td><strong>Timer</strong></td>
<td>记录事件次数和执行时间</td>
<td>接口响应时间、方法耗时</td>
</tr>
</tbody>
</table>
<p><strong>Counter 和 Gauge 的核心区别</strong>：Counter 只增不减，代表累积量；Gauge 反映瞬时状态，可以上下波动。Timer 本质上是 Counter 和耗时统计的结合体——它既记录事件发生的次数，也记录每次事件所花费的时间。</p>

<h2 id="自定义指标">自定义指标</h2>
<p>内置指标覆盖了技术和基础设施层面，但业务级别的指标（订单量、支付成功率、缓存命中率）需要开发者自行创建。</p>
<h3 id="实现方式">实现方式</h3>
<p>自定义指标有多种实现方式：</p>
<table>
<thead>
<tr>
<th>方式</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td>注入 <code>MeterRegistry</code></td>
<td>最灵活，适合动态标签和复杂逻辑</td>
</tr>
<tr>
<td>使用 <code>@Counted</code> 注解</td>
<td>统计方法调用次数，非侵入</td>
</tr>
<tr>
<td>使用 <code>@Timed</code> 注解</td>
<td>统计方法执行时间，非侵入</td>
</tr>
<tr>
<td>使用 <code>Gauge</code> 绑定对象</td>
<td>适合绑定瞬时值（如队列大小）</td>
</tr>
<tr>
<td>使用 <code>MeterBinder</code></td>
<td>适合将已有对象的状态批量绑定为指标</td>
</tr>
</tbody>
</table>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-指标基数控制">1. 指标基数控制</h3>
<p>每个唯一的标签组合都会产生一条时间序列。<strong>高基数标签</strong>会导致指标数据量膨胀：</p>
<table>
<thead>
<tr>
<th>标签类型</th>
<th>示例</th>
<th>风险</th>
</tr>
</thead>
<tbody>
<tr>
<td>低基数（安全）</td>
<td><code>status=success</code>、<code>method=GET</code></td>
<td>值有限，推荐使用</td>
</tr>
<tr>
<td>高基数（危险）</td>
<td><code>userId=12345</code>、<code>orderId=...</code></td>
<td>值无限，禁止作为标签</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!CAUTION]
切勿将用户 ID、订单 ID、请求 ID 等唯一值作为标签。这类数据应放在日志或追踪系统中，而非指标系统。</p>
</blockquote>
<h3 id="2-指标命名规范">2. 指标命名规范</h3>
<table>
<thead>
<tr>
<th>规则</th>
<th>示例</th>
</tr>
</thead>
<tbody>
<tr>
<td>使用点分小写</td>
<td><code>books.created</code>，而非 <code>BooksCreated</code></td>
</tr>
<tr>
<td>名称体现业务语义</td>
<td><code>orders.created</code>，而非 <code>counter1</code></td>
</tr>
<tr>
<td>单位放在名称末尾</td>
<td><code>books.query.time</code>（秒）、<code>cache.size</code>（个）</td>
</tr>
<tr>
<td>用标签区分维度，而非名称</td>
<td><code>books.created{status=success}</code>，而非 <code>books.created.success</code></td>
</tr>
</tbody>
</table>
<h3 id="3-指标采集与健康检查分离">3. 指标采集与健康检查分离</h3>
<p>指标监控不应影响业务性能。避免在请求路径中同步调用外部监控系统：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 不推荐：在请求中同步上报</span>
<span class="kd">public</span><span class="w"> </span><span class="n">Book</span><span class="w"> </span><span class="nf">create</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">Book</span><span class="w"> </span><span class="n">result</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">bookMapper</span><span class="p">.</span><span class="na">insert</span><span class="p">(</span><span class="n">book</span><span class="p">);</span>
<span class="w">    </span><span class="n">httpClient</span><span class="p">.</span><span class="na">post</span><span class="p">(</span><span class="s">"http://monitor/report"</span><span class="p">,</span><span class="w"> </span><span class="n">result</span><span class="p">);</span><span class="w">  </span><span class="c1">// 阻塞</span>
<span class="w">    </span><span class="k">return</span><span class="w"> </span><span class="n">result</span><span class="p">;</span>

<span class="c1">// 推荐：使用 Micrometer，由 Actuator 端点统一查看</span>

<span class="w">    </span><span class="n">Book</span><span class="w"> </span><span class="n">result</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">bookMapper</span><span class="p">.</span><span class="na">insert</span><span class="p">(</span><span class="n">book</span><span class="p">);</span>
<span class="w">    </span><span class="n">bookMetrics</span><span class="p">.</span><span class="na">recordSuccess</span><span class="p">();</span>

<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>Micrometer 核心概念</strong>：
   - <code>Meter</code>、<code>MeterRegistry</code>、<code>Tag</code> 三要素
   - Meter 类型体系（Counter、Gauge、Timer）</li>
<li><strong>内置指标</strong>：
   - JVM、系统、HTTP、数据源、缓存等自动采集指标
   - 通过 <code>management.metrics.enable</code> 禁用不需要的指标</li>
<li><strong>自定义指标</strong>：
   - 注入 <code>MeterRegistry</code> 编程式创建
   - <code>@Counted</code> / <code>@Timed</code> 注解式统计
   - <code>Gauge</code> 绑定对象、<code>MeterBinder</code> 批量绑定</li>
<li><strong>指标查看</strong>：
   - 通过 <code>/actuator/metrics</code> 查看所有指标
   - 按名称和标签过滤</li>
</ol>
