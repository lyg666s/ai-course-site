<h2 id="分页实现方式">分页实现方式</h2>
<h3 id="分页方式对比">分页方式对比</h3>
<table>
<thead>
<tr>
<th>方式</th>
<th>实现原理</th>
<th>优点</th>
<th>缺点</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>RowBounds</strong></td>
<td>逻辑分页，在内存中截取</td>

</tr>

<h3 id="方式一RowBounds不推荐">方式一：RowBounds（不推荐）</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 逻辑分页：先查询全部，再截取</span>
<span class="n">RowBounds</span><span class="w"> </span><span class="n">rowBounds</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">RowBounds</span><span class="p">(</span><span class="n">offset</span><span class="p">,</span><span class="w"> </span><span class="n">limit</span><span class="p">);</span>
<span class="n">List</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="n">books</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">sqlSession</span><span class="p">.</span><span class="na">selectList</span><span class="p">(</span><span class="s">"selectAll"</span><span class="p">,</span><span class="w"> </span><span class="kc">null</span><span class="p">,</span><span class="w"> </span><span class="n">rowBounds</span><span class="p">);</span>
</code></pre></div>

<blockquote>
<p>[!CAUTION]
RowBounds 会查询所有数据，仅在内存中截取，<strong>大数据量下性能极差</strong>，不推荐使用。</p>
</blockquote>
<h3 id="方式二手写-LIMIT物理分页">方式二：手写 LIMIT（物理分页）</h3>
<div class="codehilite lang-xml"><pre><span></span><code><span class="nt">&lt;select</span><span class="w"> </span><span class="na">id=</span><span class="s">"selectByPage"</span><span class="w"> </span><span class="na">resultType=</span><span class="s">"Book"</span><span class="nt">&gt;</span>
<span class="w">    </span>SELECT<span class="w"> </span>id,<span class="w"> </span>title,<span class="w"> </span>author,<span class="w"> </span>price,<span class="w"> </span>stock
<span class="w">    </span>FROM<span class="w"> </span>book
<span class="w">    </span>ORDER<span class="w"> </span>BY<span class="w"> </span>id
<span class="w">    </span>LIMIT<span class="w"> </span>#{offset},<span class="w"> </span>#{limit}
<span class="nt">&lt;/select&gt;</span>
</code></pre></div>

<div class="codehilite lang-java"><pre><span></span><code><span class="n">List</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">selectByPage</span><span class="p">(</span><span class="nd">@Param</span><span class="p">(</span><span class="s">"offset"</span><span class="p">)</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">offset</span><span class="p">,</span><span class="w"> </span><span class="nd">@Param</span><span class="p">(</span><span class="s">"limit"</span><span class="p">)</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">limit</span><span class="p">);</span>

<blockquote>
<p>[!NOTE]
手写 LIMIT 简单直观，但每个查询都要写分页逻辑，且不同数据库语法不同。</p>
</blockquote>
<h3 id="方式三PageHelper-分页插件推荐">方式三：PageHelper 分页插件（推荐）</h3>

<h2 id="MyBatis-缓存机制">MyBatis 缓存机制</h2>
<p>MyBatis 提供两级缓存，减少重复查询，提升性能。</p>
<h3 id="一级缓存SqlSession-级别">一级缓存（SqlSession 级别）</h3>
<ul>
<li><strong>默认开启</strong>，作用范围为同一个 SqlSession。</li>
<li>在同一个 SqlSession 中执行相同 SQL 和参数，直接返回缓存结果。</li>
</ul>
<p><strong>测试示例：</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="k">try</span><span class="w"> </span><span class="p">(</span><span class="n">SqlSession</span><span class="w"> </span><span class="n">session</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">sqlSessionFactory</span><span class="p">.</span><span class="na">openSession</span><span class="p">())</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">BookMapper</span><span class="w"> </span><span class="n">mapper</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">session</span><span class="p">.</span><span class="na">getMapper</span><span class="p">(</span><span class="n">BookMapper</span><span class="p">.</span><span class="na">class</span><span class="p">);</span>
<span class="w">    </span><span class="c1">// 第一次查询</span>
<span class="w">    </span><span class="n">Book</span><span class="w"> </span><span class="n">book1</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">mapper</span><span class="p">.</span><span class="na">selectById</span><span class="p">(</span><span class="mi">1L</span><span class="p">);</span>
<span class="w">    </span><span class="c1">// 第二次查询（命中一级缓存）</span>
<span class="w">    </span><span class="n">Book</span><span class="w"> </span><span class="n">book2</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">mapper</span><span class="p">.</span><span class="na">selectById</span><span class="p">(</span><span class="mi">1L</span><span class="p">);</span>
<span class="w">    </span><span class="c1">// book1 == book2（同一对象）</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>失效场景：</strong>
- 执行 <code>insert</code>、<code>update</code>、<code>delete</code> 后缓存清空
- 手动调用 <code>sqlSession.clearCache()</code>
- 不同 SqlSession 之间独立</p>
<h3 id="二级缓存Mapper-级别">二级缓存（Mapper 级别）</h3>
<ul>
<li><strong>默认关闭</strong>，需手动开启。</li>
<li>作用范围为同一个 Mapper（namespace），可跨 SqlSession 共享。</li>
</ul>
<p><strong>开启二级缓存：</strong></p>
<ol>
<li>在 MyBatis 配置中启用：</li>
</ol>
<div class="codehilite lang-yaml"><pre><span></span><code><span class="nt">mybatis</span><span class="p">:</span>
<span class="w">  </span><span class="nt">configuration</span><span class="p">:</span>
<span class="w">    </span><span class="nt">cache-enabled</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">true</span>
</code></pre></div>

<ol start="2">
<li>在 Mapper XML 中添加 <code>&lt;cache&gt;</code> 标签：</li>
</ol>
<div class="codehilite lang-xml"><pre><span></span><code><span class="nt">&lt;mapper</span><span class="w"> </span><span class="na">namespace=</span><span class="s">"com.example.bookmanager.mapper.BookMapper"</span><span class="nt">&gt;</span>
<span class="w">    </span><span class="cm">&lt;!-- 启用二级缓存 --&gt;</span>
<span class="w">    </span><span class="nt">&lt;cache</span><span class="w"> </span>
<span class="w">        </span><span class="na">eviction=</span><span class="s">"LRU"</span>
<span class="w">        </span><span class="na">flushInterval=</span><span class="s">"60000"</span>
<span class="w">        </span><span class="na">size=</span><span class="s">"512"</span>
<span class="w">        </span><span class="na">readOnly=</span><span class="s">"false"</span><span class="nt">/&gt;</span>
<span class="nt">&lt;/mapper&gt;</span>
</code></pre></div>

<ol start="3">
<li>实体类需实现 <code>Serializable</code> 接口（缓存可能序列化到磁盘或网络）。</li>
</ol>
<p><strong>缓存配置属性</strong></p>

<p>[!CAUTION]

</blockquote>
<p><strong>使用二级缓存：</strong></p>
<div class="codehilite lang-xml"><pre><span></span><code><span class="nt">&lt;select</span><span class="w"> </span><span class="na">id=</span><span class="s">"selectById"</span><span class="w"> </span><span class="na">resultType=</span><span class="s">"Book"</span><span class="w"> </span><span class="na">useCache=</span><span class="s">"true"</span><span class="nt">&gt;</span>

<h3 id="缓存使用场景">缓存使用场景</h3>
<ul>
<li><strong>一级缓存</strong>：在同一个事务内重复查询时自动生效，无需额外配置。</li>
<li><strong>二级缓存</strong>：适用于不常变动的字典表、配置表，建议开启后监控命中率。</li>
</ul>
<h2 id="MyBatis-拦截器">MyBatis 拦截器</h2>
<p>MyBatis 允许通过<strong>拦截器（Interceptor）</strong> 对 SQL 执行过程进行 AOP 增强，这是其最强大的扩展点之一。</p>
<h3 id="拦截器原理">拦截器原理</h3>
<p>MyBatis 的四大核心对象（<code>Executor</code>、<code>StatementHandler</code>、<code>ParameterHandler</code>、<code>ResultSetHandler</code>）都可以被拦截。通过在方法执行前后插入逻辑，我们可以：</p>
<ul>
<li>记录 SQL 执行耗时</li>
<li>打印或改写 SQL</li>
<li>实现自定义分页、读写分离等</li>
</ul>
<h3 id="实现慢-SQL-监控拦截器">实现慢 SQL 监控拦截器</h3>
<h4 id="1-创建拦截器类">1. 创建拦截器类</h4>
<p>在项目中新建 <code>SlowSqlInterceptor</code>，实现 <code>Interceptor</code> 接口，并拦截 <code>Executor</code> 的 <code>query</code> 和 <code>update</code> 方法：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Intercepts</span><span class="p">({</span>
<span class="w">        </span><span class="nd">@Signature</span><span class="p">(</span><span class="n">type</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Executor</span><span class="p">.</span><span class="na">class</span><span class="p">,</span><span class="w"> </span><span class="n">method</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"query"</span><span class="p">,</span>
<span class="w">                </span><span class="n">args</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="p">{</span><span class="n">MappedStatement</span><span class="p">.</span><span class="na">class</span><span class="p">,</span><span class="w"> </span><span class="n">Object</span><span class="p">.</span><span class="na">class</span><span class="p">,</span><span class="w"> </span><span class="n">RowBounds</span><span class="p">.</span><span class="na">class</span><span class="p">,</span><span class="w"> </span><span class="n">ResultHandler</span><span class="p">.</span><span class="na">class</span><span class="p">,</span><span class="w"> </span><span class="n">CacheKey</span><span class="p">.</span><span class="na">class</span><span class="p">,</span><span class="w"> </span><span class="n">BoundSql</span><span class="p">.</span><span class="na">class</span><span class="p">})</span>
<span class="p">})</span>

<h2 id="注意事项">注意事项</h2>
<ol>
<li>PageHelper 分页失效场景</li>
</ol>
<ul>
<li>
<p><code>PageHelper.startPage()</code> 必须放在查询<strong>之前</strong>，且与查询在同一个方法中。</p>
</li>
<li>
<p>分页参数仅在<strong>第一次查询</strong>生效，若查询后又执行其他查询，需重新设置。</p>
</li>
<li>
<p>多线程环境下，<code>PageHelper.startPage()</code> 是线程安全的（基于 ThreadLocal），但需确保每个线程独立调用。</p>
</li>
</ul>
<ol start="2">
<li>缓存数据一致性</li>
</ol>
<ul>
<li>
<p><strong>一级缓存</strong>：在 Spring 环境下，SqlSession 由 Spring 管理，一个事务对应一个 SqlSession，所以事务内重复查询可享受一级缓存。</p>
</li>
<li>
<p><strong>二级缓存</strong>：若数据变更频繁，不建议开启，否则可能读取到过期数据。</p>
</li>
</ul>
<ol start="3">
<li>拦截器使用</li>
</ol>
<ul>
<li>
<p>慢 SQL 阈值应结合业务合理设置，避免过于敏感或迟钝。</p>
</li>
<li>
<p>生产环境下，建议将慢 SQL 日志单独输出到文件，便于<strong>集中分析</strong>。</p>
</li>
</ul>
