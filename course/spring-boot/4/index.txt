17:Te1f1,<h2 id="课程目标">课程目标</h2>
<ul>
<li>掌握 <code>application.properties</code> 和 <code>application.yml</code> 两种配置文件的格式</li>

<h2 id="配置文件格式">配置文件格式</h2>

<h2 id="读取配置的两种方式">读取配置的两种方式</h2>
<h3 id="方式一Value-注解">方式一：@Value 注解</h3>
<p><code>@Value</code> 用于将配置文件中的单个值注入到字段中。</p>
<p><strong>配置文件（application.yml）：</strong></p>
<div class="codehilite lang-yaml"><pre><span></span><code><span class="nt">app</span><span class="p">:</span>
<span class="w">  </span><span class="nt">name</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">图书管理系统</span>
<span class="w">  </span><span class="nt">version</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">1.0.0</span>
<span class="w">  </span><span class="nt">welcome-message</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">欢迎使用图书管理系统！</span>
</code></pre></div>

<p><strong>代码中使用：</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kn">package</span><span class="w"> </span><span class="nn">com.example.bookmanager.controller</span><span class="p">;</span>

<span class="kn">import</span><span class="w"> </span><span class="nn">org.springframework.beans.factory.annotation.Value</span><span class="p">;</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">org.springframework.web.bind.annotation.GetMapping</span><span class="p">;</span>
<span class="kn">import</span><span class="w"> </span><span class="nn">org.springframework.web.bind.annotation.RestController</span><span class="p">;</span>

<span class="nd">@RestController</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">ConfigController</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="nd">@Value</span><span class="p">(</span><span class="s">"${app.name}"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">appName</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@Value</span><span class="p">(</span><span class="s">"${app.version}"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">appVersion</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@Value</span><span class="p">(</span><span class="s">"${app.welcome-message:默认欢迎语}"</span><span class="p">)</span><span class="w">  </span><span class="c1">// 冒号后面是默认值</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="n">welcomeMessage</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@GetMapping</span><span class="p">(</span><span class="s">"/info"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="nf">getAppInfo</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="n">String</span><span class="p">.</span><span class="na">format</span><span class="p">(</span><span class="s">"应用: %s, 版本: %s"</span><span class="p">,</span><span class="w"> </span><span class="n">appName</span><span class="p">,</span><span class="w"> </span><span class="n">appVersion</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="nd">@GetMapping</span><span class="p">(</span><span class="s">"/welcome"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="nf">getWelcome</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="n">welcomeMessage</span><span class="p">;</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>访问 <code>/info</code> 返回：</strong></p>
<div class="codehilite lang-text"><pre><span></span><code>应用: 图书管理系统, 版本: 1.0.0

<blockquote>
<p>[!NOTE]
<code>@Value</code> 中的 <code>${}</code> 是占位符语法，<code>${app.welcome-message:默认欢迎语}</code> 表示如果配置中没有 <code>app.welcome-message</code>，则使用默认值“默认欢迎语”。</p>

<span class="w">    </span><span class="p p-Indicator">-</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">图书管理</span>
<span class="w">    </span><span class="p p-Indicator">-</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">用户管理</span>

<h3 id="Value-vs-ConfigurationProperties"><strong>@Value vs @ConfigurationProperties：</strong></h3>
<table>
<thead>
<tr>
<th>对比</th>
<th>@Value</th>
<th>@ConfigurationProperties</th>
</tr>
</thead>
<tbody>
<tr>
<td>适用场景</td>
<td>单个配置值</td>
<td>一组相关配置</td>
</tr>
<tr>
<td>类型安全</td>
<td>弱（字符串转换）</td>
<td>强（自动类型转换）</td>
</tr>
<tr>
<td>复杂类型</td>
<td>不支持 List/Map</td>
<td>支持 List/Map</td>
</tr>
<tr>
<td>代码整洁度</td>
<td>字段分散</td>
<td>集中管理</td>
</tr>
<tr>
<td>IDE 支持</td>
<td>无代码提示</td>
<td>有代码提示（需添加处理器）</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]</p>
<p>要在使用 <code>@ConfigurationProperties</code> 时实现代码提示，核心是为项目添加 <strong><code>spring-boot-configuration-processor</code></strong> 依赖。</p>
<blockquote>
<p><code>xml
&lt;dependency&gt;
        &lt;groupId&gt;org.springframework.boot&lt;/groupId&gt;
        &lt;artifactId&gt;spring-boot-configuration-processor&lt;/artifactId&gt;
        &lt;optional&gt;true&lt;/optional&gt;
&lt;/dependency&gt;</code></p>
</blockquote>
<p>这个注解处理器会在编译时，为你的自定义配置类生成一个元数据（metadata）文件。IDE（如 IntelliJ IDEA）正是通过读取这个文件，才知道你的自定义属性，从而实现自动补全、跳转和文档提示。</p>
</blockquote>
<p>同时，需要确保 IDE 注解处理已开启，操作方法如下：</p>
<ul>
<li>打开 <code>Settings</code> (或 <code>Preferences</code>)。</li>
<li>导航到 <code>Build, Execution, Deployment</code> -&gt; <code>Compiler</code> -&gt; <code>Annotation Processors</code>。</li>
<li>确保 <strong><code>Enable annotation processing</code></strong> 选项已被勾选</li>
</ul>
<p>然后<strong>重新构建项目</strong>：添加依赖并确认 IDE 设置无误后，<strong>必须执行一次完整的项目重建（Rebuild）</strong>。这会触发注解处理器运行，并在 <code>target/classes/META-INF/</code> 目录下生成 <code>spring-configuration-metadata.json</code> 文件</p>

<h2 id="配置加载优先级">配置加载优先级</h2>
<p>Spring Boot 支持多种配置来源，它们之间存在<strong>优先级顺序</strong>（后面的优先级更高）：</p>
<div class="codehilite"><pre><span></span><code>优先级从低到高：
1. 默认配置（Spring Boot 内置默认值）
2. application.yml / application.properties（项目内）
3. application-{profile}.yml（环境专用配置）
4. 外部配置文件（jar 包同目录的 /config 子目录）
5. 外部配置文件（jar 包同目录）
6. 命令行参数（--server.port=9090）
7. 环境变量（SPRING_APPLICATION_JSON）
8. 系统属性（-Dserver.port=9090）
</code></pre></div>

<h3 id="优先级演示">优先级演示</h3>
<p><strong>场景：</strong> 同时存在以下配置来源：</p>
<ol>
<li><code>application.yml</code>：<code>server.port: 8080</code></li>
<li><code>application-dev.yml</code>：<code>server.port: 8081</code>（激活 dev）</li>
<li>命令行参数：<code>--server.port=9090</code></li>
</ol>
<p><strong>最终生效的端口是 9090</strong>（命令行参数优先级最高）。</p>
<h3 id="配置覆盖规则">配置覆盖规则</h3>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    Default[默认配置] --&gt; App[application.yml]
    App --&gt; Profile[application-dev.yml]
    Profile --&gt; Cmd[命令行参数]
    Cmd --&gt; Env[环境变量]
    Env --&gt; System[-D系统属性]

    System --&gt; Result[最终配置]
</code></pre></div>

<blockquote>
<p>[!NOTE]
优先级高的配置会<strong>覆盖</strong>优先级低的配置，而不是合并。</p>

<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>两种配置文件格式</strong>：Properties 和 YAML，推荐使用 YAML。</li>
<li><strong>读取配置的两种方式</strong>：
   - <code>@Value</code>：适合单个配置值
   - <code>@ConfigurationProperties</code>：适合一组相关配置（推荐）</li>
<li><strong>多环境配置（Profile）</strong>：
   - 使用 <code>application-{profile}.yml</code> 区分环境
   - 通过 <code>spring.profiles.active</code> 激活
   - 支持多种激活方式（配置文件、命令行、环境变量）</li>
<li><strong>配置加载优先级</strong>：命令行参数 &gt; 环境变量 &gt; 系统属性 &gt; Profile 配置 &gt; 默认配置</li>
<li><strong>实战应用</strong>：为图书管理系统添加了多环境配置</li>
</ol>
