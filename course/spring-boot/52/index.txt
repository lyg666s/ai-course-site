<h3 id="2-JobExplorer-与-JobOperator-的区别">2. JobExplorer 与 JobOperator 的区别</h3>
<table>
<thead>
<tr>
<th>组件</th>
<th>用途</th>
<th>是否修改数据</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>JobExplorer</code></td>
<td>查询作业信息</td>
<td>否（只读）</td>
</tr>
<tr>
<td><code>JobOperator</code></td>
<td>操作作业（启动、停止、重启）</td>
<td>是</td>
</tr>
</tbody>
</table>
<h3 id="3-重启的条件">3. 重启的条件</h3>
<p>作业重启需要满足：
- 作业状态为 <code>FAILED</code> 或 <code>STOPPED</code>
- 作业未完成
- 作业参数允许重启</p>
<h3 id="4-分页查询">4. 分页查询</h3>
<p><code>getJobInstances(jobName, start, count)</code> 支持分页：</p>
<ul>
<li><code>start</code>：起始索引（从 0 开始）</li>
<li><code>count</code>：返回数量</li>
</ul>
<h3 id="5-作业名称与实例">5. 作业名称与实例</h3>
<ul>
<li>同一个作业名 + 相同参数 = 同一个 JobInstance</li>
<li>同一个作业名 + 不同参数 = 不同的 JobInstance</li>
<li>使用 <code>JOB_KEY</code>（参数哈希）区分</li>
</ul>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>JobRepository 概述</strong>：持久化作业执行信息</li>
<li><strong>元数据表详解</strong>：
   - <code>BATCH_JOB_INSTANCE</code>：作业实例
   - <code>BATCH_JOB_EXECUTION</code>：作业执行
   - <code>BATCH_STEP_EXECUTION</code>：步骤执行
   - <code>BATCH_JOB_EXECUTION_PARAMS</code>：作业参数</li>
<li><strong>JobExplorer</strong>：查询作业执行历史（只读）</li>
<li><strong>JobOperator</strong>：停止、重启作业</li>
<li><strong>实战应用</strong>：为图书管理系统实现作业监控接口</li>
</ol>
