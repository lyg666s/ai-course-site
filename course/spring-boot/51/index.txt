<h2 id="Chunk-模型深入">Chunk 模型深入</h2>
<h3 id="Chunk-执行流程">Chunk 执行流程</h3>
<div class="codehilite lang-mermaid"><pre><span></span><code>sequenceDiagram
    participant Reader as ItemReader
    participant Processor as ItemProcessor
    participant Writer as ItemWriter
    participant Tx as 事务

    Tx-&gt;&gt;Tx: 开启事务
    loop 每次读取一条
        Reader-&gt;&gt;Reader: read()
        Reader-&gt;&gt;Processor: 传递数据
        Processor-&gt;&gt;Processor: process()
        Processor-&gt;&gt;Writer: 加入 chunk
    end
    Note over Reader,Writer: Chunk 达到指定大小
    Writer-&gt;&gt;Writer: write(chunk)
    Tx-&gt;&gt;Tx: 提交事务
    Tx-&gt;&gt;Tx: 开启新事务
</code></pre></div>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-FlatFileItemReader-的编码问题">1. FlatFileItemReader 的编码问题</h3>
<p>如果 CSV 文件包含中文，务必设置 <code>encoding("UTF-8")</code>，否则可能乱码。</p>
<h3 id="2-列名与字段名映射">2. 列名与字段名映射</h3>
<ul>
<li><code>targetType(Book.class)</code> 要求 CSV 列名与 Java 字段名一致</li>
<li>如果列名不同，使用 <code>FieldSetMapper</code> 自定义映射</li>
</ul>
<h3 id="3-ItemProcessor-返回-null-的含义">3. ItemProcessor 返回 null 的含义</h3>
<ul>
<li>返回 <code>null</code> 表示过滤该条数据，不传递给 Writer</li>
<li>这是 Spring Batch 内置的过滤机制，无需额外配置</li>
</ul>
<h3 id="4-Chunk-大小与事务">4. Chunk 大小与事务</h3>
<ul>
<li>每个 Chunk 作为一个事务单元，全部成功才提交</li>
<li>如果 Chunk 中某条数据失败，整个 Chunk 回滚</li>
</ul>
<h3 id="5-JdbcBatchItemWriter-的批量机制">5. JdbcBatchItemWriter 的批量机制</h3>
<ul>
<li><code>JdbcBatchItemWriter</code> 底层使用 <code>PreparedStatement.addBatch()</code>，性能远高于逐条写入</li>
<li>命名参数（<code>:title</code>）配合 <code>BeanPropertyItemSqlParameterSourceProvider</code> 或 <code>beanMapped()</code> 使用</li>
</ul>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>ItemReader 常用实现</strong>：
   - <code>FlatFileItemReader</code>：读取 CSV/文本文件
   - <code>JdbcPagingItemReader</code>：分页读取数据库
   - <code>FieldSetMapper</code>：自定义列映射</li>
<li><strong>ItemProcessor 处理逻辑</strong>：
   - 数据转换、数据过滤、数据校验
   - <code>CompositeItemProcessor</code> 组合多个 Processor</li>
<li><strong>ItemWriter 常用实现</strong>：
   - <code>JdbcBatchItemWriter</code>：批量写入数据库
   - <code>FlatFileItemWriter</code>：写入文件</li>
<li><strong>Chunk 模型深入</strong>：
   - 执行流程、事务机制
   - Chunk 大小的选择原则</li>
<li><strong>实战应用</strong>：从 CSV 文件导入图书数据，包含数据清洗、过滤和批量写入</li>
</ol>
