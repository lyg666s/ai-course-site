<h2 id="从编程式事务到声明式事务">从编程式事务到声明式事务</h2>
<h3 id="回顾编程式事务">回顾编程式事务</h3>
<p>上一节课我们使用 <code>TransactionTemplate</code> 实现了编程式事务：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">OrderService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="kd">final</span><span class="w"> </span><span class="n">TransactionTemplate</span><span class="w"> </span><span class="n">transactionTemplate</span><span class="p">;</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">Order</span><span class="w"> </span><span class="nf">createOrder</span><span class="p">(</span><span class="n">Order</span><span class="w"> </span><span class="n">order</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="n">transactionTemplate</span><span class="p">.</span><span class="na">execute</span><span class="p">(</span><span class="n">status</span><span class="w"> </span><span class="o">-&gt;</span><span class="w"> </span><span class="p">{</span>
<span class="w">            </span><span class="c1">// 业务逻辑...</span>
<span class="w">            </span><span class="k">return</span><span class="w"> </span><span class="n">orderRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">order</span><span class="p">);</span>
<span class="w">        </span><span class="p">});</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<p><strong>编程式事务的问题：</strong></p>
<ul>
<li>事务逻辑和业务逻辑混合在一起</li>
<li>每个需要事务的方法都需要重复编写事务模板代码</li>
<li>代码可读性降低</li>
</ul>
<h3 id="声明式事务的优势">声明式事务的优势</h3>
<p>声明式事务基于 AOP 实现，通过 <code>@Transactional</code> 注解声明事务边界，将事务管理与业务逻辑分离。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">OrderService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Transactional</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">Order</span><span class="w"> </span><span class="nf">createOrder</span><span class="p">(</span><span class="n">Order</span><span class="w"> </span><span class="n">order</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 业务逻辑（事务由 AOP 自动管理）</span>
<span class="w">        </span><span class="k">return</span><span class="w"> </span><span class="n">orderRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">order</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>

</code></pre></div>

<h2 id="事务传播行为">事务传播行为</h2>
<h3 id="传播行为概述">传播行为概述</h3>
<p>事务传播行为定义了<strong>当一个事务方法被另一个事务方法调用时，事务如何传播</strong>。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    A[方法A&lt;br/&gt;调用] --&gt; B[方法B&lt;br/&gt;被调用]
    B --&gt; C{传播行为}
    C --&gt; D[加入已有事务]
    C --&gt; E[新建事务]
    C --&gt; F[非事务执行]

    style D fill:#e8f5e9
    style E fill:#e3f2fd
    style F fill:#fff3e0
</code></pre></div>

<h3 id="七种传播行为">七种传播行为</h3>
<table>
<thead>
<tr>
<th>传播行为</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>REQUIRED（默认）</strong></td>
<td>当前存在事务则加入，否则新建</td>
</tr>
<tr>
<td><strong>SUPPORTS</strong></td>
<td>当前存在事务则加入，否则无事务执行</td>
</tr>
<tr>
<td><strong>MANDATORY</strong></td>
<td>当前必须存在事务，否则抛出异常</td>
</tr>
<tr>
<td><strong>REQUIRES_NEW</strong></td>
<td>新建事务，挂起当前事务</td>
</tr>
<tr>
<td><strong>NOT_SUPPORTED</strong></td>
<td>以非事务方式执行，挂起当前事务</td>
</tr>
<tr>
<td><strong>NEVER</strong></td>
<td>以非事务方式执行，当前存在事务则抛出异常</td>
</tr>
<tr>
<td><strong>NESTED</strong></td>
<td>当前存在事务则在嵌套事务中执行</td>
</tr>
</tbody>
</table>
<h3 id="传播行为详解与示例">传播行为详解与示例</h3>
<h4 id="REQUIRED默认">REQUIRED（默认）</h4>
<p>如果当前存在事务，则加入；如果没有，则新建一个事务。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">OrderService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">PaymentService</span><span class="w"> </span><span class="n">paymentService</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@Transactional</span><span class="w">  </span><span class="c1">// REQUIRED（默认）</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createOrder</span><span class="p">(</span><span class="n">Order</span><span class="w"> </span><span class="n">order</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">orderRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">order</span><span class="p">);</span>
<span class="w">        </span><span class="c1">// 调用另一个 @Transactional 方法</span>
<span class="w">        </span><span class="n">paymentService</span><span class="p">.</span><span class="na">processPayment</span><span class="p">(</span><span class="n">order</span><span class="p">);</span><span class="w">  </span><span class="c1">// 加入同一个事务</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">PaymentService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Transactional</span><span class="w">  </span><span class="c1">// REQUIRED（默认）</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">processPayment</span><span class="p">(</span><span class="n">Order</span><span class="w"> </span><span class="n">order</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">paymentRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">order</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>执行流程：</strong></p>
<div class="codehilite lang-text"><pre><span></span><code>createOrder() 启动事务 T1
  └── paymentService.processPayment()
        └── 加入事务 T1（不新建）
</code></pre></div>

<h4 id="REQUIRES_NEW">REQUIRES_NEW</h4>
<p>每次调用都会新建一个独立的事务，挂起当前事务。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">AuditService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Transactional</span><span class="p">(</span><span class="n">propagation</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Propagation</span><span class="p">.</span><span class="na">REQUIRES_NEW</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">logOperation</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">message</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 即使外层事务失败，审计日志仍能保存</span>
<span class="w">        </span><span class="n">auditRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">message</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">OrderService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Transactional</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createOrder</span><span class="p">(</span><span class="n">Order</span><span class="w"> </span><span class="n">order</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">orderRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">order</span><span class="p">);</span>
<span class="w">        </span><span class="k">try</span><span class="w"> </span><span class="p">{</span>
<span class="w">            </span><span class="n">auditService</span><span class="p">.</span><span class="na">logOperation</span><span class="p">(</span><span class="s">"创建订单"</span><span class="p">);</span><span class="w">  </span><span class="c1">// 独立事务</span>
<span class="w">        </span><span class="p">}</span><span class="w"> </span><span class="k">catch</span><span class="w"> </span><span class="p">(</span><span class="n">Exception</span><span class="w"> </span><span class="n">e</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">            </span><span class="c1">// 审计日志异常不影响主事务</span>
<span class="w">        </span><span class="p">}</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>执行流程：</strong></p>
<div class="codehilite lang-text"><pre><span></span><code>createOrder() 启动事务 T1
  └── auditService.logOperation()
        └── 挂起 T1，创建新事务 T2
        └── 提交 T2
        └── 恢复 T1
（T1 回滚不影响 T2）
</code></pre></div>

<blockquote>
<p>[!NOTE]
<code>REQUIRES_NEW</code> 常用于审计日志、历史记录等需要独立事务的场景，即使主事务回滚，这些记录仍然保留。</p>
</blockquote>
<h4 id="NESTED">NESTED</h4>
<p>如果当前存在事务，则创建一个嵌套事务；如果没有，则与 <code>REQUIRED</code> 行为相同。嵌套事务是当前事务的子事务，可以通过保存点（Savepoint）实现部分回滚。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">OrderService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Transactional</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createOrder</span><span class="p">(</span><span class="n">Order</span><span class="w"> </span><span class="n">order</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">orderRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">order</span><span class="p">);</span>
<span class="w">        </span><span class="c1">// 嵌套事务：如果扣款失败，只回滚嵌套部分</span>
<span class="w">        </span><span class="n">paymentService</span><span class="p">.</span><span class="na">deductPayment</span><span class="p">(</span><span class="n">order</span><span class="p">);</span><span class="w">  </span><span class="c1">// NESTED</span>
<span class="w">        </span><span class="n">inventoryService</span><span class="p">.</span><span class="na">reduceStock</span><span class="p">(</span><span class="n">order</span><span class="p">);</span><span class="w">  </span><span class="c1">// NESTED</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">PaymentService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Transactional</span><span class="p">(</span><span class="n">propagation</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Propagation</span><span class="p">.</span><span class="na">NESTED</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">deductPayment</span><span class="p">(</span><span class="n">Order</span><span class="w"> </span><span class="n">order</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 嵌套事务</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!CAUTION]
<code>NESTED</code> 需要 JDBC 3.0+ 和 Savepoint 支持。某些数据库可能不支持，使用前需确认。</p>
</blockquote>
<h4 id="SUPPORTS">SUPPORTS</h4>
<p>如果有事务则加入，否则以非事务方式执行。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Transactional</span><span class="p">(</span><span class="n">propagation</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Propagation</span><span class="p">.</span><span class="na">SUPPORTS</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="n">List</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">findAllBooks</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 有事务则使用，没有也无所谓</span>
<span class="w">    </span><span class="k">return</span><span class="w"> </span><span class="n">bookRepository</span><span class="p">.</span><span class="na">findAll</span><span class="p">();</span>
<span class="p">}</span>
</code></pre></div>

<h4 id="MANDATORY">MANDATORY</h4>
<p>必须存在事务，否则抛出 <code>IllegalTransactionStateException</code>。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Transactional</span><span class="p">(</span><span class="n">propagation</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Propagation</span><span class="p">.</span><span class="na">MANDATORY</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">updateBook</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 必须被事务方法调用，否则抛异常</span>
<span class="p">}</span>
</code></pre></div>

<h4 id="NOT_SUPPORTED">NOT_SUPPORTED</h4>
<p>以非事务方式执行，如果当前存在事务则挂起。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Transactional</span><span class="p">(</span><span class="n">propagation</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Propagation</span><span class="p">.</span><span class="na">NOT_SUPPORTED</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">generateReport</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 不需要事务，挂起当前事务</span>
<span class="p">}</span>
</code></pre></div>

<h4 id="NEVER">NEVER</h4>
<p>以非事务方式执行，如果当前存在事务则抛出异常。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Transactional</span><span class="p">(</span><span class="n">propagation</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">Propagation</span><span class="p">.</span><span class="na">NEVER</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">simpleQuery</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 绝对不能在有事务的情况下调用</span>
<span class="p">}</span>
</code></pre></div>

<h2 id="Transactional-失效场景分析">@Transactional 失效场景分析</h2>
<h3 id="场景一非-public-方法">场景一：非 public 方法</h3>
<p><code>@Transactional</code> 只能在 <code>public</code> 方法上生效。AOP 代理无法拦截非 <code>public</code> 方法。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// ❌ 不生效：private 方法</span>
<span class="w">    </span><span class="nd">@Transactional</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">doSomething</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>

<span class="w">    </span><span class="c1">// ✅ 生效：public 方法</span>
<span class="w">    </span><span class="nd">@Transactional</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">doSomethingPublic</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="场景二同类方法自调用">场景二：同类方法自调用</h3>
<p>在同一个类中，一个方法调用另一个 <code>@Transactional</code> 方法，会绕过代理，事务不生效。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createBookAndLog</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// ❌ 直接调用，事务不生效</span>
<span class="w">        </span><span class="n">createBook</span><span class="p">(</span><span class="n">book</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="nd">@Transactional</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createBook</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">bookRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">book</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>解决方案一：将调用方法也加上事务（推荐）</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Transactional</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createBookAndLog</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">createBook</span><span class="p">(</span><span class="n">book</span><span class="p">);</span><span class="w">  </span><span class="c1">// 在同一事务中执行</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>解决方案二：注入自身（通过代理调用）</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">self</span><span class="p">;</span><span class="w">  </span><span class="c1">// 注入自身代理</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createBookAndLog</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// ✅ 通过代理调用，事务生效</span>
<span class="w">        </span><span class="n">self</span><span class="p">.</span><span class="na">createBook</span><span class="p">(</span><span class="n">book</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="nd">@Transactional</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">createBook</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">bookRepository</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="n">book</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="场景三异常类型不匹配">场景三：异常类型不匹配</h3>
<p>默认情况下，<code>@Transactional</code> 只对 <code>RuntimeException</code> 和 <code>Error</code> 回滚，对受检异常（<code>Exception</code>）不回滚。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// ❌ 不会回滚：捕获了受检异常，但未设置 rollbackFor</span>
<span class="nd">@Transactional</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">updateBook</span><span class="p">(</span><span class="n">Book</span><span class="w"> </span><span class="n">book</span><span class="p">)</span><span class="w"> </span><span class="kd">throws</span><span class="w"> </span><span class="n">Exception</span><span class="w"> </span><span class="p">{</span>

<h2 id="注意事项">注意事项</h2>
<ol>
<li><strong>事务方法应尽量精简</strong>：只包含需要事务保护的操作，避免大事务影响性能。</li>
<li><strong>只读事务性能优化</strong>：查询方法设置 <code>readOnly = true</code>，数据库可进行优化。</li>
<li><strong>避免在事务中执行耗时操作</strong>：如远程调用、文件操作等，会长时间持有连接。</li>
<li><strong>注意事务传播行为的组合</strong>：<code>REQUIRES_NEW</code> 和 <code>NESTED</code> 需根据业务场景选择。</li>
<li><strong>测试事务是否生效</strong>：可使用 <code>@Rollback</code> 注解进行测试。</li>
</ol>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>声明式事务的优势</strong>：AOP 驱动，无代码侵入，将事务与业务分离。</li>
<li><strong>@Transactional 注解</strong>：核心属性（传播行为、隔离级别、超时、只读、回滚规则）。</li>
<li><strong>七种事务传播行为</strong>：
   - <code>REQUIRED</code>（默认）加入或创建
   - <code>REQUIRES_NEW</code> 新建独立事务
   - <code>NESTED</code> 创建嵌套事务（Savepoint）
   - 其他：<code>SUPPORTS</code>、<code>MANDATORY</code>、<code>NOT_SUPPORTED</code>、<code>NEVER</code></li>
<li><strong>隔离级别</strong>：<code>DEFAULT</code>、<code>READ_UNCOMMITTED</code>、<code>READ_COMMITTED</code>、<code>REPEATABLE_READ</code>、<code>SERIALIZABLE</code>。</li>
<li><strong>@Transactional 失效场景</strong>：非 public、自调用、异常被捕获、异常类型不匹配、数据库引擎不支持。</li>
</ol>
