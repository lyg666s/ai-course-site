<h2 id="SpringBootTest-概述">@SpringBootTest 概述</h2>
<h3 id="什么是-SpringBootTest">什么是 @SpringBootTest</h3>
<p><strong>@SpringBootTest</strong> 是 Spring Boot 提供的集成测试注解，它加载<strong>完整的 Spring 应用上下文</strong>，包括所有 Bean、配置、数据源等。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    A[完整上下文&lt;br/&gt;@SpringBootTest] --&gt; B[Controller]
    A --&gt; C[Service]
    A --&gt; D[Mapper]
    A --&gt; E[DataSource]
    A --&gt; F[所有 @Configuration]
    A --&gt; G[所有 @Component]

    style A fill:#e8f5e9
</code></pre></div>

<td>不启动 Web 环境</td>
<td>❌</td>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-SpringBootTest-启动慢">1. @SpringBootTest 启动慢</h3>
<p><code>@SpringBootTest</code> 会加载完整上下文，启动较慢。优化建议：</p>
<ul>
<li><strong>减少集成测试数量</strong>：只保留关键流程的集成测试</li>
<li><strong>复用上下文</strong>：相同配置的测试类会共享上下文（Spring TestContext 缓存）</li>
<li><strong>使用切片测试</strong>：能覆盖的场景优先使用切片测试</li>
</ul>
<h3 id="2-webEnvironment-的选择">2. webEnvironment 的选择</h3>
<table>
<thead>
<tr>
<th>场景</th>
<th>推荐</th>
</tr>
</thead>
<tbody>
<tr>
<td>测试 Controller 层</td>
<td><code>MOCK</code>（默认）+ MockMvc</td>
</tr>
<tr>
<td>测试完整 HTTP 链路</td>
<td><code>RANDOM_PORT</code> + TestRestTemplate</td>
</tr>
<tr>
<td>需要固定端口</td>
<td><code>DEFINED_PORT</code></td>
</tr>
<tr>
<td>非 Web 组件</td>
<td><code>NONE</code></td>
</tr>
</tbody>
</table>

<h3 id="4-数据库隔离">4. 数据库隔离</h3>
<p>如果多个测试类共享同一个数据库：</p>
<ul>
<li><strong>推荐</strong>：每个测试在 <code>@BeforeEach</code> 中清理数据</li>
<li><strong>可选</strong>：使用 <code>@Transactional</code>（仅 MockMvc 模式下有效）</li>
<li><strong>可选</strong>：每个测试使用独立的 H2 数据库</li>
</ul>

测试之间应该尽量独立，只有在测试完整生命周期时才推荐使用 <code>@Order</code>。</p>
</blockquote>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>@SpringBootTest 概述</strong>：
   - 加载完整的 Spring 上下文
   - 四种 webEnvironment 模式（MOCK、RANDOM_PORT、DEFINED_PORT、NONE）
   - 与切片测试的对比</li>
<li><strong>TestRestTemplate</strong>：
   - 发起真实 HTTP 请求
   - 与 RestTemplate 的区别
   - 测试完整请求链路</li>
<li><strong>测试配置管理</strong>：
   - <code>@TestConfiguration</code> 定义测试专用配置
   - <code>@TestPropertySource</code> 覆盖配置
   - <code>application-test.yml</code> 配置文件</li>
<li><strong>实战应用</strong>：为图书管理系统编写完整的集成测试</li>
<li><strong>分层测试策略</strong>：测试金字塔在 Spring Boot 中的实践</li>
</ol>
