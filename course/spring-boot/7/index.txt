<h2 id="Autowired-的基本用法">@Autowired 的基本用法</h2>
<h3 id="什么是-Autowired">什么是 @Autowired</h3>
<p><code>@Autowired</code> 是 Spring 提供的用于依赖注入的核心注解，它告诉 Spring 容器需要在运行时自动注入匹配的 Bean。它可以用在构造方法、Setter 方法、字段上。</p>
<h2 id="在字段上使用">在字段上使用</h2>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@RestController</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookController</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">;</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="在构造方法上使用">在构造方法上使用</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@RestController</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookController</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="kd">final</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="nf">BookController</span><span class="p">(</span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">bookService</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">bookService</span><span class="p">;</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>

<h2 id="Autowired-的核心特性">@Autowired 的核心特性</h2>
<h3 id="required-属性">required 属性</h3>
<p><code>@Autowired</code> 有一个 <code>required</code> 属性，默认为 <code>true</code>：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 必须注入，如果找不到匹配的 Bean 会抛出异常</span>
<span class="nd">@Autowired</span>
<span class="kd">private</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">;</span>

<span class="c1">// 可选注入，找不到时不报错，字段保持 null</span>
<span class="nd">@Autowired</span><span class="p">(</span><span class="n">required</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="kc">false</span><span class="p">)</span>
<span class="kd">private</span><span class="w"> </span><span class="n">OptionalService</span><span class="w"> </span><span class="n">optionalService</span><span class="p">;</span>
</code></pre></div>

<p><strong>适用场景：</strong></p>
<ul>
<li><code>required = true</code>（默认）：强制依赖，必须存在</li>
<li><code>required = false</code>：可选依赖，不存在也能正常启动</li>
</ul>

<h2 id="多-Bean-场景与注入决策">多 Bean 场景与注入决策</h2>
<h3 id="问题引入">问题引入</h3>
<p>当容器中存在多个相同类型的 Bean 时，<code>@Autowired</code> 如何选择？</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 定义接口</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">interface</span> <span class="nc">BookService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">List</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">getAllBooks</span><span class="p">();</span>
<span class="p">}</span>

<span class="c1">// 实现类1：基础实现</span>
<span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookServiceImpl</span><span class="w"> </span><span class="kd">implements</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Override</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">List</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">getAllBooks</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>
<span class="p">}</span>

<span class="c1">// 实现类2：高级实现（带缓存）</span>
<span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">CachedBookServiceImpl</span><span class="w"> </span><span class="kd">implements</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Override</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">List</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">getAllBooks</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p>此时，如果直接在字段上注入 <code>BookService</code>，Spring 会因无法确定选择哪个 Bean 而抛出异常。</p>
<h3 id="注入决策流程">注入决策流程</h3>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    Start[开始注入] --&gt; Q1{类型匹配&lt;br/&gt;是否存在多个 Bean？}
    Q1 --&gt;|否| Direct[直接注入唯一 Bean]
    Q1 --&gt;|是| Q2{是否存在 @Primary？}
    Q2 --&gt;|是| Primary[注入 @Primary 标记的 Bean]
    Q2 --&gt;|否| Q3{是否存在 @Qualifier 指定？}
    Q3 --&gt;|是| Qualifier[注入 @Qualifier 指定的 Bean]
    Q3 --&gt;|否| Q4{字段名称是否匹配 Bean 名称？}
    Q4 --&gt;|是| ByName[按名称匹配注入]
    Q4 --&gt;|否| Error[抛出 NoUniqueBeanDefinitionException]
</code></pre></div>

<h2 id="使用-Primary-指定首选-Bean">使用 @Primary 指定首选 Bean</h2>
<p><code>@Primary</code> 用于标记一个 Bean 为“首选”，当多个 Bean 匹配时优先注入。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 首选实现</span>
<span class="nd">@Primary</span>
<span class="nd">@Service</span>

<span class="w">    </span><span class="nd">@Override</span>

<h2 id="使用-Qualifier-精确指定-Bean">使用 @Qualifier 精确指定 Bean</h2>
<p>当有多个同类型 Bean 且没有设置 <code>@Primary</code>，或需要注入特定的某个 Bean 时，使用 <code>@Qualifier</code> 按名称精确指定。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>

<span class="w">    </span><span class="c1">// ...</span>
<span class="p">}</span>

<span class="nd">@Service</span><span class="p">(</span><span class="s">"cached"</span><span class="p">)</span><span class="w">  </span><span class="c1">// 指定 Bean 名称</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">CachedBookServiceImpl</span><span class="w"> </span><span class="kd">implements</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// ...</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>方式一：在注入点使用 @Qualifier</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@RestController</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookController</span><span class="w"> </span><span class="p">{</span>

<span class="p">}</span>
</code></pre></div>

<p><strong>方式二：在构造方法参数中使用</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@RestController</span>

<h2 id="Resource-注解">@Resource 注解</h2>
<p><code>@Resource</code> 是 JSR-250 规范提供的注入注解，与 <code>@Autowired</code> 功能类似，但有以下区别：</p>
<table>
<thead>
<tr>
<th>对比</th>
<th>@Autowired</th>
<th>@Resource</th>
</tr>
</thead>
<tbody>
<tr>
<td>来源</td>
<td>Spring 专有</td>
<td>Java 标准（JSR-250）</td>
</tr>
<tr>
<td>匹配方式</td>
<td><strong>先按类型</strong>匹配，再按名称</td>
<td><strong>先按名称</strong>匹配，再按类型</td>
</tr>
<tr>
<td>是否支持 required</td>
<td>✅ 支持 required</td>
<td>❌ 不支持（默认必须存在）</td>
</tr>
<tr>
<td>是否支持 @Primary</td>
<td>✅ 支持</td>
<td>✅ 支持（类型匹配时）</td>
</tr>
<tr>
<td>是否支持集合/数组</td>
<td>✅ 支持</td>
<td>❌ 不支持</td>
</tr>
</tbody>
</table>
<p><strong>@Resource 的使用示例：</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@RestController</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BookController</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 按名称注入（name 属性指定）</span>
<span class="w">    </span><span class="nd">@Resource</span><span class="p">(</span><span class="n">name</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"cachedBookService"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">;</span>

<span class="w">    </span><span class="c1">// 如果不指定 name，默认按字段名匹配</span>
<span class="w">    </span><span class="nd">@Resource</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">cachedBookService</span><span class="p">;</span><span class="w">  </span><span class="c1">// 匹配名为 basicBookService 的 Bean</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]
实际开发中推荐优先使用 <code>@Autowired</code>，因为它是 Spring 原生注解，功能更强大。</p>
</blockquote>

<h3 id="切换策略">切换策略</h3>
<ul>
<li>如果 <code>MemoryBookRepository</code> 加了 <code>@Primary</code>，且没有 <code>@Qualifier</code> 指定，则默认使用内存存储。</li>
<li>如果希望切换到数据库存储，可以通过 <code>@Qualifier("databaseBookRepository")</code> 指定。</li>
</ul>
<h2 id="常见问题与注意事项">常见问题与注意事项</h2>
<h3 id="1-注入失败NoSuchBeanDefinitionException">1. 注入失败：NoSuchBeanDefinitionException</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Autowired</span>
<span class="kd">private</span><span class="w"> </span><span class="n">SomeService</span><span class="w"> </span><span class="n">someService</span><span class="p">;</span><span class="w">  </span><span class="c1">// 如果容器中没有 SomeService 类型的 Bean，会抛出异常</span>
</code></pre></div>

<p><strong>解决方案：</strong></p>
<ul>
<li>确保 Bean 已被 Spring 管理（添加 <code>@Service</code>/<code>@Component</code> 等注解）</li>
<li>检查包扫描路径是否正确</li>
<li>如果可选依赖，设置 <code>required = false</code></li>
</ul>
<h3 id="2-注入失败NoUniqueBeanDefinitionException">2. 注入失败：NoUniqueBeanDefinitionException</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Autowired</span>
<span class="kd">private</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">;</span><span class="w">  </span><span class="c1">// 容器中存在多个 BookService 实现</span>
</code></pre></div>

<p><strong>解决方案：</strong></p>
<ul>
<li>在其中一个实现上添加 <code>@Primary</code></li>
<li>在注入点使用 <code>@Qualifier</code> 指定</li>
</ul>
<h3 id="3-循环依赖问题">3. 循环依赖问题</h3>
<p>构造器注入无法解决循环依赖。下节课做专题分析。</p>
<h3 id="4-Autowired-与-Resource-混用">4. @Autowired 与 @Resource 混用</h3>
<p>在同一类中混用两种注解可能导致混淆，建议统一使用 <code>@Autowired</code>。</p>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>@Autowired 的基本用法</strong>：可作用于字段、构造方法、Setter 方法、任意方法。</li>
<li><strong>注入数组和集合</strong>：自动注入同一类型的所有 Bean。</li>
<li><strong>注入决策流程</strong>：
   - 唯一匹配 → 直接注入
   - 多个匹配 → @Primary → @Qualifier → 按名称匹配 → 抛出异常</li>
<li><strong>@Primary</strong>：标记首选 Bean，降低注入决策歧义。</li>
<li><strong>@Qualifier</strong>：按名称精确指定要注入的 Bean。</li>
<li><strong>@Resource</strong>：JSR-250 标准注解，先按名称匹配后按类型匹配。</li>
<li><strong>实战案例</strong>：在图书管理系统中实现多种存储方式切换。</li>
</ol>
