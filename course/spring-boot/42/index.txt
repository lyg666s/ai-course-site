<h2 id="同步-vs-异步">同步 vs 异步</h2>
<h3 id="什么是同步处理">什么是同步处理</h3>
<p><strong>同步（Synchronous）</strong> 是指任务按顺序执行，当前任务完成后才执行下一个任务。在 Web 应用中，一个请求从进入 Controller 到返回响应，所有操作都在同一个线程中顺序执行。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    Start[请求到达] --&gt; A[操作1]
    A --&gt; B[操作2]
    B --&gt; C[操作3]
    C --&gt; End[返回响应]

    style A fill:#e3f2fd
    style B fill:#e3f2fd
    style C fill:#e3f2fd
</code></pre></div>

<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 同步方式：顺序执行</span>
<span class="kd">public</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="nf">process</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 步骤1：查询数据库（耗时 100ms）</span>
<span class="w">    </span><span class="n">User</span><span class="w"> </span><span class="n">user</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">userRepository</span><span class="p">.</span><span class="na">findById</span><span class="p">(</span><span class="mi">1L</span><span class="p">);</span>
<span class="w">    </span><span class="c1">// 步骤2：发送邮件（耗时 500ms）</span>
<span class="w">    </span><span class="n">emailService</span><span class="p">.</span><span class="na">send</span><span class="p">(</span><span class="n">user</span><span class="p">.</span><span class="na">getEmail</span><span class="p">());</span>
<span class="w">    </span><span class="c1">// 步骤3：记录日志（耗时 50ms）</span>
<span class="w">    </span><span class="n">logService</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="s">"processed"</span><span class="p">);</span>
<span class="w">    </span><span class="k">return</span><span class="w"> </span><span class="s">"done"</span><span class="p">;</span><span class="w">  </span><span class="c1">// 总耗时约 650ms</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>同步的特点：</strong>
- 代码执行顺序清晰，易于理解和调试
- 线程会被阻塞，等待 I/O 或耗时操作完成
- 一个耗时操作会拖慢整个请求</p>
<h3 id="什么是异步处理">什么是异步处理</h3>
<p><strong>异步（Asynchronous）</strong> 是指任务提交后不等待其完成，而是继续执行后续操作。耗时任务在后台执行，执行完成后通过回调、通知等方式获取结果。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    Start[请求到达] --&gt; A[操作1]
    A --&gt; B[提交异步任务]
    B --&gt; C[操作3]
    C --&gt; End[返回响应]

    B -.-&gt;|后台线程| D[操作2（异步）]

    style A fill:#e3f2fd
    style B fill:#fff9c4
    style C fill:#e3f2fd
    style D fill:#e8f5e9
</code></pre></div>

<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 异步方式：耗时操作在后台执行</span>
<span class="kd">public</span><span class="w"> </span><span class="n">String</span><span class="w"> </span><span class="nf">process</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// 步骤1：查询数据库（耗时 100ms）</span>
<span class="w">    </span><span class="n">User</span><span class="w"> </span><span class="n">user</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">userRepository</span><span class="p">.</span><span class="na">findById</span><span class="p">(</span><span class="mi">1L</span><span class="p">);</span>
<span class="w">    </span><span class="c1">// 步骤2：异步发送邮件（不阻塞）</span>
<span class="w">    </span><span class="n">asyncEmailService</span><span class="p">.</span><span class="na">send</span><span class="p">(</span><span class="n">user</span><span class="p">.</span><span class="na">getEmail</span><span class="p">());</span><span class="w">  </span><span class="c1">// 立即返回</span>
<span class="w">    </span><span class="c1">// 步骤3：记录日志（耗时 50ms）</span>
<span class="w">    </span><span class="n">logService</span><span class="p">.</span><span class="na">save</span><span class="p">(</span><span class="s">"processed"</span><span class="p">);</span>
<span class="w">    </span><span class="k">return</span><span class="w"> </span><span class="s">"done"</span><span class="p">;</span><span class="w">  </span><span class="c1">// 总耗时约 150ms</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>异步的特点：</strong>
- 主线程不被阻塞，响应更快
- 耗时任务在独立线程中执行
- 需要处理任务执行结果和异常</p>

<h2 id="Spring-Async-简介">Spring Async 简介</h2>
<h3 id="什么是-Spring-Async">什么是 Spring Async</h3>
<p><strong>Spring Async</strong> 是 Spring 框架提供的异步执行支持，通过 <code>@Async</code> 注解将方法的执行提交到独立的线程池，实现非阻塞的异步调用。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    subgraph 调用方线程
        Client[调用方法] --&gt; Return[立即返回]
    end

    subgraph 异步执行
        Return -.-&gt; Pool[线程池]
        Pool --&gt; Execute[执行异步方法]
        Execute --&gt; Result[返回结果/异常]
    end

    style Client fill:#e3f2fd
    style Pool fill:#fff3e0
</code></pre></div>

<h2 id="Async-方法自调用问题">@Async 方法自调用问题</h2>
<h3 id="什么是自调用问题">什么是自调用问题</h3>
<p>与 <code>@Transactional</code> 类似，<code>@Async</code> 基于代理实现。在同一个类内部直接调用 <code>@Async</code> 方法，会绕过代理，导致方法<strong>同步执行</strong>而非异步执行。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">AsyncLogService</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="nd">@Async</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">asyncMethod</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 这应该异步执行</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">caller</span><span class="p">()</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// ❌ 自调用：绕过代理，asyncMethod 同步执行</span>
<span class="w">        </span><span class="k">this</span><span class="p">.</span><span class="na">asyncMethod</span><span class="p">();</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="解决方案注入自身代理">解决方案：注入自身代理</h3>
<p>在同一个 Bean 中注入自身的代理对象，通过代理调用异步方法：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">AsyncLogService</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="nd">@Lazy</span><span class="w">  </span><span class="c1">// 延迟注入避免循环依赖</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">AsyncLogService</span><span class="w"> </span><span class="n">self</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@Async</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">logAsync</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">msg</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"异步执行: "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">Thread</span><span class="p">.</span><span class="na">currentThread</span><span class="p">().</span><span class="na">getName</span><span class="p">());</span>
<span class="w">    </span><span class="p">}</span>

<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">logWrapper</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">msg</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"调用方线程: "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">Thread</span><span class="p">.</span><span class="na">currentThread</span><span class="p">().</span><span class="na">getName</span><span class="p">());</span>
<span class="w">        </span><span class="c1">// ✅ 通过代理调用，异步执行</span>
<span class="w">        </span><span class="n">self</span><span class="p">.</span><span class="na">logAsync</span><span class="p">(</span><span class="n">msg</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]
<code>@Lazy</code> 用于解决自注入时的循环依赖问题。Spring 在创建 Bean 时，代理对象尚未完全初始化，使用 <code>@Lazy</code> 可以让代理在第一次使用时才真正初始化。</p>
</blockquote>

<h3 id="场景描述">场景描述</h3>
<p>在图书管理系统中，每次操作（新增、更新、删除）都需要记录操作日志。日志记录是非核心业务，不需要立即完成，适合异步处理。</p>
<h3 id="实现">实现</h3>
<p><strong>步骤一：创建异步日志服务</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-Async-方法必须是-public">1. @Async 方法必须是 public</h3>
<p>Spring 代理只能拦截 <code>public</code> 方法，<code>private</code> 或 <code>protected</code> 方法上的 <code>@Async</code> 不会生效。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// ❌ 不生效</span>
<span class="nd">@Async</span>
<span class="kd">private</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">logAsync</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">msg</span><span class="p">)</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>

<span class="c1">// ✅ 生效</span>
<span class="nd">@Async</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">logAsync</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">msg</span><span class="p">)</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>
</code></pre></div>

<h3 id="2-方法返回类型限制">2. 方法返回类型限制</h3>
<ul>
<li>无返回值：<code>void</code></li>
<li>有返回值：<code>Future&lt;T&gt;</code> 或 <code>CompletableFuture&lt;T&gt;</code>（下下节详细介绍）</li>
</ul>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Async</span>
<span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">asyncVoid</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>

<span class="nd">@Async</span>
<span class="kd">public</span><span class="w"> </span><span class="n">Future</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">asyncWithResult</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>
</code></pre></div>

<h3 id="3-默认线程池的局限性">3. 默认线程池的局限性</h3>
<p>Spring 默认使用 <code>SimpleAsyncTaskExecutor</code>，它为每个任务创建一个新线程，不重用线程，高并发下可能导致资源耗尽。<strong>生产环境务必配置自定义线程池</strong>（下一节详细介绍）。</p>
<h3 id="4-异常处理">4. 异常处理</h3>
<ul>
<li>无返回值的异步方法，异常默认不会传播到调用方，需要配置 <code>AsyncUncaughtExceptionHandler</code>（下下节详细介绍）</li>
<li>有返回值的异步方法，异常通过 <code>Future.get()</code> 抛出</li>
</ul>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>同步 vs 异步</strong>：
   - 同步：顺序执行，阻塞线程
   - 异步：提交任务，立即返回，独立线程执行</li>
<li><strong>Spring Async 快速上手</strong>：
   - <code>@EnableAsync</code> 启用异步
   - <code>@Async</code> 标记异步方法
   - 观察线程变化和响应时间差异</li>
<li><strong>自调用问题</strong>：
   - 代理机制导致内部调用失效
   - 注入自身代理解决</li>
<li><strong>实战应用</strong>：在图书管理系统中异步记录操作日志。</li>
</ol>
