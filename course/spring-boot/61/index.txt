<h2 id="测试切片Test-Slice">测试切片（Test Slice）</h2>
<h3 id="什么是测试切片">什么是测试切片</h3>
<p><strong>测试切片</strong>是 Spring Boot 提供的<strong>部分上下文加载</strong>机制。不同的切片注解只加载特定层次的组件，避免加载完整的 Spring 上下文，从而提升测试速度。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    A[完整上下文&lt;br/&gt;@SpringBootTest] --&gt; B[所有组件]
    C[Web 切片&lt;br/&gt;@WebMvcTest] --&gt; D[Controller + MVC 组件]
    E[数据切片&lt;br/&gt;@DataJpaTest] --&gt; F[Repository + JPA 组件]
    G[JSON 切片&lt;br/&gt;@JsonTest] --&gt; H[JSON 序列化组件]

    style C fill:#e3f2fd
    style E fill:#e8f5e9
</code></pre></div>

<h2 id="MockMvc-核心用法">MockMvc 核心用法</h2>
<h3 id="什么是-MockMvc">什么是 MockMvc</h3>
<p><strong>MockMvc</strong> 是 Spring Test 提供的模拟 MVC 请求的工具，可以在<strong>不启动真实 HTTP 服务器</strong>的情况下发送请求并验证响应。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    A[测试代码] --&gt;|perform| B[MockMvc]
    B --&gt;|模拟请求| C[DispatcherServlet]
    C --&gt; D[Controller]
    D --&gt; C
    C --&gt;|响应| B
    B --&gt;|andExpect| A

    style B fill:#e8f5e9
</code></pre></div>

<h3 id="启用-MockMvc">启用 MockMvc</h3>
<p><strong>方式一：使用 @WebMvcTest（推荐）</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@WebMvcTest</span><span class="p">(</span><span class="n">BookController</span><span class="p">.</span><span class="na">class</span><span class="p">)</span>
<span class="kd">class</span> <span class="nc">BookControllerTest</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">MockMvc</span><span class="w"> </span><span class="n">mockMvc</span><span class="p">;</span>
<span class="p">}</span>
</code></pre></div>

<p><code>@WebMvcTest</code> 会自动配置 <code>MockMvc</code>，直接 <code>@Autowired</code> 注入即可。</p>
<p><strong>方式二：手动配置（老式）</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@SpringBootTest</span>
<span class="nd">@AutoConfigureMockMvc</span>
<span class="kd">class</span> <span class="nc">BookControllerTest</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">MockMvc</span><span class="w"> </span><span class="n">mockMvc</span><span class="p">;</span>
<span class="p">}</span>
</code></pre></div>

<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">MockMvc</span><span class="w"> </span><span class="n">mockMvc</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@MockitoBean</span>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-WebMvcTest-不加载哪些组件">1. @WebMvcTest 不加载哪些组件</h3>
<ul>
<li><code>@Service</code>、<code>@Repository</code>、<code>@Component</code></li>
<li><code>@Configuration</code> 类（部分例外）</li>
<li>数据源、JPA、缓存等自动配置</li>
</ul>
<p>如果 Controller 依赖了这些组件，需要使用 <code>@MockitoBean</code> 提供 Mock。</p>
<h3 id="2-使用-WebMvcTestcontrollers-限定范围">2. 使用 @WebMvcTest(controllers = ...) 限定范围</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 只加载 BookController</span>
<span class="nd">@WebMvcTest</span><span class="p">(</span><span class="n">BookController</span><span class="p">.</span><span class="na">class</span><span class="p">)</span>

<span class="c1">// 加载多个 Controller</span>
<span class="nd">@WebMvcTest</span><span class="p">(</span><span class="n">controllers</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="p">{</span><span class="n">BookController</span><span class="p">.</span><span class="na">class</span><span class="p">,</span><span class="w"> </span><span class="n">OrderController</span><span class="p">.</span><span class="na">class</span><span class="p">})</span>

<span class="c1">// 不指定则加载所有 Controller</span>
<span class="nd">@WebMvcTest</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]
推荐显式指定要测试的 Controller，避免加载无关的组件。</p>
</blockquote>
<h3 id="3-MockMvc-的依赖">3. MockMvc 的依赖</h3>
<ul>
<li><code>spring-boot-starter-test</code> 已经包含了 MockMvc 所需的依赖</li>
<li>无需额外添加</li>
</ul>
<h3 id="4-参数校验需要-validation-依赖">4. 参数校验需要 validation 依赖</h3>
<p>如果 Controller 中使用了 <code>@Valid</code>、<code>@Min</code> 等校验注解，需要确保：</p>
<div class="codehilite lang-xml"><pre><span></span><code><span class="nt">&lt;dependency&gt;</span>
<span class="w">    </span><span class="nt">&lt;groupId&gt;</span>org.springframework.boot<span class="nt">&lt;/groupId&gt;</span>
<span class="w">    </span><span class="nt">&lt;artifactId&gt;</span>spring-boot-starter-validation<span class="nt">&lt;/artifactId&gt;</span>
<span class="nt">&lt;/dependency&gt;</span>
</code></pre></div>

<p>Spring Boot 2.3+ 中，<code>spring-boot-starter-web</code> 不再默认包含 validation，需要显式添加。</p>
<h3 id="5-JSON-序列化需要无参构造">5. JSON 序列化需要无参构造</h3>
<p>被测对象（如 <code>Book</code>）需要有<strong>无参构造方法</strong>和 <strong>getter/setter</strong>，否则 Jackson 序列化/反序列化会失败。</p>
<h3 id="6-MockitoBean-的影响范围">6. <code>@MockitoBean</code> 的影响范围</h3>
<p><code>@MockitoBean</code> 会<strong>替换容器中的 Bean</strong>。如果在测试类级别使用，所有测试方法都使用 Mock；如果在方法级别使用，仅当前测试方法使用。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 类级别：所有测试方法使用 Mock</span>
<span class="nd">@MockitoBean</span>
<span class="kd">private</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">;</span>

<span class="c1">// 方法级别：仅当前测试方法使用 Mock</span>
<span class="nd">@Test</span>
<span class="kt">void</span><span class="w"> </span><span class="nf">test</span><span class="p">(</span><span class="nd">@MockitoBean</span><span class="w"> </span><span class="n">BookService</span><span class="w"> </span><span class="n">bookService</span><span class="p">)</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">...</span><span class="w"> </span><span class="p">}</span>
</code></pre></div>

<h3 id="7-测试方法独立性">7. 测试方法独立性</h3>
<p>每个测试方法执行前，Spring 会重置 <code>@MockitoBean</code> 的调用记录，但不重置 <code>when()</code> 预设。因此推荐在 <code>@BeforeEach</code> 中重新配置 Mock。</p>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>测试切片概念</strong>：<code>@WebMvcTest</code> 只加载 Web 层组件</li>
<li><strong>@WebMvcTest 使用</strong>：
   - <code>@Autowired MockMvc</code> 直接注入
   - <code>@MockitoBean</code> 替换 Service 依赖
   - <code>@WebMvcTest(BookController.class)</code> 限定范围</li>
<li><strong>MockMvc 核心 API</strong>：
   - 请求构建：<code>get()</code>、<code>post()</code>、<code>param()</code>、<code>content()</code>
   - 响应断言：<code>status()</code>、<code>jsonPath()</code>、<code>content().json()</code></li>
<li><strong>测试各种场景</strong>：
   - 正常请求、路径参数、查询参数、请求体
   - 参数校验失败、资源不存在、业务异常</li>
<li><strong>实战应用</strong>：为 <code>BookController</code> 编写完整的 Web 层测试</li>
</ol>
