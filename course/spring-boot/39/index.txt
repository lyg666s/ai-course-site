<h2 id="条件缓存condition">条件缓存（condition）</h2>
<h3 id="什么是-condition">什么是 condition</h3>
<p><code>condition</code> 属性用于<strong>在满足特定条件时才执行缓存操作</strong>。它接受一个 SpEL 表达式，只有表达式结果为 <code>true</code> 时，才会进行缓存的查询和存储。</p>
<h3 id="执行时机">执行时机</h3>
<p><code>condition</code> 在<strong>方法执行前</strong>评估，因此：
- 可以访问方法参数（如 <code>#id</code>、<code>#book</code>）
- <strong>不能访问</strong> <code>#result</code>（返回值尚未产生）</p>
<h3 id="基本用法">基本用法</h3>

<h2 id="排除缓存unless">排除缓存（unless）</h2>
<h3 id="什么是-unless">什么是 unless</h3>
<p><code>unless</code> 属性用于<strong>在满足特定条件时排除缓存</strong>，即不缓存结果。与 <code>condition</code> 的区别在于，<code>unless</code> 在<strong>方法执行后</strong>评估，因此可以访问 <code>#result</code>（方法返回值）。</p>
<h3 id="执行时机_1">执行时机</h3>
<table>
<thead>
<tr>
<th>属性</th>
<th>评估时机</th>
<th>可访问 #result</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>condition</code></td>
<td>方法执行前</td>
<td>❌ 不可访问</td>
</tr>
<tr>
<td><code>unless</code></td>
<td>方法执行后</td>
<td>✅ 可访问</td>
</tr>
</tbody>
</table>

<h2 id="sync-属性同步缓存">sync 属性（同步缓存）</h2>
<h3 id="什么是-sync">什么是 sync</h3>
<p><code>sync</code> 属性用于<strong>防止缓存击穿</strong>。当多个线程同时请求一个未缓存的键时，<code>sync = true</code> 会使用锁机制，确保只有一个线程执行方法，其他线程等待结果。</p>
<h3 id="问题场景">问题场景</h3>
<p>场景1：sync = false（默认）</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>sequenceDiagram
    participant T1 as 线程1
    participant T2 as 线程2
    participant T3 as 线程3
    participant Cache as 缓存
    participant DB as 数据库

    Note over T1,T3: sync = false（默认）

    T1-&gt;&gt;Cache: 查询缓存（未命中）
    T2-&gt;&gt;Cache: 查询缓存（未命中）
    T3-&gt;&gt;Cache: 查询缓存（未命中）
    T1-&gt;&gt;DB: 执行查询
    T2-&gt;&gt;DB: 执行查询
    T3-&gt;&gt;DB: 执行查询
    Note over T1,T3: 3 次数据库查询
</code></pre></div>

<p>场景2：sync = true</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>sequenceDiagram
    participant T1 as 线程1
    participant T2 as 线程2
    participant T3 as 线程3
    participant Cache as 缓存
    participant DB as 数据库

    Note over T1,T3: sync = true

    T1-&gt;&gt;Cache: 查询缓存（未命中）
    T1-&gt;&gt;DB: 执行查询
    Note over T1: 持有锁
    T2-&gt;&gt;Cache: 等待锁
    T3-&gt;&gt;Cache: 等待锁
    T1--&gt;&gt;Cache: 存入缓存
    T1--&gt;&gt;T2: 返回结果
    T2-&gt;&gt;Cache: 查询缓存（命中）
    T3-&gt;&gt;Cache: 查询缓存（命中）
    Note over T1,T3: 1 次数据库查询
</code></pre></div>

<h3 id="基本用法_2">基本用法</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 启用同步缓存</span>
<span class="nd">@Cacheable</span><span class="p">(</span><span class="n">value</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"books"</span><span class="p">,</span><span class="w"> </span><span class="n">key</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"#id"</span><span class="p">,</span><span class="w"> </span><span class="n">sync</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="kc">true</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="n">Book</span><span class="w"> </span><span class="nf">getBookById</span><span class="p">(</span><span class="n">Long</span><span class="w"> </span><span class="n">id</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="k">return</span><span class="w"> </span><span class="n">bookRepository</span><span class="p">.</span><span class="na">findById</span><span class="p">(</span><span class="n">id</span><span class="p">);</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="sync-属性详解">sync 属性详解</h3>
<table>
<thead>
<tr>
<th>属性值</th>
<th>行为</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>sync = false</code>（默认）</td>
<td>多个线程同时请求未缓存的键时，各自执行方法体（可能导致缓存击穿）</td>
</tr>
<tr>
<td><code>sync = true</code></td>
<td>多个线程同时请求未缓存的键时，仅一个线程执行方法体，其他线程等待缓存结果</td>
</tr>

<h3 id="sync-与-unless-的冲突">sync 与 unless 的冲突</h3>
<blockquote>
<p>[!CAUTION]
<code>sync = true</code> 与 <code>unless</code> 属性<strong>不能同时使用</strong>，因为 <code>unless</code> 需要 <code>#result</code>（方法返回值），而 <code>sync = true</code> 在方法执行前就已加锁，返回值尚未产生。</p>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-condition-与-unless-的优先级">1. condition 与 unless 的优先级</h3>
<p><code>condition</code> 在方法执行前评估，<code>unless</code> 在方法执行后评估。当两者都配置时：
- <code>condition = true</code>：进入缓存逻辑，方法执行后根据 <code>unless</code> 决定是否缓存
- <code>condition = false</code>：跳过缓存逻辑，方法执行，不缓存（<code>unless</code> 不会被评估）</p>
<h3 id="2-SpEL-表达式的限制">2. SpEL 表达式的限制</h3>
<ul>
<li><code>condition</code> 中不能使用 <code>#result</code></li>
<li><code>unless</code> 中可以使用 <code>#result</code>，但不能使用 <code>#result</code> 修改缓存键</li>
<li>在 <code>@Cacheable</code> 的 <code>key</code> 中，<code>#result</code> 不可用（因为查询缓存时方法尚未执行）</li>
</ul>
<h3 id="3-sync-与-unless-的冲突">3. sync 与 unless 的冲突</h3>
<p><code>sync = true</code> 与 <code>unless</code> 不兼容，如果同时使用会抛出异常。需要用 <code>condition</code> 替代。</p>
<h3 id="4-自定义-KeyGenerator-的线程安全">4. 自定义 KeyGenerator 的线程安全</h3>
<p><code>KeyGenerator</code> 实例是单例的，在多线程环境下共享，必须保证线程安全（无状态设计）。</p>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>条件缓存（condition）</strong>：
   - 在方法执行前评估，控制是否进入缓存逻辑
   - 不能使用 <code>#result</code></li>
<li><strong>排除缓存（unless）</strong>：
   - 在方法执行后评估，控制是否存储结果
   - 可以使用 <code>#result</code></li>
<li><strong>自定义 KeyGenerator</strong>：
   - 实现 KeyGenerator 接口
   - 全局配置或局部使用</li>
<li><strong>同步缓存（sync）</strong>：
   - 防止缓存击穿
   - 与 <code>unless</code> 不兼容</li>
</ol>
