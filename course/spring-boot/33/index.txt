<ul>
<li>理解 MyBatis-Plus 的设计哲学：“只做增强不做改变”</li>
<li>掌握 MyBatis-Plus 与原生 MyBatis 的对比差异</li>

<h2 id="回顾与导入">回顾与导入</h2>
<p>在前面课程中，我们完成了 MyBatis 的基础集成、XML 映射、动态 SQL 和分页等高级特性。但有一个问题始终困扰着开发者：</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    A[每张表] --&gt; B[写 Mapper 接口]
    B --&gt; C[写 XML 映射文件]
    C --&gt; D[写基础 CRUD SQL]
    D --&gt; E[重复劳动]
    E --&gt; F[效率低]
</code></pre></div>

<p><strong>传统 MyBatis 开发的痛点：</strong>
- 每张表都要写一套 CRUD 的 XML 和接口方法
- 单表操作大量重复，但无法复用
- 开发效率受限于重复劳动</p>
<p>MyBatis-Plus 正是为了解决这个问题而生。</p>
<h2 id="MyBatis-Plus-概述">MyBatis-Plus 概述</h2>
<h3 id="什么是-MyBatis-Plus">什么是 MyBatis-Plus</h3>
<p><strong>MyBatis-Plus（简称 MP）</strong> 是 MyBatis 的<strong>增强工具包</strong>，它在 MyBatis 的基础上提供了额外的功能，<strong>而不对 MyBatis 核心框架做任何修改</strong>。</p>
<h3 id="核心设计理念只做增强不做改变">核心设计理念：“只做增强不做改变”</h3>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    subgraph 传统MyBatis
        M1[Mapper 接口]
        M2[XML 映射文件]
        M3[手写 SQL]
    end

    subgraph MyBatis-Plus增强
        MP1[BaseMapper&lt;br/&gt;通用 CRUD]
        MP2[条件构造器&lt;br/&gt;Wrapper]
        MP3[分页插件]
        MP4[代码生成器]
    end

    M1 -.-&gt;|继承| MP1
    M2 -.-&gt;|可选| MP2
    M3 -.-&gt;|替代| MP3
</code></pre></div>

<blockquote>
<p>[!NOTE]
MyBatis-Plus 不会改变 MyBatis 的任何行为。你仍然可以使用 MyBatis 的所有功能，MP 只是在上面“加了东西”。</p>
</blockquote>

<h2 id="BaseMapper-通用-CRUD">BaseMapper 通用 CRUD</h2>

<h2 id="逻辑删除">逻辑删除</h2>
<h3 id="什么是逻辑删除">什么是逻辑删除</h3>
<p>逻辑删除不真正删除数据库记录，而是通过一个标记字段（如 <code>deleted</code>）标记为“已删除”，查询时自动过滤。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    A[deleteById] --&gt; B[UPDATE SET deleted = 1]
    B --&gt; C[查询时 WHERE deleted = 0]

    style A fill:#ffcdd2
    style B fill:#fff3e0
    style C fill:#e8f5e9
</code></pre></div>

<h3 id="配置逻辑删除">配置逻辑删除</h3>
<h4 id="1-数据库添加字段">1. 数据库添加字段</h4>
<div class="codehilite lang-sql"><pre><span></span><code><span class="k">ALTER</span><span class="w"> </span><span class="k">TABLE</span><span class="w"> </span><span class="n">book</span><span class="w"> </span><span class="k">ADD</span><span class="w"> </span><span class="k">COLUMN</span><span class="w"> </span><span class="n">deleted</span><span class="w"> </span><span class="nb">INT</span><span class="w"> </span><span class="k">DEFAULT</span><span class="w"> </span><span class="mi">0</span><span class="p">;</span>
</code></pre></div>

<h4 id="2-实体类添加注解">2. 实体类添加注解</h4>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@TableName</span><span class="p">(</span><span class="s">"book"</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">Book</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="c1">// ... 其他字段</span>

<span class="w">    </span><span class="nd">@TableLogic</span>
<span class="w">    </span><span class="nd">@TableField</span><span class="p">(</span><span class="s">"deleted"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">Integer</span><span class="w"> </span><span class="n">deleted</span><span class="p">;</span>
<span class="p">}</span>
</code></pre></div>

<h4 id="3-全局配置可选">3. 全局配置（可选）</h4>
<p>在 <code>application.yml</code> 中配置全局默认值：</p>
<div class="codehilite lang-yaml"><pre><span></span><code><span class="nt">mybatis-plus</span><span class="p">:</span>
<span class="w">  </span><span class="nt">global-config</span><span class="p">:</span>
<span class="w">    </span><span class="nt">db-config</span><span class="p">:</span>
<span class="w">      </span><span class="nt">logic-delete-field</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">deleted</span><span class="w">      </span><span class="c1"># 全局逻辑删除字段名</span>
<span class="w">      </span><span class="nt">logic-delete-value</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">1</span><span class="w">            </span><span class="c1"># 逻辑已删除值（默认 1）</span>
<span class="w">      </span><span class="nt">logic-not-delete-value</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">0</span><span class="w">        </span><span class="c1"># 逻辑未删除值（默认 0）</span>
</code></pre></div>

<h3 id="使用逻辑删除">使用逻辑删除</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// 执行删除（实际是 UPDATE）</span>
<span class="kt">int</span><span class="w"> </span><span class="n">rows</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">bookMapper</span><span class="p">.</span><span class="na">deleteById</span><span class="p">(</span><span class="mi">1L</span><span class="p">);</span><span class="w">  </span><span class="c1">// SQL: UPDATE book SET deleted = 1 WHERE id = 1</span>

<span class="c1">// 查询（自动过滤已删除）</span>
<span class="n">List</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="n">books</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">bookMapper</span><span class="p">.</span><span class="na">selectList</span><span class="p">(</span><span class="kc">null</span><span class="p">);</span><span class="w">  </span><span class="c1">// SQL: WHERE deleted = 0</span>

<span class="c1">// 查询包含已删除（使用 wrapper 不加 deleted 条件）</span>
<span class="n">LambdaQueryWrapper</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="n">wrapper</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">LambdaQueryWrapper</span><span class="o">&lt;&gt;</span><span class="p">();</span>
<span class="n">wrapper</span><span class="p">.</span><span class="na">eq</span><span class="p">(</span><span class="n">Book</span><span class="p">::</span><span class="n">getDeleted</span><span class="p">,</span><span class="w"> </span><span class="mi">1</span><span class="p">);</span><span class="w">  </span><span class="c1">// 手动查询已删除数据</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<p>逻辑删除后，<code>selectList</code>、<code>selectById</code> 等查询方法会自动追加 <code>WHERE deleted = 0</code> 条件。</p>
</blockquote>

</blockquote>
<h2 id="注意事项">注意事项</h2>
<h3 id="1-实体类必须有无参构造方法">1. 实体类必须有无参构造方法</h3>
<p>MyBatis-Plus 通过反射创建实体实例，必须提供<strong>无参构造方法</strong>。</p>
<h3 id="2-主键策略选择">2. 主键策略选择</h3>
<ul>
<li>PostgreSQL 使用 <code>BIGSERIAL</code> 时，推荐 <code>IdType.AUTO</code></li>
<li>分布式场景推荐 <code>IdType.ASSIGN_ID</code>（雪花算法）</li>
</ul>
<h3 id="3-字段名映射">3. 字段名映射</h3>
<p>默认开启 <code>map-underscore-to-camel-case</code>，数据库下划线字段自动映射为 Java 驼峰属性。如需自定义，使用 <code>@TableField</code> 注解。</p>
<h3 id="4-逻辑删除">4. 逻辑删除</h3>
<p>使用 <code>@TableLogic</code> 标记逻辑删除字段后：
- <code>deleteById</code> 变为逻辑删除（UPDATE deleted = 1）
- <code>selectList</code> 自动过滤已删除数据（WHERE deleted = 0）</p>

<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>MyBatis-Plus 设计哲学</strong>：只做增强不做改变，是 MyBatis 的补充而非替代。</li>
<li><strong>Spring Boot 集成</strong>：替换依赖、配置属性、<code>@MapperScan</code> 扫描。</li>
<li><strong>实体类注解</strong>：
   - <code>@TableName</code>：指定表名
   - <code>@TableId</code>：主键及策略
   - <code>@TableField</code>：字段映射
   - <code>@TableLogic</code>：逻辑删除</li>
<li><strong>BaseMapper</strong>：继承即获得完整 CRUD，无需编写 XML。</li>
<li><strong>混合使用</strong>：MP 的 BaseMapper 与原生 MyBatis 的 XML/注解可共存。</li>
</ol>
