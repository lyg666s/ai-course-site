<h2 id="批处理概述">批处理概述</h2>
<h3 id="什么是批处理">什么是批处理</h3>
<p><strong>批处理（Batch Processing）</strong> 是指在无需人工干预的情况下，自动执行一系列数据处理任务的过程。批处理通常处理<strong>大量数据</strong>，可以一次性完成、定时执行或按需触发。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    A[数据源] --&gt; B[批处理任务]
    B --&gt; C[数据处理]
    C --&gt; D[结果输出]

    style B fill:#e3f2fd
</code></pre></div>

<h3 id="Chunk-模型">Chunk 模型</h3>
<p><strong>Chunk 模型</strong> 是 Spring Batch 最常用的处理模型，它将数据分成多个小块（chunk）进行处理。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    A[读取 10 条] --&gt; B[处理 10 条]
    B --&gt; C[写入 10 条]
    C --&gt; D[提交事务]
    D --&gt; E{还有数据？}
    E --&gt;|是| A
    E --&gt;|否| F[完成]

    style A fill:#e8f5e9
    style B fill:#fff3e0
    style C fill:#e3f2fd
    style D fill:#f3e5f5
</code></pre></div>

<p><strong>工作流程：</strong>
1. ItemReader 读取一条数据，放入 chunk
2. ItemProcessor 处理该数据，放回 chunk
3. 重复上述过程，直到 chunk 达到配置的大小（如 10 条）
4. ItemWriter 一次性写入这 10 条数据
5. 提交事务
6. 继续下一个 chunk</p>
<p><strong>Chunk 大小的选择：</strong></p>
<table>
<thead>
<tr>
<th>Chunk 大小</th>
<th>优点</th>
<th>缺点</th>
</tr>
</thead>
<tbody>
<tr>
<td>小（如 10）</td>
<td>内存占用少，事务提交频繁</td>
<td>提交次数多，性能略低</td>
</tr>
<tr>
<td>大（如 1000）</td>
<td>提交次数少，性能高</td>
<td>内存占用大，失败时回滚数据多</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]
通常建议 Chunk 大小在 100-1000 之间，具体根据数据大小和内存情况调整。</p>
</blockquote>

<h2 id="运行批处理任务">运行批处理任务</h2>
<h3 id="方式一应用启动时自动运行">方式一：应用启动时自动运行</h3>
<p>在 <code>application.yml</code> 中设置：</p>
<div class="codehilite lang-yaml"><pre><span></span><code><span class="nt">spring</span><span class="p">:</span>
<span class="w">  </span><span class="nt">batch</span><span class="p">:</span>
<span class="w">    </span><span class="nt">job</span><span class="p">:</span>
<span class="w">      </span><span class="nt">enabled</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">true</span><span class="w">   </span><span class="c1"># 应用启动时自动运行所有 Job</span>
<span class="w">      </span><span class="nt">names</span><span class="p">:</span><span class="w"> </span><span class="l l-Scalar l-Scalar-Plain">importBookJob</span><span class="w">  </span><span class="c1"># 指定要运行的 Job 名称</span>
</code></pre></div>

<p>启动应用，控制台会输出：</p>
<div class="codehilite"><pre><span></span><code>处理图书: Spring Boot 实战
处理图书: Java 核心技术
写入 2 条图书数据
处理图书: 深入理解 Java 虚拟机
处理图书: Effective Java
写入 2 条图书数据
处理图书: Spring 源码深度解析
写入 1 条图书数据
</code></pre></div>

<h3 id="方式二通过-JobLauncher-手动触发">方式二：通过 JobLauncher 手动触发</h3>
<p>创建 Controller 手动触发 Job：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@RestController</span>
<span class="nd">@RequestMapping</span><span class="p">(</span><span class="s">"/api/batch"</span><span class="p">)</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">BatchController</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">JobLauncher</span><span class="w"> </span><span class="n">jobLauncher</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@Autowired</span>
<span class="w">    </span><span class="nd">@Qualifier</span><span class="p">(</span><span class="s">"importBookJob"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">private</span><span class="w"> </span><span class="n">Job</span><span class="w"> </span><span class="n">importBookJob</span><span class="p">;</span>

<span class="w">    </span><span class="nd">@PostMapping</span><span class="p">(</span><span class="s">"/import-books"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="n">Result</span><span class="o">&lt;</span><span class="n">String</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">importBooks</span><span class="p">()</span><span class="w"> </span><span class="kd">throws</span><span class="w"> </span><span class="n">Exception</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 使用时间戳作为参数，避免重复执行被拒绝</span>
<span class="w">        </span><span class="n">JobParameters</span><span class="w"> </span><span class="n">params</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">JobParametersBuilder</span><span class="p">()</span>
<span class="w">                </span><span class="p">.</span><span class="na">addLong</span><span class="p">(</span><span class="s">"timestamp"</span><span class="p">,</span><span class="w"> </span><span class="n">System</span><span class="p">.</span><span class="na">currentTimeMillis</span><span class="p">())</span>
<span class="w">                </span><span class="p">.</span><span class="na">toJobParameters</span><span class="p">();</span>

<span class="w">        </span><span class="n">jobLauncher</span><span class="p">.</span><span class="na">run</span><span class="p">(</span><span class="n">importBookJob</span><span class="p">,</span><span class="w"> </span><span class="n">params</span><span class="p">);</span>

<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

</blockquote>

</tr>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-元数据表的初始化">1. 元数据表的初始化</h3>
<ul>
<li>开发环境可使用 <code>initialize-schema: always</code> 自动创建</li>
<li>生产环境建议使用 <code>never</code>，通过 SQL 脚本手动初始化</li>
</ul>
<h3 id="2-Job-参数唯一性">2. Job 参数唯一性</h3>
<ul>
<li>相同的 Job 参数不能重复执行同一个 Job</li>
<li>如果需要重复执行，加入时间戳参数</li>
</ul>
<h3 id="3-Chunk-大小的选择">3. Chunk 大小的选择</h3>
<ul>
<li>Chunk 太小：事务提交频繁，性能低</li>
<li>Chunk 太大：内存占用高，失败时回滚数据多</li>
<li>建议：100-1000，根据实际情况调整</li>
</ul>
<h3 id="4-Job-自动执行配置">4. Job 自动执行配置</h3>
<ul>
<li><code>spring.batch.job.enabled: false</code>：应用启动时不自动执行 Job</li>
<li>通过 <code>JobLauncher</code> 手动触发，灵活性更高</li>
</ul>
<h3 id="5-事务管理">5. 事务管理</h3>
<ul>
<li>Step 中的事务由 <code>PlatformTransactionManager</code> 管理</li>
<li>每个 Chunk 作为一个事务单元，全部成功才提交</li>
</ul>

<p>本节课我们学习了：</p>
<ol>
<li><strong>批处理概述</strong>：批处理的应用场景和 Spring Batch 的优势</li>
<li><strong>Spring Batch 核心概念</strong>：
   - Job、Step、ItemReader、ItemProcessor、ItemWriter
   - Chunk 模型</li>
<li><strong>Spring Boot 集成</strong>：依赖配置、数据源配置、元数据表初始化</li>
<li><strong>第一个批处理任务</strong>：批量导入图书数据</li>

<li><strong>执行记录</strong>：通过元数据表查看作业状态</li>
</ol>
