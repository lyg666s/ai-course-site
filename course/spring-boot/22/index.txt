<h2 id="批量操作">批量操作</h2>
<h3 id="什么是批量操作">什么是批量操作</h3>
<p>批量操作是指在一次数据库交互中执行多条 SQL 语句，可以显著减少网络开销，提升性能。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    subgraph 单条插入
        A1[insert 1] --&gt; A2[insert 2] --&gt; A3[insert 3]
    end

    subgraph 批量插入
        B1[insert 1,2,3&lt;br/&gt;一次性提交]
    end

    A1 --&gt;|3次网络往返| DB
    B1 --&gt;|1次网络往返| DB
</code></pre></div>

<p>在真实系统中，数据量可能很大（数千、数万甚至百万条）。一次性查询全部数据会导致：</p>
<ul>
<li>内存压力大</li>
<li>网络传输慢</li>
<li>前端渲染卡顿</li>
</ul>
<p>分页查询将结果分成若干页，每页只返回一小部分数据。</p>

<h2 id="SimpleJdbcInsert-使用">SimpleJdbcInsert 使用</h2>
<h3 id="什么是-SimpleJdbcInsert">什么是 SimpleJdbcInsert</h3>
<p><code>SimpleJdbcInsert</code> 是 Spring JDBC 提供的专门用于简化插入操作的类。它基于数据库元数据自动生成 INSERT 语句，无需手动编写 SQL。</p>
<p><strong>优势：</strong></p>
<ul>
<li>无需手动编写 INSERT SQL</li>
<li>自动从数据库元数据获取列名</li>
<li>支持获取自动生成的主键</li>
<li>支持批量插入</li>
</ul>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-批量操作的大小限制">1. 批量操作的大小限制</h3>
<ul>
<li>批量操作每次提交的数据量不宜过大（建议 500-1000 条），否则可能占用大量内存。</li>
<li>使用 <code>batchUpdate</code> 的 <code>batchSize</code> 参数控制每批大小。</li>
</ul>
<h3 id="2-分页查询的排序注入">2. 分页查询的排序注入</h3>
<ul>
<li>排序字段名应使用白名单验证，避免 SQL 注入。</li>
<li>排序方向同样需要验证。</li>
</ul>
<h3 id="3-SimpleJdbcInsert-的列名">3. SimpleJdbcInsert 的列名</h3>
<ul>
<li><code>usingColumns</code> 指定的列必须存在于表中，且顺序不重要。</li>
<li>未指定的列将使用数据库默认值或 <code>NULL</code>。</li>
</ul>
<h3 id="4-获取主键的差异">4. 获取主键的差异</h3>
<ul>
<li>不同数据库获取主键的方式不同（MySQL 的 <code>GENERATED_KEY</code>、Oracle 的 <code>RETURNING</code>）。<code>SimpleJdbcInsert</code> 会适配不同数据库。</li>
<li>如果表使用复合主键，需使用 <code>executeAndReturnKeyHolder</code> 方法。</li>
</ul>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>批量操作</strong>：
   - <code>batchUpdate</code> 执行批量插入、更新、删除
   - 分批处理大数据量，控制内存使用</li>
<li><strong>分页查询与排序</strong>：
   - 使用 <code>LIMIT OFFSET</code> 实现分页
   - 封装 <code>PageResult</code> 统一分页结果
   - 动态构建条件查询</li>
<li><strong>SimpleJdbcInsert</strong>：
   - 基于元数据自动生成 INSERT SQL
   - 支持单条插入和批量插入
   - 支持 <code>BeanPropertySqlParameterSource</code> 简化参数构建</li>
<li><strong>实战应用</strong>：
   - 在图书管理系统中集成批量导入
   - 添加分页查询接口</li>
</ol>
