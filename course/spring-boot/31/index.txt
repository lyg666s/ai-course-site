<h2 id="回顾与导入">回顾与导入</h2>
<p>在上一讲中，我们完成了 MyBatis 与 Spring Boot 的集成，并编写了基础的 CRUD 映射。但在实际业务中，查询条件往往是动态组合的，而且表与表之间存在着关联关系。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    A[用户请求] --&gt; B{查询条件}
    B --&gt;|有作者| C[AND author LIKE ?]
    B --&gt;|有分类| D[AND category = ?]
    B --&gt;|有价格范围| E[AND price BETWEEN ? AND ?]
    C --&gt; F[动态拼接 WHERE]
    D --&gt; F
    E --&gt; F
    F --&gt; G[执行 SQL]
</code></pre></div>

<p>本节课将深入学习 MyBatis 映射文件的高级特性，重点掌握动态 SQL 和关联映射，并完整实现图书订单管理功能。</p>

<span class="w">            </span>AND<span class="w"> </span>category<span class="w"> </span>=<span class="w"> </span>#{category}

<h3 id="参数传递-vs">参数传递：<code>#{}</code> vs <code>${}</code></h3>
<table>
<thead>
<tr>
<th>方式</th>
<th>说明</th>
<th>示例</th>
<th>安全性</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>#{}</code></td>
<td>预编译占位符，生成 <code>?</code>，防止 SQL 注入</td>
<td><code>WHERE id = #{id}</code> → <code>WHERE id = ?</code></td>
<td>✅ 安全</td>
</tr>
<tr>
<td><code>${}</code></td>
<td>字符串直接拼接，存在注入风险</td>
<td><code>ORDER BY ${column}</code> → <code>ORDER BY id</code></td>
<td>❌ 不安全</td>
</tr>
</tbody>
</table>
<p><strong>使用建议：</strong></p>
<ul>
<li>
<p>优先使用 <code>#{}</code> 传递参数值</p>
</li>
<li>
<p><code>${}</code> 仅用于表名、列名、排序方向等<strong>无法预编译</strong>的场景，且必须进行<strong>白名单校验</strong></p>
</li>
</ul>

<h2 id="注意事项">注意事项</h2>
<ol>
<li>
<p><strong>动态 SQL 的性能</strong>：复杂动态 SQL 建议通过单元测试验证生成的 SQL 是否符合预期。</p>
</li>
<li>
<p><strong>N+1 问题</strong>：使用 <code>collection</code> 的 <code>select</code> 属性会触发 N+1，推荐使用 JOIN（<code>resultMap</code> 嵌套）一次性加载。</p>
</li>
<li>
<p><strong>列值覆盖问题</strong>：Book、Order和OrderItem三个表都有同名的 id、created_at、updated_at 等字段，在结果集中后出现的列值会覆盖前面的，导致 MyBatis 无法正确识别订单项和图书的主键，从而将多个订单项错误地合并为一个（或只取最后一条）</p>
</li>
<li>
<p><strong><code>#{}</code> vs <code>${}</code></strong>：</p>
</li>
</ol>
<ul>
<li><code>#{}</code>：预编译占位符，防止 SQL 注入（推荐）</li>
<li><code>${}</code>：字符串直接拼接，存在 SQL 注入风险，仅用于表名、列名等动态部分</li>
</ul>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>映射文件核心元素</strong>：<code>select</code>、<code>insert</code>、<code>update</code>、<code>delete</code> 的用法。</li>
<li><strong>参数传递</strong>：<code>#{}</code>（安全） vs <code>${}</code>（拼接）。</li>
<li><strong>结果集映射（resultMap）</strong>：基础映射、<code>association</code>（一对一）、<code>collection</code>（一对多）。</li>
<li><strong>动态 SQL</strong>：<code>&lt;if&gt;</code>、<code>&lt;where&gt;</code>、<code>&lt;set&gt;</code>、<code>&lt;foreach&gt;</code>、<code>&lt;choose&gt;</code>。</li>
<li><strong>完整实战</strong>：Book、Order、OrderItem 的完整 Mapper、Service、Controller 实现。</li>
</ol>
