<h2 id="条件构造器体系">条件构造器体系</h2>
<h3 id="回顾和导入">回顾和导入</h3>
<p>在上一讲中，我们使用 <code>BaseMapper</code> 实现了零 SQL 的通用 CRUD。但实际业务中，查询条件往往是动态组合的：</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    A[用户请求] --&gt; B{查询条件}
    B --&gt;|作者| C[author LIKE ?]
    B --&gt;|分类| D[category = ?]
    B --&gt;|价格| E[price BETWEEN ? AND ?]
    C --&gt; F[动态组合 WHERE]
    D --&gt; F
    E --&gt; F
    F --&gt; G[执行查询]
</code></pre></div>

<p>MyBatis-Plus 提供了<strong>条件构造器（Wrapper）</strong> 来优雅地处理动态查询，无需手写 SQL 或 XML。</p>
<h3 id="整体架构">整体架构</h3>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    Wrapper[Wrapper 抽象类] --&gt; AbstractWrapper[AbstractWrapper]
    AbstractWrapper --&gt; QueryWrapper[QueryWrapper]
    AbstractWrapper --&gt; UpdateWrapper[UpdateWrapper]
    AbstractWrapper --&gt; LambdaQueryWrapper[LambdaQueryWrapper]
    AbstractWrapper --&gt; LambdaUpdateWrapper[LambdaUpdateWrapper]
</code></pre></div>

<table>

<th>类</th>
<th>说明</th>
</tr>
</thead>

<td>普通查询条件构造器，字段名用字符串</td>
</tr>

<td>类型安全的查询条件构造器（推荐）</td>

<td>普通更新条件构造器</td>

<h2 id="LambdaQueryWrapper推荐">LambdaQueryWrapper（推荐）</h2>

<h2 id="UpdateWrapper-条件更新">UpdateWrapper 条件更新</h2>
<h3 id="基本用法_1">基本用法</h3>
<p><code>UpdateWrapper</code> 用于批量更新，无需先查询再更新。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="nf">updatePriceByCategory</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">category</span><span class="p">,</span><span class="w"> </span><span class="n">Double</span><span class="w"> </span><span class="n">multiplier</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">LambdaUpdateWrapper</span><span class="o">&lt;</span><span class="n">Book</span><span class="o">&gt;</span><span class="w"> </span><span class="n">wrapper</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">LambdaUpdateWrapper</span><span class="o">&lt;&gt;</span><span class="p">();</span>

<span class="w">    </span><span class="c1">// 更新条件</span>
<span class="w">    </span><span class="n">wrapper</span><span class="p">.</span><span class="na">eq</span><span class="p">(</span><span class="n">Book</span><span class="p">::</span><span class="n">getCategory</span><span class="p">,</span><span class="w"> </span><span class="n">category</span><span class="p">);</span>

<span class="w">    </span><span class="c1">// 设置更新字段</span>
<span class="w">    </span><span class="n">wrapper</span><span class="p">.</span><span class="na">set</span><span class="p">(</span><span class="n">Book</span><span class="p">::</span><span class="n">getPrice</span><span class="p">,</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">Column</span><span class="p">(</span><span class="s">"price * "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">multiplier</span><span class="p">));</span>
<span class="w">    </span><span class="c1">// 或直接设置固定值</span>
<span class="w">    </span><span class="c1">// wrapper.set(Book::getCategory, "新技术");</span>

<span class="w">    </span><span class="k">return</span><span class="w"> </span><span class="n">bookMapper</span><span class="p">.</span><span class="na">update</span><span class="p">(</span><span class="kc">null</span><span class="p">,</span><span class="w"> </span><span class="n">wrapper</span><span class="p">);</span>
<span class="p">}</span>

</blockquote>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-分页插件需配置数据库类型">1. 分页插件需配置数据库类型</h3>
<p>在 <code>PaginationInnerInterceptor</code> 中指定 <code>DbType.POSTGRE_SQL</code>，否则生成的 SQL 语法可能不正确。</p>
<h3 id="2-Lambda-表达式与序列化">2. Lambda 表达式与序列化</h3>
<p><code>LambdaQueryWrapper</code> 依赖实体类的 <code>Serializable</code> 支持，但通常无需额外实现。</p>
<h3 id="3-条件构造器的-and-与-or">3. 条件构造器的 <code>and</code> 与 <code>or</code></h3>
<ul>
<li>多个条件默认用 <code>AND</code> 连接。</li>
<li>使用 <code>or()</code> 切换逻辑关系。</li>
<li>使用 <code>and(w -&gt; w.条件1.or().条件2)</code> 构建复杂括号。</li>
</ul>
<h3 id="4-分页与性能">4. 分页与性能</h3>
<ul>
<li><code>Page</code> 对象会自动生成 <code>COUNT</code> 查询，对于大表可能影响性能。</li>
<li>可通过 <code>Page</code> 的 <code>optimizeCountSql</code> 或 <code>isSearchCount</code> 控制是否生成 COUNT。</li>
</ul>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>条件构造器体系</strong>：
   - <code>QueryWrapper</code>（字符串字段名）
   - <code>LambdaQueryWrapper</code>（Lambda 表达式，推荐）
   - <code>UpdateWrapper</code> 和 <code>LambdaUpdateWrapper</code>（条件更新）</li>
<li><strong>常用方法</strong>：<code>eq</code>、<code>like</code>、<code>ge</code>、<code>le</code>、<code>in</code>、<code>between</code>、<code>orderBy</code> 等。</li>
<li><strong>分页插件</strong>：
   - 配置 <code>PaginationInnerInterceptor</code>
   - 使用 <code>Page</code> 对象进行分页查询</li>
<li><strong>实战应用</strong>：图书管理系统中使用 Wrapper 实现动态查询、分页和条件更新。</li>
</ol>
