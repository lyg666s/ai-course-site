<h2 id="从传统-JDBC-到-Spring-JDBC">从传统 JDBC 到 Spring JDBC</h2>
<h3 id="回顾传统-JDBC-的痛点">回顾传统 JDBC 的痛点</h3>
<p>上一节课我们通过实际代码体验了传统 JDBC 开发，总结出以下痛点：</p>
<table>
<thead>
<tr>
<th>痛点</th>
<th>表现</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>重复代码</strong></td>
<td>每次操作都要获取连接、创建 Statement、处理异常、关闭资源</td>
</tr>
<tr>
<td><strong>资源管理</strong></td>
<td>容易忘记关闭连接导致资源泄漏</td>
</tr>
<tr>
<td><strong>异常处理</strong></td>
<td>SQLException 是受检异常，代码冗长</td>
</tr>
<tr>
<td><strong>结果映射</strong></td>
<td>手动将 ResultSet 转换为 Java 对象，繁琐且易错</td>
</tr>
<tr>
<td><strong>耦合度高</strong></td>
<td>SQL 散落在业务代码中，难以维护</td>
</tr>
</tbody>
</table>
<h3 id="Spring-JDBC-的设计目标">Spring JDBC 的设计目标</h3>
<p>Spring JDBC（<code>spring-jdbc</code> 模块）是 Spring 框架对 JDBC 的封装，旨在<strong>简化 JDBC 操作</strong>，让开发者专注于 SQL 和结果处理，而非底层资源管理。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    subgraph 传统JDBC
        App1[应用程序] --&gt; JDBC1[JDBC API]
        JDBC1 --&gt; |手动管理| Resource[连接/Statement/ResultSet]
        JDBC1 --&gt; |受检异常| Exception[SQLException]
        JDBC1 --&gt; |手动映射| Mapping[ResultSet → 对象]
    end

    subgraph SpringJDBC
        App2[应用程序] --&gt; Template[JdbcTemplate]
        Template --&gt; |自动管理| Resource2[资源管理]
        Template --&gt; |非受检异常| Exception2[DataAccessException]
        Template --&gt; |模板方法| Mapping2[RowMapper/ResultSetExtractor]
        Template --&gt; JDBC2[JDBC API]
    end
</code></pre></div>

<h3 id="Spring-JDBC-的核心组件">Spring JDBC 的核心组件</h3>
<table>
<thead>
<tr>
<th>组件</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>JdbcTemplate</strong></td>
<td>核心类，封装了所有 JDBC 操作，提供模板方法</td>
</tr>
<tr>
<td><strong>DataSource</strong></td>
<td>数据源，管理数据库连接池</td>
</tr>
<tr>
<td><strong>RowMapper</strong></td>
<td>将 ResultSet 的一行映射为 Java 对象</td>
</tr>
<tr>
<td><strong>ResultSetExtractor</strong></td>
<td>将整个 ResultSet 映射为任意结果</td>
</tr>
<tr>
<td><strong>SimpleJdbcInsert</strong></td>
<td>简化 INSERT 操作（下一课介绍）</td>
</tr>
<tr>
<td><strong>SimpleJdbcCall</strong></td>
<td>简化存储过程调用（很少使用）</td>
</tr>
</tbody>
</table>

<h2 id="JdbcTemplate-与-RowMapper-的工作流程">JdbcTemplate 与 RowMapper 的工作流程</h2>
<h3 id="JdbcTemplate-核心流程">JdbcTemplate 核心流程</h3>
<p><code>JdbcTemplate</code> 封装了 JDBC 的重复流程：</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    App[应用程序调用 JdbcTemplate] --&gt; GetConn[获取数据库连接]
    GetConn --&gt; PrepStmt[创建 PreparedStatement]
    PrepStmt --&gt; SetParams[设置参数]
    SetParams --&gt; Exec[执行 SQL]
    Exec --&gt; Process[处理结果]
    Process --&gt;|查询| Map[RowMapper 映射]
    Process --&gt;|更新| UpdateCount[返回影响行数]
    Map --&gt; Close[自动关闭资源]
    UpdateCount --&gt; Close
    Close --&gt; Return[返回结果]
</code></pre></div>

<h3 id="RowMapper-回调机制">RowMapper 回调机制</h3>
<p><code>RowMapper</code> 是典型的<strong>回调模式</strong>：<code>JdbcTemplate</code> 负责遍历 <code>ResultSet</code>，每行调用 <code>RowMapper.mapRow()</code> 方法进行转换。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// JdbcTemplate 内部简化逻辑</span>
<span class="kd">public</span><span class="w"> </span><span class="o">&lt;</span><span class="n">T</span><span class="o">&gt;</span><span class="w"> </span><span class="n">List</span><span class="o">&lt;</span><span class="n">T</span><span class="o">&gt;</span><span class="w"> </span><span class="nf">query</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">sql</span><span class="p">,</span><span class="w"> </span><span class="n">RowMapper</span><span class="o">&lt;</span><span class="n">T</span><span class="o">&gt;</span><span class="w"> </span><span class="n">rowMapper</span><span class="p">,</span><span class="w"> </span><span class="n">Object</span><span class="p">...</span><span class="w"> </span><span class="n">args</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">    </span><span class="n">Connection</span><span class="w"> </span><span class="n">conn</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">getConnection</span><span class="p">();</span>
<span class="w">    </span><span class="n">PreparedStatement</span><span class="w"> </span><span class="n">ps</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">conn</span><span class="p">.</span><span class="na">prepareStatement</span><span class="p">(</span><span class="n">sql</span><span class="p">);</span>
<span class="w">    </span><span class="n">ResultSet</span><span class="w"> </span><span class="n">rs</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">ps</span><span class="p">.</span><span class="na">executeQuery</span><span class="p">();</span>
<span class="w">    </span><span class="n">List</span><span class="o">&lt;</span><span class="n">T</span><span class="o">&gt;</span><span class="w"> </span><span class="n">results</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">ArrayList</span><span class="o">&lt;&gt;</span><span class="p">();</span>
<span class="w">    </span><span class="kt">int</span><span class="w"> </span><span class="n">rowNum</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="mi">0</span><span class="p">;</span>
<span class="w">    </span><span class="k">while</span><span class="w"> </span><span class="p">(</span><span class="n">rs</span><span class="p">.</span><span class="na">next</span><span class="p">())</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 回调 RowMapper 的 mapRow 方法</span>
<span class="w">        </span><span class="n">T</span><span class="w"> </span><span class="n">item</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="n">rowMapper</span><span class="p">.</span><span class="na">mapRow</span><span class="p">(</span><span class="n">rs</span><span class="p">,</span><span class="w"> </span><span class="n">rowNum</span><span class="o">++</span><span class="p">);</span>
<span class="w">        </span><span class="n">results</span><span class="p">.</span><span class="na">add</span><span class="p">(</span><span class="n">item</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="w">    </span><span class="c1">// 自动关闭资源</span>
<span class="w">    </span><span class="n">close</span><span class="p">(</span><span class="n">rs</span><span class="p">,</span><span class="w"> </span><span class="n">ps</span><span class="p">,</span><span class="w"> </span><span class="n">conn</span><span class="p">);</span>
<span class="w">    </span><span class="k">return</span><span class="w"> </span><span class="n">results</span><span class="p">;</span>
<span class="p">}</span>
</code></pre></div>

<blockquote>
<p>[!NOTE]</p>
<p>回调模式让开发者只需关注“如何将一行数据转换为对象”，而无需关心连接管理、异常处理等样板代码。</p>
</blockquote>
<h2 id="注意事项">注意事项</h2>
<h3 id="1-查询结果的空值处理">1. 查询结果的空值处理</h3>
<ul>
<li><code>queryForObject</code> 无结果时抛出 <code>EmptyResultDataAccessException</code>，需捕获处理。</li>
<li><code>query</code> 无结果时返回空列表，不会抛出异常。</li>
<li><code>queryForList</code> 无结果时返回空列表。</li>
</ul>
<h3 id="2-SQL-注入防护">2. SQL 注入防护</h3>
<p>始终使用<strong>参数化查询</strong>（<code>?</code> 占位符），避免字符串拼接 SQL：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// ❌ 错误：字符串拼接，存在 SQL 注入风险</span>
<span class="n">String</span><span class="w"> </span><span class="n">sql</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"SELECT * FROM book WHERE title = '"</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">title</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="s">"'"</span><span class="p">;</span>

<span class="c1">// ✅ 正确：使用参数化查询</span>
<span class="n">String</span><span class="w"> </span><span class="n">sql</span><span class="w"> </span><span class="o">=</span><span class="w"> </span><span class="s">"SELECT * FROM book WHERE title = ?"</span><span class="p">;</span>
</code></pre></div>

<h3 id="3-获取主键">3. 获取主键</h3>
<ul>
<li><code>KeyHolder</code> 适用于支持自动生成主键的数据库（MySQL、H2、PostgreSQL 等）。</li>
<li>不支持自动生成主键的数据库需使用 <code>Sequence</code> 或 <code>UUID</code> 等方式。</li>
</ul>
<h3 id="4-JdbcTemplate-线程安全">4. JdbcTemplate 线程安全</h3>
<p><code>JdbcTemplate</code> 是<strong>线程安全</strong>的，可以在多个 Repository 中共享同一个实例。Spring Boot 自动配置的 <code>JdbcTemplate</code> 是单例，可直接注入使用。</p>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>Spring JDBC 整体架构</strong>：<code>JdbcTemplate</code> + <code>DataSource</code> + <code>RowMapper</code>。</li>
<li><strong>数据源配置</strong>：在 <code>application.yml</code> 中配置数据源，Spring Boot 自动创建 <code>DataSource</code>。</li>
<li><strong>JdbcTemplate 基础 CRUD</strong>：
   - 查询：<code>queryForObject</code>、<code>query</code>、<code>queryForObject</code>（单值）
   - 插入：使用 <code>KeyHolder</code> 获取自动生成的主键
   - 更新/删除：<code>update</code> 方法</li>
<li><strong>RowMapper</strong>：将 <code>ResultSet</code> 的一行映射为 Java 对象。</li>
<li><strong>实战迁移</strong>：将图书管理系统的 <code>BookRepository</code> 从内存存储迁移到 JdbcTemplate。</li>
</ol>
