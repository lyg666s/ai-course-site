<h2 id="初始化Spring-Data-JPA开发环境">初始化Spring Data JPA开发环境</h2>
<p>在前一节课中，我们了解了 ORM 的核心概念和 Spring Data 的整体架构。Spring Data JPA 是 Spring Data 家族中最重要的成员之一，它基于 JPA 规范提供了强大的数据访问能力。</p>
<p><strong>使用 Spring Data JPA 的核心步骤：</strong></p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart LR
    A[添加依赖] --&gt; B[配置数据源]
    B --&gt; C[定义 Entity]
    C --&gt; D[定义 Repository]
    D --&gt; E[注入使用]

    style A fill:#e3f2fd
    style B fill:#e8f5e9
    style C fill:#fff3e0
    style D fill:#f3e5f5
    style E fill:#c8e6c9
</code></pre></div>

<p>本节课我们将通过图书管理系统，一步步实现从 Spring JDBC 到 Spring Data JPA 的迁移，并使用 PostgreSQL 作为生产级数据库。</p>
<h3 id="添加-Spring-Data-JPA-和-PostgreSQL-依赖">添加 Spring Data JPA 和 PostgreSQL 依赖</h3>
<p>在 <code>pom.xml</code> 中添加以下依赖：</p>
<div class="codehilite lang-xml"><pre><span></span><code><span class="cm">&lt;!-- Spring Data JPA --&gt;</span>

<span class="nt">&lt;dependency&gt;</span>

<span class="w">    </span><span class="nt">&lt;scope&gt;</span>runtime<span class="nt">&lt;/scope&gt;</span>

<h2 id="Spring-Data-JPA-vs-JdbcTemplate-对比">Spring Data JPA vs JdbcTemplate 对比</h2>
<table>
<thead>
<tr>
<th>操作</th>
<th>JdbcTemplate</th>
<th>Spring Data JPA</th>
</tr>
</thead>
<tbody>
<tr>
<td>查询全部</td>
<td>手写 SQL + RowMapper</td>
<td><code>findAll()</code></td>
</tr>
<tr>
<td>查询单条</td>
<td>手写 SQL + RowMapper</td>
<td><code>findById(id)</code></td>
</tr>
<tr>
<td>插入</td>
<td>手写 SQL + KeyHolder</td>
<td><code>save(entity)</code></td>
</tr>
<tr>
<td>更新</td>
<td>手写 SQL</td>
<td><code>save(entity)</code>（根据 ID 自动判断）</td>
</tr>
<tr>
<td>删除</td>
<td>手写 SQL</td>
<td><code>deleteById(id)</code></td>
</tr>
<tr>
<td>统计</td>
<td>手写 SQL</td>
<td><code>count()</code></td>
</tr>
</tbody>
</table>
<p><strong>Spring Data JPA 的优势：</strong></p>
<ul>
<li>无需编写 SQL 语句</li>
<li>无需编写结果集映射</li>
<li>无需手动管理主键生成</li>
<li>代码量减少 70% 以上</li>
</ul>
<p><strong>适用场景：</strong></p>
<ul>
<li>标准 CRUD 操作</li>
<li>业务逻辑复杂的领域模型</li>
<li>需要快速开发的场景</li>
</ul>
<p><strong>JdbcTemplate 仍然适用的场景：</strong></p>
<ul>
<li>需要手写复杂 SQL（多表关联、聚合查询）</li>
<li>对 SQL 性能有极致要求</li>
<li>需要精细控制 SQL 执行过程</li>
</ul>
<h2 id="注意事项">注意事项</h2>
<h3 id="1-实体类必须有无参构造方法">1. 实体类必须有无参构造方法</h3>
<p>JPA 通过反射创建实体实例，必须提供<strong>无参构造方法</strong>（可以是 <code>private</code>）。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="kd">public</span><span class="w"> </span><span class="nf">Book</span><span class="p">()</span><span class="w"> </span><span class="p">{</span><span class="w"> </span><span class="p">}</span><span class="w">  </span><span class="c1">// JPA 要求</span>
</code></pre></div>

<h3 id="2-PostgreSQL-自增主键">2. PostgreSQL 自增主键</h3>
<p>使用 <code>GenerationType.IDENTITY</code> 时，PostgreSQL 对应 <code>bigserial</code> 类型，Hibernate 会自动创建序列。</p>
<h3 id="3-注意-equals-和-hashCode">3. 注意 equals 和 hashCode</h3>
<p>建议重写 <code>equals</code> 和 <code>hashCode</code>，使用业务唯一标识（如 <code>id</code> 或业务主键），避免在集合操作时出现意外行为。</p>
<h3 id="4-避免在实体中使用基本类型">4. 避免在实体中使用基本类型</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// ❌ 不推荐：基本类型无法表示 null</span>
<span class="kd">private</span><span class="w"> </span><span class="kt">int</span><span class="w"> </span><span class="n">stock</span><span class="p">;</span>

<span class="c1">// ✅ 推荐：使用包装类</span>
<span class="kd">private</span><span class="w"> </span><span class="n">Integer</span><span class="w"> </span><span class="n">stock</span><span class="p">;</span>
</code></pre></div>

<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>Spring Data JPA 的依赖与配置</strong>：
   - <code>spring-boot-starter-data-jpa</code> 依赖
   - PostgreSQL 驱动和连接配置
   - JPA 属性（<code>ddl-auto</code>、<code>show-sql</code>、<code>dialect</code> 等）</li>
<li><strong>JPA 实体映射</strong>：
   - <code>@Entity</code>、<code>@Table</code>、<code>@Id</code>、<code>@GeneratedValue</code>、<code>@Column</code>
   - <code>@PrePersist</code>、<code>@PreUpdate</code> 生命周期回调</li>
<li><strong>Repository 接口</strong>：
   - 继承 <code>JpaRepository&lt;T, ID&gt;</code> 自动获得完整 CRUD 方法
   - 无需编写实现类</li>
<li><strong>CRUD 操作</strong>：<code>save</code>、<code>findById</code>、<code>findAll</code>、<code>deleteById</code>、<code>count</code> 等</li>
<li><strong>Service 层注入</strong>：在 Service 中注入 Repository 并调用</li>
<li><strong>对比 JdbcTemplate</strong>：Spring Data JPA 代码量大幅减少，适合标准 CRUD 场景</li>
</ol>
