<h2 id="ORM-核心概念回顾">ORM 核心概念回顾</h2>
<h3 id="什么是-ORM">什么是 ORM</h3>
<p><strong>ORM（Object-Relational Mapping，对象关系映射）</strong> 是一种编程技术，用于将关系型数据库中的表结构映射为面向对象语言中的对象，让开发者可以用操作对象的方式来操作数据库。</p>

<h2 id="MyBatis-概述">MyBatis 概述</h2>
<h3 id="什么是-MyBatis">什么是 MyBatis</h3>
<p><strong>MyBatis</strong> 是一款优秀的<strong>持久层框架</strong>，它支持自定义 SQL、存储过程以及高级映射。MyBatis 消除了几乎所有的 JDBC 代码和参数的手工设置以及结果集的检索封装。</p>
<h3 id="MyBatis-核心架构">MyBatis 核心架构</h3>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    App[应用程序] --&gt; SqlSessionFactory[SqlSessionFactory]
    SqlSessionFactory --&gt; SqlSession[SqlSession]
    SqlSession --&gt; Mapper[Mapper 接口/XML]
    Mapper --&gt; SQL[执行 SQL]
    SQL --&gt; DB[(数据库)]

    subgraph MyBatis配置
        Config[mybatis-config.xml / application.yml]
        Mappers[Mapper XML 文件]
    end

    Config -.-&gt; SqlSessionFactory
    Mappers -.-&gt; Mapper
</code></pre></div>

<h3 id="核心组件说明">核心组件说明</h3>

<h3 id="MyBatis-工作流程">MyBatis 工作流程</h3>
<div class="codehilite lang-mermaid"><pre><span></span><code>sequenceDiagram
    participant App as 应用程序
    participant SSF as SqlSessionFactory
    participant SS as SqlSession
    participant M as Mapper
    participant DB as 数据库

    App-&gt;&gt;SSF: 获取 SqlSession
    SSF--&gt;&gt;App: 返回 SqlSession
    App-&gt;&gt;SS: 获取 Mapper 代理
    SS--&gt;&gt;App: 返回 Mapper 实例
    App-&gt;&gt;M: 调用 Mapper 方法
    M-&gt;&gt;SS: 执行 SQL
    SS-&gt;&gt;DB: 执行 SQL 并映射结果
    DB--&gt;&gt;SS: 返回结果集
    SS--&gt;&gt;M: 映射为对象
    M--&gt;&gt;App: 返回结果
</code></pre></div>

<blockquote>
<p>[!NOTE]
MyBatis 的核心是 <strong>Mapper 动态代理</strong>：应用程序调用 Mapper 接口方法时，MyBatis 通过动态代理生成代理对象，解析 XML 或注解中的 SQL，执行并映射结果。</p>
</blockquote>

<h2 id="注意事项">注意事项</h2>
<ol>
<li>
<p><strong>XML 文件路径必须匹配</strong>：<code>mybatis.mapper-locations</code> 默认值为 <code>classpath*:mapper/**/*.xml</code>，确保 XML 文件放在 <code>src/main/resources/mapper/</code> 目录或其子目录下。</p>
</li>
<li>
<p><strong>namespace 必须与 Mapper 接口全限定名一致</strong>：如果 namespace 写错，应用启动时会报错。</p>
</li>
<li>
<p><strong>resultType 与 resultMap</strong></p>
</li>
</ol>
<ul>
<li><code>resultType</code> 用于简单映射（字段名与列名自动匹配或符合驼峰规则）</li>
<li><code>resultMap</code> 用于复杂映射（如关联对象、自定义映射规则）</li>
<li>若同时配置了 <code>map-underscore-to-camel-case: true</code>，大多数简单查询可用 <code>resultType</code></li>
</ul>
<ol start="4">
<li><strong>事务管理</strong>：MyBatis 可以与 Spring 事务管理无缝整合，使用 <code>@Transactional</code> 即可，无需额外配置。</li>
</ol>
