<h3 id="方法命名查询的原理">方法命名查询的原理</h3>
<p>Spring Data JPA 在启动时会解析方法名，生成对应的 JPQL 查询。例如：</p>
<table>
<thead>
<tr>
<th>方法</th>
<th>自动生成的 JPQL</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>findByAuthor(String author)</code></td>
<td><code>SELECT b FROM Book b WHERE b.author = ?1</code></td>
</tr>
<tr>
<td><code>findByPriceBetween(Double min, Double max)</code></td>
<td><code>SELECT b FROM Book b WHERE b.price BETWEEN ?1 AND ?2</code></td>
</tr>
<tr>
<td><code>findByTitleContaining(String keyword)</code></td>
<td><code>SELECT b FROM Book b WHERE b.title LIKE CONCAT('%', ?1, '%')</code></td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]
方法命名查询虽然方便，但方法名可能变得很长，且不支持复杂查询（如多表关联、子查询等）。对于复杂场景，可以使用 <code>@Query</code> 注解。</p>
</blockquote>
<h2 id="Query-注解">@Query 注解</h2>
<h3 id="什么是-Query">什么是 @Query</h3>
<p><code>@Query</code> 注解允许开发者直接在 Repository 方法上定义 JPQL 或原生 SQL 查询语句，提供了最大的灵活性。</p>
<h3 id="JPQL-查询">JPQL 查询</h3>
<p><strong>JPQL（Java Persistence Query Language）</strong> 是 JPA 定义的面向对象的查询语言，操作的是<strong>实体对象</strong>而非数据库表。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Repository</span>

<code>@Param</code> 注解用于绑定方法参数到 JPQL 中的命名参数（<code>:author</code>）。如果参数名与 JPQL 中的命名参数一致，且编译时保留参数名（<code>-parameters</code>），可省略 <code>@Param</code>。</p>
</blockquote>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-方法命名查询的限制">1. 方法命名查询的限制</h3>
<ul>
<li>方法名不能太长，否则难以维护</li>
<li>不支持多表关联（可用 <code>@Query</code>）</li>
</ul>
<h3 id="2-Query-中的参数绑定">2. @Query 中的参数绑定</h3>
<ul>
<li>使用 <code>:</code> 加参数名（如 <code>:author</code>）</li>
<li>使用 <code>@Param</code> 绑定方法参数</li>
<li>支持 SpEL 表达式（如 <code>:#{#param}</code>）</li>
</ul>
<h3 id="3-Modifying-的副作用">3. @Modifying 的副作用</h3>
<ul>
<li>修改操作不会自动刷新持久化上下文，可能导致查询结果过时</li>
<li>建议设置 <code>clearAutomatically = true</code> 清除缓存</li>
<li>必须配合 <code>@Transactional</code> 使用</li>
</ul>
<h3 id="4-分页参数">4. 分页参数</h3>
<ul>
<li><code>PageRequest.of(page, size)</code> 中 <code>page</code> 从 <code>0</code> 开始</li>
<li>用户传入的页码通常从 <code>1</code> 开始，需减 1 转换</li>
</ul>
<h3 id="5-性能考虑">5. 性能考虑</h3>
<ul>
<li>大结果集查询建议使用分页</li>
<li><code>@Query</code> 复杂查询要注意 SQL 性能</li>
<li>原生 SQL 可以使用数据库特有的性能优化语法</li>
</ul>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>方法命名查询</strong>：通过 <code>findBy</code> + 属性名 + 操作符自动生成 SQL，简单易用。</li>
<li><strong>@Query 注解</strong>：支持 JPQL 和原生 SQL，提供最大灵活性。</li>
<li><strong>分页与排序</strong>：<code>Pageable</code> 和 <code>Sort</code> 实现动态分页和排序查询。</li>
<li><strong>@Modifying</strong>：执行更新和删除操作，注意清理持久化上下文。</li>
<li><strong>查询策略</strong>：根据场景选择合适的方式，保持代码可读性。</li>
</ol>
