<h2 id="回顾与导入">回顾与导入</h2>
<p>在上一讲中，我们使用 <code>@Async</code> 实现了异步方法，但底层使用的是 Spring 默认的 <code>SimpleAsyncTaskExecutor</code>。</p>
<p><strong>默认执行器的局限：</strong></p>
<table>
<thead>
<tr>
<th>问题</th>
<th>说明</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>无线程复用</strong></td>

</tr>

<td>频繁创建销毁线程开销大</td>
</tr>
</tbody>
</table>

<h2 id="TaskExecutor-体系概述">TaskExecutor 体系概述</h2>
<h3 id="什么是-TaskExecutor">什么是 TaskExecutor</h3>
<p><code>TaskExecutor</code> 是 Spring 提供的任务执行器抽象接口，类似于 Java 的 <code>Executor</code>，但增加了 Spring 的生命周期管理能力。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    TaskExecutor[TaskExecutor 接口] --&gt; Simple[SimpleAsyncTaskExecutor&lt;br/&gt;每次新建线程]
    TaskExecutor --&gt; ThreadPool[ThreadPoolTaskExecutor&lt;br/&gt;基于线程池（推荐）]
    TaskExecutor --&gt; Concurrent[ConcurrentTaskExecutor&lt;br/&gt;适配 JDK 线程池]
    TaskExecutor --&gt; Sync[SyncTaskExecutor&lt;br/&gt;同步执行（测试用）]

    style ThreadPool fill:#e8f5e9
    style Simple fill:#ffcdd2
</code></pre></div>

<h3 id="核心实现类对比">核心实现类对比</h3>
<table>
<thead>
<tr>
<th>实现类</th>
<th>说明</th>
<th>适用场景</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>SimpleAsyncTaskExecutor</code></td>
<td>每次调用新建线程，不重用</td>
<td>❌ 生产环境不推荐</td>
</tr>
<tr>
<td><strong><code>ThreadPoolTaskExecutor</code></strong></td>
<td>基于线程池，支持核心参数</td>
<td>✅ <strong>最常用，推荐</strong></td>
</tr>
<tr>
<td><code>ConcurrentTaskExecutor</code></td>
<td>适配 <code>java.util.concurrent.Executor</code></td>
<td>需要适配 JDK 线程池</td>
</tr>
<tr>
<td><code>SyncTaskExecutor</code></td>
<td>同步执行，不异步</td>
<td>单元测试</td>
</tr>
</tbody>
</table>
<blockquote>
<p>[!NOTE]
本课重点讲解 <code>ThreadPoolTaskExecutor</code>，它是 Spring 对 <code>java.util.concurrent.ThreadPoolExecutor</code> 的封装，提供了更友好的配置方式。</p>
</blockquote>

<h2 id="拒绝策略详解">拒绝策略详解</h2>
<h3 id="什么是拒绝策略">什么是拒绝策略</h3>
<p>当线程池已满（核心线程、任务队列、最大线程都已饱和）时，新提交的任务会触发拒绝策略。</p>
<h3 id="内置拒绝策略">内置拒绝策略</h3>
<table>
<thead>
<tr>
<th>策略</th>
<th>说明</th>
<th>适用场景</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>AbortPolicy（默认）</strong></td>
<td>抛出 <code>RejectedExecutionException</code></td>
<td>关键任务，不能丢弃</td>
</tr>
<tr>
<td><strong>CallerRunsPolicy</strong></td>
<td>由调用方线程执行</td>
<td>希望任务必须执行，且需要反馈</td>
</tr>
<tr>
<td><strong>DiscardPolicy</strong></td>
<td>静默丢弃任务</td>
<td>非关键任务，可丢失</td>
</tr>
<tr>
<td><strong>DiscardOldestPolicy</strong></td>
<td>丢弃队列中最旧的任务，重试提交</td>
<td>最新任务优先级高</td>
</tr>
</tbody>
</table>

<h2 id="注意事项">注意事项</h2>
<h3 id="1-线程池大小设置">1. 线程池大小设置</h3>
<ul>
<li><strong>CPU 密集型</strong>：corePoolSize = CPU 核心数 + 1（充分利用 CPU）</li>
<li><strong>I/O 密集型</strong>：corePoolSize = CPU 核心数 × 2（更关注 I/O 等待）</li>
<li><strong>混合型</strong>：根据实际负载测试，逐步调整</li>
</ul>
<h3 id="2-队列容量设置">2. 队列容量设置</h3>
<ul>
<li>队列过大会占用内存，可能导致 OOM</li>
<li>队列过小容易触发拒绝策略</li>
<li>通常设置为 50-1000，根据任务量和内存决定</li>
</ul>
<h3 id="3-优雅关闭">3. 优雅关闭</h3>
<div class="codehilite lang-java"><pre><span></span><code><span class="n">executor</span><span class="p">.</span><span class="na">setWaitForTasksToCompleteOnShutdown</span><span class="p">(</span><span class="kc">true</span><span class="p">);</span>
<span class="n">executor</span><span class="p">.</span><span class="na">setAwaitTerminationSeconds</span><span class="p">(</span><span class="mi">30</span><span class="p">);</span>
</code></pre></div>

<p>确保应用关闭时，正在执行的任务能够完成。</p>
<h3 id="4-监控与告警">4. 监控与告警</h3>
<ul>
<li>监控活跃线程数、队列大小</li>
<li>设置告警阈值（如队列超过 80%）</li>
<li>定期检查任务完成情况</li>
</ul>
