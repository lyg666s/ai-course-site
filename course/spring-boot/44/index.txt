<ul>
<li>掌握无返回值异步方法的使用和异常处理</li>

<h2 id="回顾与导入">回顾与导入</h2>
<p>在前面内容中，我们学习了 @Async 的基本用法和线程池配置，但所有示例都是无返回值的（<code>void</code>）。在实际项目中，我们经常需要异步任务返回结果，并且需要妥善处理可能发生的异常。</p>
<div class="codehilite lang-mermaid"><pre><span></span><code>flowchart TB
    A[异步方法返回值] --&gt; B[void&lt;br/&gt;无返回值]
    A --&gt; C[Future&lt;br/&gt;有返回值]
    A --&gt; D[CompletableFuture&lt;br/&gt;异步编排]

    style B fill:#e3f2fd
    style C fill:#e8f5e9
    style D fill:#fff3e0
</code></pre></div>

<p>本节课将深入讲解异步方法的返回值类型、异常处理机制以及异步编排的最佳实践。</p>
<h2 id="无返回值异步方法">无返回值异步方法</h2>
<h3 id="基本用法">基本用法</h3>
<p>无返回值异步方法是最简单的异步形式，方法声明为 <code>void</code>：</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">AsyncLogService</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="nd">@Async</span><span class="p">(</span><span class="s">"logExecutor"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">logOperation</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">msg</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 异步执行，无返回值</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"日志记录: "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">msg</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h3 id="异常处理">异常处理</h3>
<p>无返回值异步方法的异常<strong>不会传播到调用方</strong>，需要单独处理。默认情况下，异常会被记录到日志。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@Service</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">AsyncLogService</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="nd">@Async</span><span class="p">(</span><span class="s">"logExecutor"</span><span class="p">)</span>
<span class="w">    </span><span class="kd">public</span><span class="w"> </span><span class="kt">void</span><span class="w"> </span><span class="nf">logOperation</span><span class="p">(</span><span class="n">String</span><span class="w"> </span><span class="n">msg</span><span class="p">)</span><span class="w"> </span><span class="p">{</span>
<span class="w">        </span><span class="c1">// 如果这里抛出异常，调用方不会收到</span>

<span class="w">            </span><span class="k">throw</span><span class="w"> </span><span class="k">new</span><span class="w"> </span><span class="n">IllegalArgumentException</span><span class="p">(</span><span class="s">"消息不能为空"</span><span class="p">);</span>
<span class="w">        </span><span class="p">}</span>
<span class="w">        </span><span class="n">System</span><span class="p">.</span><span class="na">out</span><span class="p">.</span><span class="na">println</span><span class="p">(</span><span class="s">"日志记录: "</span><span class="w"> </span><span class="o">+</span><span class="w"> </span><span class="n">msg</span><span class="p">);</span>
<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<p><strong>调用方无法感知异常：</strong></p>
<div class="codehilite lang-java"><pre><span></span><code><span class="nd">@RestController</span>
<span class="kd">public</span><span class="w"> </span><span class="kd">class</span> <span class="nc">LogController</span><span class="w"> </span><span class="p">{</span>

<span class="w">    </span><span class="p">}</span>
<span class="p">}</span>
</code></pre></div>

<h2 id="CompletableFuture-进阶">CompletableFuture 进阶</h2>
<h3 id="什么是-CompletableFuture">什么是 CompletableFuture</h3>
<p><code>CompletableFuture</code> 是 Java 8 引入的异步编程工具，比 <code>Future</code> 更强大：</p>
<ul>
<li>支持链式调用（<code>thenApply</code>、<code>thenAccept</code>、<code>thenRun</code>）</li>
<li>支持组合多个异步任务（<code>allOf</code>、<code>anyOf</code>）</li>
<li>支持异常处理（<code>exceptionally</code>、<code>handle</code>）</li>
<li>支持手动完成（<code>complete</code>、<code>completeExceptionally</code>）</li>
</ul>

<h3 id="1-Futureget-阻塞问题">1. Future.get() 阻塞问题</h3>
<p><code>get()</code> 会阻塞当前线程，如果异步方法执行时间过长，可能导致请求超时。<strong>必须设置超时时间</strong>。</p>
<div class="codehilite lang-java"><pre><span></span><code><span class="c1">// ❌ 无限等待</span>

<h3 id="2-异常处理优先原则">2. 异常处理优先原则</h3>
<ul>
<li>无返回值异步方法：使用 <code>AsyncUncaughtExceptionHandler</code></li>
<li>有返回值异步方法：使用 <code>future.get()</code> 捕获异常</li>
<li>CompletableFuture：使用 <code>exceptionally</code> 或 <code>handle</code></li>
</ul>
<h3 id="3-异步方法返回类型选择">3. 异步方法返回类型选择</h3>
<table>
<thead>
<tr>
<th>场景</th>
<th>推荐返回类型</th>
</tr>
</thead>
<tbody>
<tr>
<td>不需要结果</td>
<td><code>void</code></td>
</tr>
<tr>
<td>需要获取结果</td>
<td><code>CompletableFuture&lt;T&gt;</code></td>
</tr>
<tr>
<td>简单场景</td>
<td><code>Future&lt;T&gt;</code> + <code>AsyncResult</code></td>
</tr>
</tbody>
</table>
<h3 id="4-线程池隔离">4. 线程池隔离</h3>
<p>为不同返回值类型的任务配置不同的线程池，避免相互影响。</p>
<h2 id="小结">小结</h2>
<p>本节课我们学习了：</p>
<ol>
<li><strong>无返回值异步方法</strong>：使用 <code>void</code>，异常通过 <code>AsyncUncaughtExceptionHandler</code> 处理</li>
<li><strong>有返回值异步方法</strong>：
   - <code>Future</code> + <code>AsyncResult</code> 包装结果
   - <code>Future.get()</code> 获取结果并处理异常</li>
<li><strong>CompletableFuture 进阶</strong>：
   - 链式调用（<code>thenApply</code>、<code>thenAccept</code>、<code>thenRun</code>）
   - 组合多个任务（<code>allOf</code>、<code>anyOf</code>）
   - 异常处理（<code>exceptionally</code>、<code>handle</code>）</li>
<li><strong>实战应用</strong>：异步报表生成和导出</li>
</ol>
